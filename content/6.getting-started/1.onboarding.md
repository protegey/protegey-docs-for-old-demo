# Getting Started

Becoming a Centry partner involves a multi-stage onboarding process designed to ensure security and compliance.

## Onboarding Stages

### Stage 1: Discovery
**Access**: Public documentation only

- Evaluate the platform
- Review technical requirements
- Understand the trust model

**No account required**

---

### Stage 2: Approved Pilot Partner
**Access**: Partner documentation (Sandbox sections only)

**Requirements**:
- Legal agreement signed
- Compliance questionnaire approved
- Named technical contact designated

**What you get**:
- Sandbox API access
- Test credentials
- Limited API reference
- Integration support

---

### Stage 3: Pre-Production Review
**Access**: Full partner documentation + Production API reference

**Requirements**:
- Successful sandbox validation
- Security review completed
- Incident response contact provided
- Go-live checklist completed

**What you get**:
- Production API credentials
- Full API documentation
- Production environment access

---

### Stage 4: Live Partner
**Access**: Full partner documentation + Changelog + Incident guides

**Ongoing requirements**:
- Maintain compliance standards
- Respond to security incidents
- Adhere to fair use policies

::callout{icon="i-lucide-info" color="blue"}
Abuse or misuse can result in restricted documentation access and API suspension.
::

## Next Steps

Contact our partnership team at [partners@centry.ai](mailto:partners@centry.ai) to begin the onboarding process.
