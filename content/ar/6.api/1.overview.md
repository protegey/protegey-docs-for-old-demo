واجهة برمجة تطبيقات Protegey هي واجهة RESTful مصممة لاتخاذ قرارات مكافحة الاحتيال عالية الأداء في الوقت الفعلي.

::callout{icon="i-lucide-lock" color="amber"}
**وصول عام مقيّد**: يقدم هذا القسم نظرة عامة مفاهيمية. توثيق مرجعي API الكامل (نقاط النهاية والمخططات ورموز الخطأ) متاح فقط للشركاء المعتمدين في [توثيق الشركاء](/ar/partners).
::

## فلسفة التصميم

### 1. موجّه نحو الموارد

تنظم واجهة API حول موارد قياسية:

- `Signals`: مؤشرات الاحتيال التي يُقدّمها الشركاء.
- `Queries`: طلبات تقييم المخاطر.
- `Entities`: الكيانات قيد التحليل (المستخدمون والأجهزة والمدفوعات).

### 2. الأمان كإعداد افتراضي

- تتطلب جميع نقاط النهاية HTTPS (TLS 1.3).
- المصادقة عبر مفاتيح API عالية الانتروبيا.
- التحقق من صحة المدخلات صارم؛ تُرفض الطلبات المشوّهة فورًا.

### 3. الأداء أولًا

- مُصمَّمة لمسارات اتخاذ القرار دون الثانية.
- معالجة غير متزامنة للعمليات غير المقيّدة.
- تخزين مؤقت على الحافة لجميع الأصول الثابتة.

## أنماط التكامل

ندعم نمطَي تكامل رئيسيين:

### المتزامن (استعلام المخاطر)

الأنسب لاتخاذ القرار في الوقت الفعلي (مثل تسجيل الدخول وإتمام الشراء).

1. يُرسل خادمك `Query` يتضمن تفاصيل الكيان.
2. تستجيب Protegey فورًا بـ `درجة مخاطر` و`توصية`.
3. يسمح تطبيقك للمستخدم أو يحجبه بناءً على الاستجابة.

### غير المتزامن (تقديم الإشارات)

الأنسب للإبلاغ عن احتيال مؤكد أو تحديثات في الخلفية.

1. يُرسل خادمك `Signal` (مثال: "تم استلام استرداد المبلغ").
2. تقبل Protegey الإشارة (`202 Accepted`).
3. تُعالَج الإشارة وتنتشر إلى الشبكة بصورة غير متزامنة.

## البيئات

نوفر بيئتين معزولتين بصرامة:

| البيئة | الغرض | البيانات |
|---|---|---|
| **Sandbox** | اختبار التكامل والتطوير | بيانات اصطناعية/وهمية فقط |
| **الإنتاج** | الحماية المباشرة من الاحتيال | استخبارات شبكية حقيقية |

::callout{icon="i-lucide-alert-circle" color="blue"}
**ملاحظة**: البيانات لا تنتقل بين البيئات. الإشارة المُنشأة في Sandbox لن تؤثر في درجات مخاطر الإنتاج.
::

## الإصدارات

تتوفر API بأنظمة إصدارات لضمان الاستقرار.

- الإصدار الحالي: `v1`
- التغييرات المتوافقة مع الإصدارات السابقة (إضافة حقول) تُجرى دون تغيير رقم الإصدار.
- التغييرات الجذرية تتطلب إصدارًا جديدًا (مثال: `/api/v2/`).

## مجموعات SDK والمكتبات

نوفر مكتبات عميل رسمية لتبسيط التكامل:

- **Node.js**: `@centry/node`
- **Python**: `centry-python`
- **Java**: `centry-java`
- **Go**: `centry-go`

(الروابط إلى مستودعات SDK متاحة في بوابة الشريك).
