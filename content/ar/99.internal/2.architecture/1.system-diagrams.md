## الطوبولوجيا عالية المستوى

```
نظام الشريك
     │ HTTPS + X-API-Key
     ▼
SignalController (Laravel 12)
     │ التحقق من مفتاح API → تحديد الشريك
     │ فحص حد معدل الطلبات (بالساعة/باليوم حسب الخطة)
     │ فحص feature flag
     ▼
IngestSignalAction (خط أنابيب متزامن، هدف <50ms)
     ├── UFESNormalizationService
     ├── UFESValidator
     ├── ResolverRegistry (MSISDN, Device, Geo, Time)
     ├── FeatureEngineeringService → SignalFeature محفوظ
     ├── DetectorRegistry (5 مكشّفات) → DetectorExecution محفوظ
     ├── TaxonomyRegistry → TaxonomyAssignment محفوظ
     ├── HotGraphService → graph_nodes/graph_edges محدَّثة + Redis مُسخَّن
     ├── WeightedRiskFusionEngine → fused_score محسوب
     ├── PolicyEngine → قرار BLOCK/ALLOW/ESCALATE/STEP_UP
     └── AlertGenerationService → FraudAlert + AlertLineage مُنشآن
             │
             ├── (غير متزامن) AMLComplianceService
             │         → TransactionMonitoringRulesService
             │         → SanctionsMatchingService
             │         → PEPDetectionService
             │
             ├── (غير متزامن) مستمع ShareAlertOnCreation
             │         → BroadcastSharedIntelligenceJob
             │
             └── (غير متزامن) WebhookService
                       → إرسال حمولات موقّعة بـ HMAC إلى partner_webhooks
```

## البنية التحتية الأساسية

| المكوّن | التقنية | الغرض |
|---|---|---|
| خادم الويب | Laravel 12 (Octane اختياري) | معالجة طلبات HTTP |
| قائمة الانتظار | Laravel queues (محرك Redis) | معالجة المهام غير المتزامنة |
| قاعدة البيانات الرئيسية | PostgreSQL 15+ | جميع البيانات الدائمة |
| الذاكرة المؤقتة + التجاور | Redis 7+ | ذاكرة مؤقتة للرسم البياني، مؤقتة للمخاطر الجغرافية، عدادات حدود المعدل |
| الدفع الفوري | Laravel Reverb (WebSockets) | تحديثات بوابة الشريك المباشرة |
| واجهة الإدارة | Inertia.js + Vue 3 | لوحة الإدارة الداخلية |
| بوابة الشريك | Nuxt 3 (SPA) | البوابة الموجهة للشريك |

## عزل مخطط قاعدة البيانات

```
قاعدة بيانات PostgreSQL
├── مخطط public
│   ├── signals, fraud_entities, fraud_cases, fraud_alerts
│   ├── graph_nodes, graph_edges
│   ├── partner_webhooks, webhook_deliveries
│   ├── policy_documents, decision_explanations
│   ├── aml_transaction_flags, suspicious_activity_reports
│   ├── pep_designations, geographic_risk_profiles
│   ├── osint_facts, osint_sources, osint_entity_links
│   ├── shared_intelligence_feed, regulatory_advisories
│   └── users, partners, subscriptions (مشتركة)
│
└── مخطط sandbox
    ├── signals (بيانات شريك sandbox)
    ├── fraud_entities (بيانات شريك sandbox)
    ├── fraud_cases (بيانات شريك sandbox)
    └── [جميع الجداول ذات نطاق الشريك مُكرَّرة]
```

`SET search_path TO {sandbox|public}, public` يُطبَّق لكل طلب بواسطة middleware `EnforceSchemaIsolation`. تستعلم النماذج المخطط الصحيح تلقائيًا.

## استخبارات الرسم البياني (Hot Graph)

```
إشارة مستوعَبة
     │
     ▼
HotGraphService::linkSignalToGraph()
     │
     ├── GraphNodeService::upsert(ACTOR, actor.hashed_id)
     ├── GraphNodeService::upsert(ACCOUNT, account)
     ├── GraphNodeService::upsert(DEVICE, device_fingerprint)
     ├── GraphNodeService::upsert(MSISDN, msisdn)
     ├── GraphEdgeService::upsert(ACTOR → ACCOUNT, USES_ACCOUNT)
     ├── GraphEdgeService::upsert(ACTOR → DEVICE, USES_DEVICE)
     └── GraphEdgeService::upsert(ACTOR → MSISDN, USES_PHONE)

GraphCacheService (Redis)
     ├── graph:1hop:{node_id} → جيران JSON (TTL 15 دقيقة)
     └── graph:2hop:{node_id} → تجميع JSON بسَفَرَيْن (TTL 15 دقيقة)

HotGraphService::getNeighborhoodRisk(nodeId, hops=2)
     └── ذاكرة مؤقتة read-through: Redis أولًا → رجوع إلى Postgres
```

أنواع العقد: `ACTOR`, `ACCOUNT`, `MSISDN`, `DEVICE`, `IP`, `MERCHANT`, `AGENT`, `BENEFICIARY`
أنواع الحواف: `USES_DEVICE`, `USES_PHONE`, `SENT_TO`, `RECEIVED_FROM`, `CASHED_OUT_AT`, `SHARED_IDENTIFIER`

جميع استعلامات الرسم البياني مقيّدة بـ `tenant_id` لمنع IDOR عبر المستأجرين.

## جدول المهام غير المتزامنة

| المهمة | الجدول | الاعتماد |
|---|---|---|
| `osint:ingest` (UN/EU/AU) | يومي 03:00 UTC | لا يوجد |
| `BulkSanctionsRescreeningJob` | يومي 04:00 UTC | بعد استيعاب OSINT |
| `ComplianceCalendarReminderJob` | يومي 08:00 UTC | لا يوجد |
| `GraphCacheRebuildJob` | أسبوعي الأحد 02:00 UTC | لا يوجد |
| `ThresholdAutoCalibrationJob` | عند الطلب | طلب الشريك |
