# واجهة برمجة المنظم

يُهيَّأ المنظمون كحسابات خاصة بـ `role: regulator` في نظام IAM. يصلون إلى واجهة برمجة بث الاستشارات عبر عميل OAuth2 مخصص. توثّق هذه الصفحة نقاط النهاية الموجهة للمنظمين التي **لا تُكشف** في وثائق API الموجهة للشركاء.

---

## المصادقة

تستخدم حسابات المنظمين نفس تدفق OAuth2 كالشركاء لكنها تتلقى رمزًا بنطاق `regulator`:

```http
POST /oauth/token
{
  "grant_type": "client_credentials",
  "client_id": "{regulator_client_id}",
  "client_secret": "{regulator_client_secret}",
  "scope": "regulator"
}
```

---

## نقاط النهاية

### بث استشارة

```http
POST /api/v1/regulator/advisories
Authorization: Bearer {regulator_token}
```

ينشئ استشارة ويبثها لجميع الشركاء في النطاق المستهدف المحدد.

**جسم الطلب**:

```json
{
  "title": "FATF Mutual Evaluation — Enhanced Monitoring Required",
  "body": "All partners operating in jurisdictions under enhanced monitoring must implement additional transaction screening by 2026-04-01.",
  "severity": "high",
  "category": "regulatory_update",
  "target_scope": "all",
  "expires_at": "2026-04-30T23:59:59Z",
  "action_required": true,
  "action_deadline": "2026-04-01T00:00:00Z"
}
```

| الحقل | النوع | الوصف |
|-------|------|-------------|
| `title` | string | 255 حرفًا كحد أقصى |
| `body` | string | نص الاستشارة الكامل (يدعم Markdown) |
| `severity` | string | `critical`، `high`، `medium`، `low`، `info` |
| `category` | string | `regulatory_update`، `threat_intelligence`، `platform_notice`، `compliance_deadline` |
| `target_scope` | string | `all`، `enterprise`، أو `partner_uuid` محدد |
| `expires_at` | datetime | متى تنتهي الاستشارة (اختياري) |
| `action_required` | boolean | هل يجب على الشركاء الإقرار |
| `action_deadline` | datetime | الموعد النهائي للإجراء المطلوب (اختياري) |

**الاستجابة**: `201 Created` مع UUID الاستشارة.

---

### تعطيل استشارة

```http
PATCH /api/v1/regulator/advisories/{uuid}/deactivate
Authorization: Bearer {regulator_token}
```

يُعطِّل الاستشارة فورًا — تختفي من جميع بوابات الشركاء ولا تُحسب بعد ذلك في شارات غير المقروءة. استخدمه حين تُصدر استشارة بالخطأ أو يُستبدَل بها واحدة أحدث.

**الاستجابة**: `200 OK` مع حالة الاستشارة المحدَّثة.

---

### إحصاءات التسليم

```http
GET /api/v1/regulator/advisories/{uuid}/stats
Authorization: Bearer {regulator_token}
```

يُعيد إحصاءات التسليم والإقرار لاستشارة مبثوثة.

**الاستجابة**:

```json
{
  "data": {
    "advisory_uuid": "adv_01HZ...",
    "title": "FATF Mutual Evaluation — Enhanced Monitoring Required",
    "total_recipients": 47,
    "delivered": 47,
    "read": 38,
    "acknowledged": 29,
    "dismissed": 3,
    "pending_acknowledgement": 15,
    "action_required": true,
    "action_deadline": "2026-04-01T00:00:00Z"
  }
}
```

## حدود معدل الطلبات

تخضع رموز المنظمين لحدود معدل أكثر صرامة من رموز الشركاء — إذ يُعدّ بث الاستشارات عملية ذات توزيع واسع.

| نقطة النهاية | الحد | النافذة الزمنية |
|----------|--------|---------|
| `POST /regulator/advisories` | 10 | في الساعة |
| `PATCH /regulator/advisories/{uuid}/deactivate` | 30 | في الساعة |
| `GET /regulator/advisories/{uuid}/stats` | 120 | في الساعة |

يُعيد تجاوز الحدود `429 Too Many Requests` مع رأس `Retry-After` (بالثواني). طلبات البث التي تُطلق توزيعًا لأكثر من 100 شريك تُضاف إلى قائمة الانتظار — تُعاد الاستجابة فورًا بـ `202 Accepted` مع UUID الاستشارة؛ التسليم غير متزامن.

---

## رموز الخطأ

| الرمز | HTTP | المعنى |
|------|------|---------------|
| `advisory_not_found` | 404 | UUID غير موجود أو ينتمي لمنظّم آخر |
| `advisory_already_deactivated` | 409 | الاستشارة معطّلة بالفعل — التعطيل المتبادل آمن للإعادة |
| `advisory_expired` | 422 | `expires_at` في الماضي وقت البث |
| `invalid_target_scope` | 422 | `target_scope` ليس `all` أو `enterprise` أو UUID شريك صالح |
| `action_deadline_before_now` | 422 | `action_deadline` في الماضي |
| `action_deadline_without_flag` | 422 | `action_deadline` مُقدَّم لكن `action_required: false` |
| `regulator_scope_missing` | 403 | الرمز لا يحمل نطاق `regulator` |
| `regulator_account_suspended` | 403 | حساب المنظم غير نشط — تواصل مع فريق عمليات Protegey |
| `broadcast_fan_out_failed` | 500 | خطأ في إرسال المهام — الاستشارة مُحفظة لكن مهام التسليم لم تُضَف للقائمة؛ أعد التشغيل عبر `php artisan advisories:retry-dispatch {uuid}` |

## توفير عميل OAuth

### إنشاء حساب منظِّم

```bash
# 1. إنشاء مستخدم المنظّم + سجل الشريك
php artisan make:regulator "{اسم_المؤسسة}" "{بريد_المسؤول}"
# الإخراج: UUID المنظّم، كلمة مرور مُولَّدة (مرة واحدة — أرسلها عبر قناة آمنة)

# 2. إنشاء عميل client_credentials لـ OAuth2
php artisan passport:client --client --name="{اسم_المؤسسة} Regulator Client"
# الإخراج: client_id و client_secret — احفظهما في 1Password ضمن "Regulator OAuth Clients"
# تُعرض هذه القيم مرة واحدة فقط؛ لا يُعيد Passport كشف السر بعد الإنشاء

# 3. تعيين نطاق regulator للعميل
php artisan passport:scope --client-id={client_id} --scope=regulator
```

### تدوير بيانات اعتماد العميل

لا يمكن تجديد أسرار العميل في موضعها عبر Passport — يجب إعادة إنشاء العميل:

```bash
# 1. إنشاء عميل بديل
php artisan passport:client --client --name="{اسم_المؤسسة} Regulator Client v2"

# 2. تعيين النطاق
php artisan passport:scope --client-id={new_client_id} --scope=regulator

# 3. مشاركة البيانات الجديدة مع المنظّم (قناة آمنة)

# 4. بعد تأكيد المنظّم، إلغاء الرموز القديمة
php artisan passport:purge --revoked
# ثم تعطيل عميل OAuth القديم:
# UPDATE oauth_clients SET revoked = 1 WHERE id = {old_client_id};
```

**نافذة التدوير**: خصِّص 48 ساعة على الأقل للصلاحية المتوازية. لا تُلغِ العميل القديم قبل تأكيد المنظّم عمل العميل الجديد في الإنتاج.

### تعليق حساب منظِّم

```bash
# إلغاء جميع الرموز النشطة فورًا
php artisan passport:purge --revoked --client-id={client_id}

# تعطيل عميل OAuth
# UPDATE oauth_clients SET revoked = 1 WHERE id = {client_id};

# وضع علامة على سجل الشريك المنظّم كغير نشط
php artisan partner:deactivate {regulator_uuid} --reason="معلَّق وفق تذكرة عمليات #OP-XXXX"
```

## أحداث Webhook

### `advisory.created`

يُطلَق لكل شريك في النطاق المستهدف عند بث استشارة.

```json
{
  "event": "advisory.created",
  "delivery_id": "del_01HZ...",
  "timestamp": "2026-03-19T08:00:00Z",
  "data": {
    "advisory_uuid": "adv_01HZ...",
    "title": "FATF Mutual Evaluation — Enhanced Monitoring Required",
    "severity": "high",
    "category": "regulatory_update",
    "action_required": true,
    "action_deadline": "2026-04-01T00:00:00Z",
    "expires_at": "2026-04-30T23:59:59Z",
    "issued_by": "البنك المركزي الغاني",
    "issued_at": "2026-03-19T08:00:00Z"
  }
}
```

**سلوك التوزيع الواسع**: بث `target_scope: all` لـ 47 شريكًا بمتوسط 1.8 نقطة نهاية webhook لكل منهم يُولّد ~85 مهمة، جميعها على قائمة `webhooks`. راقبها عبر لوحة قائمة الانتظار (`/admin/queues`).

**لا يوجد حدث `advisory.deactivated`**: التعطيل لا يُطلق webhook — يزيل الاستشارة فقط من واجهة بوابة الشريك.

## ملاحظات لفريق العمليات

- تُهيَّأ حسابات المنظمين يدويًا — راجع قسم **توفير عميل OAuth** أعلاه
- يرسل `target_scope: all` إلى **جميع** الشركاء النشطين بغض النظر عن مستوى الخطة — استخدم بحذر؛ يُطلق ~85 مهمة webhook لنشر نموذجي
- الاستشارات المُعطَّلة تُحذف بصورة ناعمة — تبقى في قاعدة البيانات لأغراض التدقيق؛ متاحة عبر لوحة الإدارة في `/admin/advisories`
- تتضمن إحصاءات التسليم حسابات شركاء `sandbox` — صفِّر حسب `is_sandbox: false` إذا لزم لتقارير الامتثال
- يدعم حقل `body` للاستشارات Markdown — تظهر الروابط والتنسيق والقوائم في بوابة الشريك
- إعادة إرسال بثوث الاستشارات الفاشلة: `php artisan advisories:retry-dispatch {uuid}` — متبادل لكل نقطة نهاية شريك
