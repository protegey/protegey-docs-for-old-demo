# واجهة برمجة المنظم

يُهيَّأ المنظمون كحسابات خاصة بـ `role: regulator` في نظام IAM. يصلون إلى واجهة برمجة بث الاستشارات عبر عميل OAuth2 مخصص. توثّق هذه الصفحة نقاط النهاية الموجهة للمنظمين التي **لا تُكشف** في وثائق API الموجهة للشركاء.

---

## المصادقة

تستخدم حسابات المنظمين نفس تدفق OAuth2 كالشركاء لكنها تتلقى رمزًا بنطاق `regulator`:

```http
POST /oauth/token
{
  "grant_type": "client_credentials",
  "client_id": "{regulator_client_id}",
  "client_secret": "{regulator_client_secret}",
  "scope": "regulator"
}
```

---

## نقاط النهاية

### بث استشارة

```http
POST /api/v1/regulator/advisories
Authorization: Bearer {regulator_token}
```

ينشئ استشارة ويبثها لجميع الشركاء في النطاق المستهدف المحدد.

**جسم الطلب**:

```json
{
  "title": "FATF Mutual Evaluation — Enhanced Monitoring Required",
  "body": "All partners operating in jurisdictions under enhanced monitoring must implement additional transaction screening by 2026-04-01.",
  "severity": "high",
  "category": "regulatory_update",
  "target_scope": "all",
  "expires_at": "2026-04-30T23:59:59Z",
  "action_required": true,
  "action_deadline": "2026-04-01T00:00:00Z"
}
```

| الحقل | النوع | الوصف |
|-------|------|-------------|
| `title` | string | 255 حرفًا كحد أقصى |
| `body` | string | نص الاستشارة الكامل (يدعم Markdown) |
| `severity` | string | `critical`، `high`، `medium`، `low`، `info` |
| `category` | string | `regulatory_update`، `threat_intelligence`، `platform_notice`، `compliance_deadline` |
| `target_scope` | string | `all`، `enterprise`، أو `partner_uuid` محدد |
| `expires_at` | datetime | متى تنتهي الاستشارة (اختياري) |
| `action_required` | boolean | هل يجب على الشركاء الإقرار |
| `action_deadline` | datetime | الموعد النهائي للإجراء المطلوب (اختياري) |

**الاستجابة**: `201 Created` مع UUID الاستشارة.

---

### تعطيل استشارة

```http
PATCH /api/v1/regulator/advisories/{uuid}/deactivate
Authorization: Bearer {regulator_token}
```

يُعطِّل الاستشارة فورًا — تختفي من جميع بوابات الشركاء ولا تُحسب بعد ذلك في شارات غير المقروءة. استخدمه حين تُصدر استشارة بالخطأ أو يُستبدَل بها واحدة أحدث.

**الاستجابة**: `200 OK` مع حالة الاستشارة المحدَّثة.

---

### إحصاءات التسليم

```http
GET /api/v1/regulator/advisories/{uuid}/stats
Authorization: Bearer {regulator_token}
```

يُعيد إحصاءات التسليم والإقرار لاستشارة مبثوثة.

**الاستجابة**:

```json
{
  "data": {
    "advisory_uuid": "adv_01HZ...",
    "title": "FATF Mutual Evaluation — Enhanced Monitoring Required",
    "total_recipients": 47,
    "delivered": 47,
    "read": 38,
    "acknowledged": 29,
    "dismissed": 3,
    "pending_acknowledgement": 15,
    "action_required": true,
    "action_deadline": "2026-04-01T00:00:00Z"
  }
}
```

## ملاحظات لفريق العمليات

- تُهيَّأ حسابات المنظمين يدويًا عبر `php artisan make:regulator {name} {email}`
- يرسل `target_scope: all` إلى **جميع** الشركاء النشطين بغض النظر عن مستوى الخطة — استخدم بحذر
- تُطلق بثوث الاستشارات حدث webhook بـ `advisory.created` لجميع الشركاء المستهدفين
- الاستشارات المُعطَّلة تُحذف بصورة ناعمة — تبقى في قاعدة البيانات لأغراض التدقيق
- تتضمن إحصاءات التسليم حسابات شركاء `sandbox` — صفِّر حسب `is_sandbox: false` إذا لزم لتقارير الامتثال
