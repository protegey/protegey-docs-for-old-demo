# تسجيل ثقة OSINT

## نظرة عامة

لنتائج OSINT الخام (قوائم عقوبات الأمم المتحدة والاتحاد الأوروبي والاتحاد الأفريقي، سجلات الأشخاص السياسيين المعرضين للمخاطر) موثوقية متغيرة جدًا. تطابق على القائمة الموحدة للأمم المتحدة ليس معادلًا لتطابق على إشعار إقليمي لم يُحدَّث منذ 18 شهرًا. يُحدِّد إطار تسجيل الثقة هذا التباين عبر أربعة أبعاد.

تُحفظ درجات الثقة في `OsintEntityLink.confidence_score` (قيمة عشرية 0.0–1.0) وتُعاد في جميع استجابات فحص العقوبات.

---

## الأبعاد الأربعة

### 1. السلطة (40%)

تقيس مصداقية المصدر ووزنه التنظيمي.

| المصدر | درجة السلطة |
|--------|----------------|
| القائمة الموحدة لمجلس الأمن الدولي | 1.00 |
| قائمة عقوبات الاتحاد الأوروبي المالية الموحدة | 0.95 |
| قائمة OFAC SDN (الولايات المتحدة) | 0.95 |
| مجلس الأمن والسلام للاتحاد الأفريقي | 0.85 |
| قوائم وحدات الاستخبارات المالية الوطنية (دول FATF) | 0.75 |
| إشعارات GIABA / ESAAMLG | 0.65 |
| إشعارات INTERPOL Red Notices | 0.80 |
| قوائم OHADA الإقليمية | 0.55 |
| محركات تجميع OSINT التجارية | 0.50 |

درجات السلطة ثابتة لكل مصدر ومخزَّنة في `config/osint.php` ضمن `source_authority`.

### 2. الحداثة (25%)

تقيس مدى حداثة استيعاب بيانات المصدر ومدى حداثة تأكيد السجل المحدد. تستخدم التحلل الأسي:

```php
$daysSinceIngest = now()->diffInDays($link->ingested_at);
$freshnessScore  = exp(-$daysSinceIngest / 365); // half-life ~253 days
```

| العمر | درجة الحداثة |
|-----|----------------|
| 0–7 أيام | 0.98–1.00 |
| شهر واحد | 0.92 |
| 3 أشهر | 0.78 |
| 6 أشهر | 0.61 |
| 12 شهرًا | 0.37 |
| 24 شهرًا | 0.14 |

تُعاد احتساب الحداثة أسبوعيًا بمهمة `osint:recompute-freshness` (الأحد، 05:00 UTC).

### 3. التعزيز (20%)

يقيس عدد المصادر المستقلة التي تؤكد نفس التطابق.

```php
$sourceCount       = $link->corroborating_source_count; // 1–N
$corroborationScore = min(1.0, 0.4 + ($sourceCount - 1) * 0.2);
```

| المصادر المستقلة | درجة التعزيز |
|---------------------|---------------------|
| 1 (مصدر وحيد) | 0.40 |
| مصدران | 0.60 |
| 3 مصادر | 0.80 |
| 4 مصادر أو أكثر | 1.00 |

### 4. الخصوصية (15%)

تقيس دقة التطابق في تحديد الموضوع — الاسم القانوني الكامل + تاريخ الميلاد + الجنسية مقابل تطابق الاسم الجزئي فقط.

| حقول التطابق المتوفرة | درجة الخصوصية |
|---------------------|------------------|
| الاسم + تاريخ الميلاد + الجنسية + معرّف | 1.00 |
| الاسم + تاريخ الميلاد + الجنسية | 0.85 |
| الاسم + تاريخ الميلاد | 0.70 |
| الاسم + الجنسية | 0.60 |
| الاسم فقط | 0.40 |
| تطابق فازي / صوتي | 0.20 |

تُحتسب الخصوصية بواسطة `EntityResolutionService::computeSpecificity()` وقت الاستيعاب.

---

## صيغة الدرجة المركّبة

```php
$confidence = (
    ($authority      * 0.40) +
    ($freshness      * 0.25) +
    ($corroboration  * 0.20) +
    ($specificity    * 0.15)
);
```

**مثال**: تطابق على قائمة UN SDN، مُستوعَب منذ أسبوعين، مؤكَّد بمصدرين، الاسم + تاريخ الميلاد + الجنسية:
```
(1.00 × 0.40) + (0.97 × 0.25) + (0.60 × 0.20) + (0.85 × 0.15)
= 0.40 + 0.2425 + 0.12 + 0.1275
= 0.89
```

## الثقة في تسجيل المخاطر

تُغذّي درجات الثقة مساهمة مخاطر العقوبات:

```php
// In SanctionsMatchingService
$riskContribution = $match->is_exact_match
    ? 100 * $match->confidence_score
    : 50  * $match->confidence_score;
```

يُسهم تطابق عالي الثقة (0.9+) على قائمة UN بما يقارب 90 نقطة مخاطر. يُسهم تطابق منخفض الثقة (0.3) على قائمة إقليمية قديمة بـ ~15 نقطة — كافية للإشارة للمراجعة لكن ليس للحظر التلقائي.

---

## مهمة التحلل الأسبوعية

`php artisan osint:recompute-freshness`

- تختار جميع سجلات `OsintEntityLink` حيث `last_freshness_computed_at < 7 days ago`
- تعيد احتساب درجة الحداثة باستخدام الصيغة أعلاه
- تحدّث `confidence_score` كمركّب للسلطة الحالية + الحداثة الجديدة + التعزيز المخزَّن + الخصوصية المخزَّنة
- تسجّل عدد إعادة الاحتساب في مؤشر `osint_freshness_recomputed`

تعمل أسبوعيًا الأحد 05:00 UTC عبر Laravel scheduler. يمكن تشغيلها يدويًا دون آثار جانبية.

## الكشف عبر API

تُعاد درجات الثقة في `GET /api/v1/partner/compliance/sanctions/{entityId}`:

```json
{
  "matches": [
    {
      "source": "UN_CONSOLIDATED",
      "match_type": "exact",
      "confidence_score": 0.89,
      "confidence_breakdown": {
        "authority": 1.00,
        "freshness": 0.97,
        "corroboration": 0.60,
        "specificity": 0.85
      },
      "ingested_at": "2026-03-10T03:00:00Z"
    }
  ]
}
```
