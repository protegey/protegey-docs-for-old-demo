## الغرض

يُسجّل نظام Audit Lineage سلسلة قابلية تتبع كاملة لكل تنبيه:

```
إشارة مستلَمة
  └─> تشغيل المكشّفات (detector_executions)
        └─> تسجيل الشدة (scoring_breakdown في البيانات الوصفية للإشارة)
              └─> تعيين التصنيف (taxonomy_assignments)
                    └─> توليد التنبيه
                          └─> تسجيل السلسلة (alert_lineage)
                                └─> مكشوف عبر GET /alerts/{uuid}/lineage
```

يُلبّي هذا متطلبات قابلية التفسير التنظيمية ويُمكّن الشركاء من فهم _سبب_ توليد التنبيه عبر ميزة "اشرح هذا التنبيه".

---

## المخطط

### `detector_executions`

صف واحد لكل مكشّف لكل إشارة. يُسجّل نتيجة كل تشغيل للمكشّف.

| العمود | النوع | الوصف |
|---|---|---|
| `id` | ULID | المفتاح الأساسي |
| `signal_id` | ULID | FK → `signals.id` |
| `detector_id` | string | معرّف المكشّف (مثال: `LARGE_OUTLIER_TRANSACTION`) |
| `fired` | boolean | ما إذا كان المكشّف قد أُطلق |
| `confidence` | float | ثقة المكشّف (0.0–1.0) |
| `risk_score` | float | مساهمة المخاطر من هذا المكشّف |
| `evidence` | JSON | أدلة مفتاح-قيمة من المكشّف |
| `reasoning` | text | تفسير اختياري بلغة بشرية |
| `version` | string | إصدار المكشّف وقت التنفيذ |

### `alert_lineage`

صف واحد لكل تنبيه. يخزن السلسلة الكاملة.

| العمود | النوع | الوصف |
|---|---|---|
| `id` | ULID | المفتاح الأساسي |
| `alert_uuid` | string | FK → `fraud_alerts.uuid` |
| `signal_id` | ULID | FK → `signals.id` |
| `taxonomy_primary` | string | معرّف فئة التصنيف الأساسي |
| `taxonomy_all` | مصفوفة JSON | جميع فئات التصنيف المُعيَّنة |
| `detector_results` | JSON | لقطة لجميع نتائج تنفيذ المكشّف |
| `features` | JSON | قيم features الإشارة وقت الكشف |
| `base_severity` | float | الشدة الأساسية قبل الـ boost |
| `final_severity` | float | درجة الشدة النهائية بعد الحساب |
| `source_confidence` | float | ثقة مصدر الإشارة |
| `anomaly_factor` | float | مُضاعف كشف الشذوذ |
| `explanation` | text | تفسير تلقائي بلغة بشرية |

## تصميم غير فاتال

تسجيل السلسلة متعمَّد أنه غير فاتال. إذا رمى `recordAlertLineage()` استثناءً، يُسجَّل تحذير لكن التنبيه لا يزال يُنشأ. يمنع هذا إخفاقات تتبع السلسلة من حجب عمليات كشف الاحتيال.

المراقبة: تحقق من `Log::warning('Failed to record alert lineage', ...)` في سجلات التطبيق إذا بدت بيانات السلسلة مفقودة للتنبيهات الحديثة.
