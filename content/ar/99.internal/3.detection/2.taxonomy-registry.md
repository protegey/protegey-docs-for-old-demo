## الغرض

يستبدل Taxonomy Registry عمليات ربط `event_type → severity` المُرمَّزة بشكل ثابت في `FraudScoringService` بنظام تركيبي مستند إلى قاعدة البيانات ومدرك للمكشّفات. يُتيح ذلك:

- ضبط الشدة لكل مجال دون عمليات نشر للكود
- تعزيز الشدة المدرك للمكشّفات (المكشّفات تعزز ثقة التصنيف)
- التصنيف متعدد التسميات (يمكن أن تنتمي الإشارة إلى فئات متعددة)
- تصنيف احتيال قابل للتدقيق والتفسير

## المخطط

### `taxonomy_registry`

| العمود | النوع | الوصف |
|---|---|---|
| `id` | ULID | المفتاح الأساسي |
| `category_id` | string | معرّف بالترميز النقطي (مثال: `identity.account_takeover`) |
| `domain` | string | المجال العلوي (`identity`, `payment`, `social`, `device`, `geo`) |
| `name` | string | اسم مقروء |
| `description` | text | وصف الفئة |
| `base_severity` | float | شدة NUFSS الأساسية (0.0–1.0) |
| `detectors_required` | مصفوفة JSON | معرّفات المكشّفات التي تشير بقوة إلى هذه الفئة |
| `event_type_mappings` | مصفوفة JSON | قيم `event_type` التي تُربط بهذه الفئة |
| `version` | string | إصدار SemVer |

### `taxonomy_assignments`

| العمود | النوع | الوصف |
|---|---|---|
| `id` | ULID | المفتاح الأساسي |
| `signal_id` | ULID | FK → `signals.id` |
| `taxonomy_id` | ULID | FK → `taxonomy_registry.id` |
| `category_id` | string | منسوخ للبحث السريع |
| `confidence` | float | ثقة التعيين (0.0–1.0) |
| `is_primary` | boolean | ما إذا كان هذا التصنيف الأساسي |
| `assignment_method` | string | `event_type_mapping` أو `detector_overlap` |

## API الخدمة

### `TaxonomyRegistry::getSeverityWithDetectorBoost(string $eventType, array $firedDetectorIds): float`

يُعيد `base_severity` بالإضافة إلى boost تداخل المكشّف (حتى +0.10). يُستخدم بواسطة `FraudScoringService`.

### `TaxonomyRegistry::assignTaxonomy(Signal $signal, array $detectorResults): array`

يكتب صفوف `taxonomy_assignments` للإشارة:

1. **التعيين الأساسي**: مشتق من ربط `event_type`
2. **التعيينات الثانوية**: إدخالات تداخل المكشّف حيث ثقة التداخل ≥ 0.5

## نقاط التكامل

- **`FraudScoringService::calculateScoringBreakdown()`** — يستدعي `getSeverityWithDetectorBoost()`
- **مستمع `CalculateSignalSeverity`** — يستدعي `assignTaxonomy()` بعد التسجيل
- **`LineageTrackingService::recordAlertLineage()`** — يقرأ `taxonomy_assignments` لسجل السلسلة
- **`TaxonomyRegistrySeeder`** — يُدرج 13 إدخالًا قانونيًا؛ تشغيله أثناء `db:seed`
