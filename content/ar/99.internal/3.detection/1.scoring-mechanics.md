## دمج المخاطر المرجّح (v2.0 — الحالي)

اعتبارًا من v1.5.0، يُحسب درجة المخاطر النهائية بواسطة `WeightedRiskFusionEngine` الذي يجمع أربعة أبعاد تسجيل مستقلة:

| البُعد | الوزن | المصدر |
|---|---|---|
| السلوكي | **35%** | خط أنابيب NUFSS (تجميع سلسلة المكشّفات) |
| الشبكي | **40%** | `HotGraphService::getNeighborhoodRisk()` — 1 + 2 قفزة |
| السياقي | **15%** | مساهمات feature المحلل (جغرافي، زمني، جِدّة الجهاز) |
| التاريخي | **10%** | تاريخ مخاطر الكيان (نافذة متداولة 90 يومًا) |

**صيغة الدرجة المدمجة:**

```
fused_score = (behavioral × 0.35) + (network × 0.40) + (contextual × 0.15) + (historical × 0.10)
```

**تضخيم الرسم البياني** — يُطبَّق بعد الدمج:

- إذا `network_score > 0.7` و `behavioral_score > 0.5`: اضرب في `1.15`
- إذا كان أي جار بسَفَرَيْن لديه `risk_score > 0.9`: أضف `+0.05` ثابتة
- الدرجة المُضخَّمة محدودة بـ `1.0`

يُخزَّن `WeightedRiskScore` DTO الكامل في `alert_lineage` مع حقول لكل بُعد: `behavioral_score`, `network_score`, `contextual_score`, `historical_score`, `fused_risk_score`.

### مخاطر الشبكة (وزن 40%)

محسوبة بواسطة `HotGraphService::getNeighborhoodRisk(nodeId, hops=2)`:

```
NeighborhoodRiskResult {
    direct_neighbors: int,
    avg_risk: float,
    max_risk: float,
    high_risk_count: int,
    propagated_risk: float   ← يُستخدم كـ networkScore
}
```

تراجع القفزة: جيران القفزة الواحدة يساهمون بوزن `0.7`، القفزتان بـ `0.3`.

مفاتيح ذاكرة Redis المؤقتة: `graph:1hop:{node_id}`, `graph:2hop:{node_id}`. TTL: 15 دقيقة.

### معايرة العتبات

تُصنَّف الدرجات المدمجة في مستويات خطورة بواسطة `ThresholdCalibrationService`:

- للشركاء عتبات قابلة للتهيئة مخزنة في `partner_threshold_profiles`
- الافتراضيات: حرج ≥ 0.80، مرتفع ≥ 0.60، متوسط ≥ 0.40، منخفض < 0.40
- مضاعفات زمنية: `off_hours`, `weekend`, `salary_week` — تُطبَّق قبل التصنيف
- الحد التنظيمي: لا يمكن تصنيفه `منخفض` إذا كانت الدرجة المدمجة ≥ `regulatory_floor` (الافتراضي 0.35)

## خط أنابيب NUFSS (المكوّن السلوكي)

**Network-Unified Fraud Severity Score** يُغذّي البُعد السلوكي بـ 35%. يُحسب في `FraudScoringService`:

```
behavioral_score = base_risk × source_confidence × anomaly_factor
```

| المكوّن | المصدر | النطاق |
|---|---|---|
| `base_risk` | بحث Taxonomy Registry حسب `event_type` + boost المكشّف | 0.3 – 1.0 |
| `source_confidence` | حقل `source_confidence` للإشارة | 0.0 – 1.0 |
| `anomaly_factor` | مُضاعف `AnomalyDetectionService` | 1.0 – 1.5 |

### boost خطورة المكشّف

عندما تتداخل المكشّفات المُطلَقة مع `detectors_required` لإدخال في التصنيف، يتلقى `base_risk` boost تناسبيًا (حتى +0.10):

```php
$boost = min(0.10, $matchRatio * 0.10);
$baseSeverity += $boost;
// $matchRatio = count(intersection) / count(detectors_required)
```

المكشّفات الخمسة النشطة:

- `RapidVelocityDetector` — تردد المعاملات في نوافذ زمنية قصيرة
- `LargeOutlierTransactionDetector` — المبلغ > 3σ من تاريخ الكيان
- `SimSwapProximityDetector` — MSISDN مرتبط بتبادل SIM حديث
- `NewDeviceAccessDetector` — جهاز جديد لأول مرة للممثل
- `ImpossibleTravelDetector` — حركة جغرافية مستحيلة ضمن الوقت المنقضي

## تسجيل قواعد AML (Enterprise — علامة `risk_and_compliance`)

يُقيّم `TransactionMonitoringRulesService` 4 قواعد AML لكل إشارة ويحفظ سجلات `AmlTransactionFlag`:

| القاعدة | الكشف | مساهمة المخاطر |
|---|---|---|
| `structuring` | معاملات متعددة أقل قليلًا من عتبة الإبلاغ | مرتفعة |
| `velocity_breach` | عدد أو حجم المعاملات يتجاوز عتبة AML للشريك في النافذة | مرتفعة |
| `round_number` | المبلغ رقم مستدير مريب (1000، 5000، 10000) | متوسطة |
| `high_risk_jurisdiction` | `country_code` في القائمة الرمادية أو السوداء لـ FATF | مرتفعة |

علامات AML لا تُعدّل الدرجة المدمجة مباشرةً — تُنشئ سجلات `aml_transaction_flags` وقد تُطلق إنشاء SAR أو إجراءات سياسة ESCALATE.

## تاريخ مخاطر الكيان (المكوّن التاريخي — وزن 10%)

`HistoricalRiskService::getHistoricalScore(entity)`:

- يستعلم `fraud_entity_risk_histories` لآخر 90 يومًا
- يُعيد متوسطًا مُرجَّحًا متداولًا (0.0–1.0)
- يُستخدم كبُعد `historical_score` في الدمج المرجَّح

## التراجع الزمني (إشارات الكيانات التاريخية)

درجة المخاطر الإجمالية للكيان (مستقلة عن الدرجة المدمجة لكل إشارة) تستخدم تراجعًا أسيًا:

```
decay = e^(-0.1 × أيام_منذ_الحدث)
```

- **نصف العمر**: ~7 أيام
- **الحد الأقصى للعمر**: 90 يومًا (وزن فعّال صفر)
