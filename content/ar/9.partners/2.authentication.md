# المصادقة

تستخدم Protegey **مصادقة مفتاح API**.

::callout{icon="i-lucide-key" color="blue"}
**إدارة المفاتيح**: يمكنك توليد المفاتيح وإلغاؤها من [بوابة الشريك](https://app.protegey.com/settings/api-keys).
::

## رأس الطلب

يجب أن تتضمَّن جميع طلبات واجهة برمجة التطبيقات **المفتاح السري** في رأس `X-Centry-Key`.

```bash
curl -X GET https://api.protegey.com/v1/health \
  -H "X-Centry-Key: cen_live_sk_592834..."
```

## أنواع المفاتيح

| النوع             | البادئة      | الوصف                                               | الاستخدام                                                |
| ----------------- | ------------ | --------------------------------------------------- | -------------------------------------------------------- |
| **المفتاح السري** | `..._sk_...` | **سري**. يمنح وصولًا كاملًا لواجهة برمجة التطبيقات. | استدعاءات واجهة برمجة التطبيقات من جانب الخادم.          |
| **المفتاح العام** | `..._pk_...` | تعريف عام.                                          | تتبع جانب العميل (مستقبلًا) أو معرِّف المصادقة الأساسية. |

## دورة حياة المفتاح

### التوليد

تُولَّد المفاتيح بطريقة تشفيرية. يُعرض **المفتاح السري** **مرة واحدة فقط**.

- الصيغة: `cen_[env]_sk_[random_string]`
- مثال: `cen_live_sk_8f7d6a5...`

### التدوير

نوصي بتدوير المفاتيح كل 90 يومًا.

1. أنشئ مفتاحًا جديدًا في البوابة.
2. حدِّث متغيرات بيئة تطبيقك.
3. تحقَّق من عمل المفتاح الجديد.
4. ألغِ المفتاح القديم في البوابة.

### الإلغاء

إذا اشتبهت في اختراق مفتاح:

1. **فورًا** ألغِ المفتاح في بوابة الشريك.
2. سيُعطَّل فورًا أي جلسة نشطة تستخدم ذلك المفتاح.
3. تواصل مع [security@protegey.com](mailto:security@protegey.com) لطلب تدقيق في النشاط.

## قائمة السماح بعناوين IP

لطبقة أمان إضافية، يمكنك تقييد استخدام المفتاح على عناوين IP أو كتل CIDR محددة.

- قم بالتكوين في **الإعدادات > الأمان > قائمة السماح بعناوين IP**.
- ستُرفض الطلبات من عناوين IP غير المصرَّح بها برمز `403 Forbidden` حتى إذا كان مفتاح API صالحًا.

## رموز الخطأ

| الرمز              | المعنى                     | الإجراء                                              |
| ------------------ | -------------------------- | ---------------------------------------------------- |
| `401 Unauthorized` | مفتاح مفقود أو غير صالح    | تحقَّق من رأس `X-Centry-Key` الخاص بك.               |
| `403 Forbidden`    | مفتاح صالح لكن الإذن مرفوض | تحقَّق من قائمة السماح بعناوين IP أو نطاقات المفتاح. |
