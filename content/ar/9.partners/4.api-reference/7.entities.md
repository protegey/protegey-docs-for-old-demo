توفر واجهة برمجة تطبيقات استخبارات الكيانات (Entity Intelligence API) وصولاً برمجياً إلى ملفات تعريف كيانات الاحتيال (الفاعلون، الأجهزة، الحسابات) التي يتتبعها محرك الكشف في Protegey. تمثل الكيانات فاعلين يمكن تحديدهم (أرقام هواتف، عناوين بريد إلكتروني، بصمات أجهزة، إلخ) مشاركين في إشارات الاحتيال.

::callout{type="info"}
**قيد الوظيفة**: استخبارات الكيانات متاحة في خطط Professional وما فوق. **مستوى الوصول**: للقراءة فقط افتراضياً. تحديثات الحالة تتطلب ميزة `entity_intelligence` (خطط Business/Enterprise).
::

## المصادقة

تتطلب جميع نقاط نهاية استخبارات الكيانات مصادقة عبر رمز OAuth2 Bearer:

```bash
Authorization: Bearer YOUR_ACCESS_TOKEN
```

## حدود المعدل (Rate Limits)

- **قائمة الكيانات**: 60 طلباً في الدقيقة
- **عرض تفاصيل الكيان**: 120 طلباً في الدقيقة
- **تحديث حالة الكيان**: 30 طلباً في الدقيقة (مقيدة بميزة)
- **سجل المخاطر**: 60 طلباً في الدقيقة

---

## قائمة الكيانات (List Entities)

**GET** `/api/v1/partner/entities`

استرجاع قائمة مرتبة من كيانات الاحتيال التي يتم تتبعها لمنظمتك الشريكة مع خيارات تصفية وفرز متقدمة.

### معلمات الاستعلام

| المعلمة       | النوع   | الوصف                                                                        |
| ------------- | ------- | ---------------------------------------------------------------------------- |
| `entity_type` | string  | تصفية حسب النوع: `phone_number`, `email`, `device_fingerprint`, `ip_address` |
| `status`      | string  | تصفية حسب الحالة: `flagged`, `confirmed`, `false_positive`, `monitoring`     |
| `risk_level`  | string  | تصفية حسب المخاطر: `critical` (≥80), `high`, `medium`, `low`                 |
| `per_page`    | integer | العناصر لكل صفحة (الحد الأقصى: 100)                                          |

---

## عرض تفاصيل الكيان

**GET** `/api/v1/partner/entities/{uuid}`

استرجاع معلومات شاملة حول كيان احتيال محدد، بما في ذلك سجل الحالة، سجل المخاطر، التنبيهات ذات الصلة، وسجل المعاملات.

---

## تحديث حالة الكيان

**PUT** `/api/v1/partner/entities/{uuid}/status`

تحديث حالة الكيان بناءً على نتائج التحقيق. هذه نقطة النهاية **مقيدة بميزة** وتتطلب خطة Business أو Enterprise.

::callout{type="warning"}
**يتطلب تفعيل الميزة**: تتطلب نقطة النهاية هذه تفعيل ميزة `entity_intelligence` لمنظمتك الشريكة. مستخدمو خطة Professional لديهم وصول للقراءة فقط.
::

---

## سجل المخاطر (Risk History)

**GET** `/api/v1/partner/entities/{uuid}/risk-history`

استرجاع تطور درجة المخاطر لكيان معين بمرور الوقت. مفيد لتصور اتجاهات المخاطر وفهم عوامل تسجيل النقاط.

---

## إحصائيات الكيانات

**GET** `/api/v1/partner/entities/statistics`

استرجاع إحصائيات مجمعة حول الكيانات للمنظمة الشريكة.

---

## أنواع الكيانات

| نوع الكيان           | الوصف                    | تنسيق المعرف                                      |
| -------------------- | ------------------------ | ------------------------------------------------- |
| `phone_number`       | أرقام الهواتف            | رقم هاتف مُعمّى (يظهر كـ `024******`)             |
| `email`              | عناوين البريد الإلكتروني | بريد إلكتروني مُعمّى (يظهر كـ `j***@example.com`) |
| `device_fingerprint` | بصمات الأجهزة            | هاش بصمة الجهاز                                   |
| `ip_address`         | عناوين IP                | عنوان IP كامل أو جزئي                             |

---

## دورة حياة حالة الكيان

تتطور الكيانات عبر الحالات بناءً على نتائج التحقيق:
`monitoring` (مراقبة) ← `flagged` (مشار إليه) ← `confirmed` (مؤكد كاحتيال) أو `false_positive` (إيجابي كاذب).

---

## تفسير درجة المخاطر

تتراوح درجات المخاطر من 0 إلى 100:

| النطاق     | المستوى | التفسير                     |
| ---------- | ------- | --------------------------- |
| **80-100** | حرج     | ثقة عالية جداً بوجود احتيال |
| **60-79**  | عالٍ    | مؤشرات احتيال قوية          |
| **40-59**  | متوسط   | تم اكتشاف أنماط مشبوهة      |
| **0-39**   | منخفض   | مخاطر عادية أو ضئيلة        |

## تحليل مخاطر الجوار البياني

```http
GET /api/v1/partner/entities/{uuid}/graph
Authorization: Bearer {token}
```

يُعيد مقاييس مخاطر إجمالية لجوار الكيان ضمن قفزتين في الرسم البياني الساخن. استخدمه لفهم تعرض الكيان لمخاطر الشبكة دون تحميل الرسم البياني الكامل.

### الاستجابة

```json
{
  "data": {
    "entity_uuid": "ent_01HZ...",
    "direct_neighbors": 7,
    "second_degree_neighbors": 23,
    "avg_risk": 54.3,
    "max_risk": 91,
    "high_risk_count": 3,
    "propagated_risk": 67.2,
    "top_edge_types": ["shared_device", "shared_ip"]
  }
}
```

| الحقل | الوصف |
|-------|-------------|
| `direct_neighbors` | اتصالات القفزة الأولى |
| `second_degree_neighbors` | اتصالات القفزة الثانية (بدون احتساب مزدوج لاتصالات القفزة الأولى) |
| `avg_risk` | متوسط درجة المخاطر عبر جميع الجيران |
| `max_risk` | أعلى درجة مخاطر في الجوار |
| `high_risk_count` | الجيران بـ `risk_score > 80` |
| `propagated_risk` | مساهمة مخاطر الشبكة المحتسبة (تُستخدم في محرك الدمج) |
| `top_edge_types` | أكثر أنواع العلاقات شيوعًا في الجوار |

## تصوير الرسم البياني

```http
GET /api/v1/partner/entities/{uuid}/graph-visualization
Authorization: Bearer {token}
```

يُعيد بيانات الرسم البياني القوي مناسبةً للعرض في مكوّن تصوير الشبكة. اجتياز BFS حتى العمق 2، محدود بـ 200 عقدة.

### معلمات الاستعلام

| المعلمة | النوع | الوصف |
|-----------|------|-------------|
| `node_type[]` | array | التصفية لأنواع عقد محددة: `phone_number`، `device_fingerprint`، `ip_address`، `account_id` |
| `from` | datetime | تضمين الحواف التي رُئيت لأول مرة بعد هذا التاريخ فقط |
| `to` | datetime | تضمين الحواف التي رُئيت آخر مرة قبل هذا التاريخ فقط |

### الاستجابة

```json
{
  "data": {
    "nodes": [
      {
        "id": "a1b2c3d4****",
        "node_type": "device_fingerprint",
        "risk_score": 91,
        "depth": 1
      }
    ],
    "edges": [
      {
        "source": "ent_01HZ...",
        "target": "a1b2c3d4****",
        "edge_type": "shared_device",
        "weight": 0.95
      }
    ],
    "total_nodes": 31,
    "total_edges": 44,
    "depth": 2,
    "truncated": false
  }
}
```

::callout{type="warning"}
**الخصوصية — معرفات مُقنَّعة**: معرفات الكيانات الخارجية في استجابات الرسم البياني مُقنَّعة بأول 8 أحرف متبوعةً بـ `****` (مثلًا: `a1b2c3d4****`). يمنع ذلك استنتاج الكيانات بين الشركاء. يمكنك التعرف على كياناتك بمقارنة أول 8 أحرف بسجلات تجزئة HMAC المحلية لديك.
::

### قوة علاقة الحافة

| نطاق القوة | المعنى |
|----------------|---------|
| 0.9–1.0 | قوية جدًا — سمات مشتركة متعددة (مثلًا: نفس الجهاز + نفس IP) |
| 0.7–0.89 | قوية — سمة مشتركة واحدة بثقة عالية |
| 0.5–0.69 | متوسطة — سمة مشتركة مع قرب زمني |
| 0.3–0.49 | ضعيفة — ارتباط غير مباشر (تُستبعد ما دون 0.3) |
