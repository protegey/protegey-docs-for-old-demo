تسمح واجهة برمجة تطبيقات إدارة الحالات للشركاء بإنشاء وإدارة والتحقيق في حالات الاحتيال مباشرة من أنظمتهم. تمثل الحالات تحقيقات احتيال رسمية تبدأ عادةً من إشارات أو تنبيهات.

::callout{type="info"}
**قيد الوظيفة**: إدارة الحالات متاحة في خطط Professional وما فوق. الوصول إلى البيئة التجريبية (Sandbox) مشمول في جميع الخطط.
::

## المصادقة

تتطلب جميع نقاط نهاية إدارة الحالات مصادقة عبر رمز OAuth2 Bearer:

```bash
Authorization: Bearer YOUR_ACCESS_TOKEN
```

## حدود المعدل (Rate Limits)

- **قائمة الحالات**: 60 طلباً في الدقيقة
- **إنشاء/تحديث الحالات**: 30 طلباً في الدقيقة
- **إضافة ملاحظات/أدلة**: 120 طلباً في الدقيقة
- **عرض تفاصيل الحالة**: 120 طلباً في الدقيقة

---

## قائمة الحالات (List Cases)

**GET** `/api/v1/partner/cases`

استرجاع قائمة مرتبة من حالات الاحتيال الخاصة بالمنظمة الشريكة.

### معلمات الاستعلام

| المعلمة    | النوع   | الوصف                                                         |
| ---------- | ------- | ------------------------------------------------------------- |
| `status`   | string  | تصفية حسب الحالة: `open`, `in_progress`, `resolved`, `closed` |
| `priority` | string  | تصفية حسب الأولوية: `low`, `medium`, `high`, `critical`       |
| `per_page` | integer | العناصر لكل صفحة (الحد الأقصى: 100)                           |

---

## إنشاء حالة (Create Case)

**POST** `/api/v1/partner/cases`

إنشاء حالة تحقيق احتيال جديدة يدوياً.

### جسم الطلب (Request Body)

| الحقل         | النوع  | مطلوب | الوصف                                               |
| ------------- | ------ | ----- | --------------------------------------------------- |
| `title`       | string | نعم   | عنوان الحالة (الحد الأقصى 255 حرفاً)                |
| `description` | string | لا    | وصف مفصل للحالة                                     |
| `priority`    | string | نعم   | مستوى الأولوية: `low`, `medium`, `high`, `critical` |

---

## عرض تفاصيل الحالة

**GET** `/api/v1/partner/cases/{uuid}`

استرجاع معلومات مفصلة حول حالة محددة، بما في ذلك الحوادث ذات الصلة، الملاحظات، وتغييرات الحالة.

---

## تحديث الحالة

**PUT** `/api/v1/partner/cases/{uuid}`

تحديث حالة القضية، أو أولويتها، أو التعيين، أو إضافة ملاحظات.

---

## إضافة ملاحظة

**POST** `/api/v1/partner/cases/{uuid}/notes`

إضافة ملاحظة تحقيق إلى حالة.

---

## إرفاق أدلة (Attach Evidence)

**POST** `/api/v1/partner/cases/{uuid}/evidence`

إرفاق أدلة داعمة للقضية (لقطات شاشة، مستندات، سجلات، إلخ).

::callout{type="info"}
**أنواع الملفات المدعومة**: الصور (PNG, JPG, GIF)، المستندات (PDF, DOCX, XLSX)، السجلات (TXT, LOG, JSON)، الأرشيف (ZIP).
::

---

## إنشاء حالة من إشارة (Create Case from Signal)

**POST** `/api/v1/partner/cases/from-signal/{signalId}`

إنشاء حالة احتيال مباشرة من إشارة/معاملة. هذا هو سير العمل الموصى به لتصعيد الإشارات المشبوهة إلى تحقيقات رسمية.

---

## دورة حياة الحالة (Status Lifecycle)

تتبع الحالات دورة حياة محددة:
`open` (مفتوحة) ← `in_progress` (قيد المعالجة) ← `resolved` (تم الحل) ← `closed` (مغلقة).

| الحالة          | الوصف                                         |
| --------------- | --------------------------------------------- |
| **open**        | تم إنشاء الحالة، في انتظار التعيين أو الفرز.  |
| **in_progress** | التحقيق جارٍ بنشاط.                           |
| **resolved**    | تم حل المشكلة، في انتظار التأكيد النهائي.     |
| **closed**      | تم إغلاق الحالة رسمياً، لا مزيد من الإجراءات. |

---

## مستويات الأولوية

| الأولوية     | حالة الاستخدام                    |
| ------------ | --------------------------------- |
| **critical** | احتيال نشط جارٍ، تأثير مالي كبير. |
| **high**     | احتيال مشتبه به، مخاطر كبيرة.     |
| **medium**   | احتيال محتمل، مخاطر متوسطة.       |
| **low**      | شذوذ طفيف، مخاطر منخفضة.          |
