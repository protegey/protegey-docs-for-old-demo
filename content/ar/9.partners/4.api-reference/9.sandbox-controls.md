توفر واجهة برمجة تطبيقات عناصر التحكم في البيئة التجريبية (Sandbox Controls API) وصولاً برمجياً لإدارة البيئة التجريبية، مما يسمح لك بإعادة تعيين بيانات البيئة التجريبية، وتوليد إشارات تجريبية، وتشغيل محاكاة للاحتيال متعددة الخطوات لاختبار والتحقق من التكامل.

::callout{type="info"}
**للبيئة التجريبية فقط**: جميع نقاط النهاية في هذه الواجهة **حصرية للبيئة التجريبية (Sandbox)**. ستعيد `403 Forbidden` إذا تم استدعاؤها في بيئة الإنتاج. مستوى الوصول: **قراءة/كتابة** (متاح في جميع الخطط).
::

## المصادقة

تتطلب جميع نقاط نهاية التحكم في البيئة التجريبية مصادقة عبر رمز OAuth2 Bearer:

```bash
Authorization: Bearer YOUR_ACCESS_TOKEN
X-Centry-Environment: sandbox
```

::callout{type="warning"}
**رأس البيئة مطلوب**: يجب عليك تعيين البيئة صراحةً إلى `sandbox` باستخدام رأس `X-Centry-Environment` أو معلمة الاستعلام `?environment=sandbox`. لن تعمل نقاط نهاية التحكم في البيئة التجريبية في بيئة الإنتاج.
::

## حدود المعدل (Rate Limits)

- **إعادة تعيين البيئة التجريبية**: 10 طلبات في الساعة
- **توليد إشارات تجريبية**: 3 طلبات في الساعة
- **قائمة القوالب**: 60 طلباً في الدقيقة

## إعادة تعيين البيئة التجريبية (Reset Sandbox)

**POST** `/api/v1/partner/sandbox/reset`

إعادة تعيين بيانات البيئة التجريبية مع تحكم دقيق في البيانات التي يتم حذفها.

### جسم الطلب (Request Body)

| الحقل               | النوع   | الوصف                                        |
| ------------------- | ------- | -------------------------------------------- |
| `reset_signals`     | boolean | حذف جميع إشارات البيئة التجريبية             |
| `reset_entities`    | boolean | حذف جميع كيانات الاحتيال في البيئة التجريبية |
| `reset_alerts`      | boolean | حذف جميع تنبيهات البيئة التجريبية            |
| `preserve_api_keys` | boolean | الاحتفاظ بمفاتيح API (موصى به)               |

::callout{type="danger"}
**عملية غير قابلة للتراجع**: إعادة تعيين البيئة التجريبية دائمة ولا يمكن التراجع عنها. لا يمكن استعادة البيانات المحذوفة. استخدمها بحذر.
::

## توليد إشارات تجريبية (Generate Demo Signals)

**POST** `/api/v1/partner/sandbox/generate-demo-signals`

توليد إشارات تجريبية واقعية من قوالب محددة مسبقاً لاختبار قواعد كشف الاحتيال وسير عمل إدارة الحالات.

### جسم الطلب (Request Body)

| الحقل      | النوع   | مطلوب | الوصف                                              |
| ---------- | ------- | ----- | -------------------------------------------------- |
| `template` | string  | نعم   | اسم القالب (مثلاً: `transaction/account_takeover`) |
| `count`    | integer | لا    | عدد الإشارات المراد توليدها (1-100)                |

---

## قائمة القوالب (List Templates)

**GET** `/api/v1/partner/sandbox/templates`

استرجاع قائمة بجميع قوالب الإشارات المتاحة لتوليد الإشارات التجريبية.
