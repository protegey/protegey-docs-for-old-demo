# مواضيع الدعم

توفر واجهة برمجة تطبيقات مواضيع الدعم قناةً للمراسلة داخل المنصة بين مؤسستك وفريق دعم Protegey. تُحفظ المواضيع عبر الجلسات، وتدعم إرفاق الملفات، وتُسلَّم الرسائل في الوقت الفعلي عبر WebSocket.

::callout{type="info"}
مواضيع الدعم مرتبطة بحساب شريكك. يتشارك جميع الوكلاء وأعضاء فريقك صندوقًا واحدًا للمواضيع.
::

---

## نقاط النهاية

| الطريقة | المسار | الوصف |
|--------|------|-------------|
| `GET` | `/api/v1/partner/support/threads` | عرض قائمة مواضيع الدعم |
| `POST` | `/api/v1/partner/support/threads` | إنشاء موضوع جديد |
| `GET` | `/api/v1/partner/support/threads/{uuid}` | عرض تفاصيل الموضوع مع جميع رسائله |
| `POST` | `/api/v1/partner/support/threads/{uuid}/messages` | إضافة رسالة إلى موضوع |
| `GET` | `/api/v1/partner/support/attachments/{uuid}` | تنزيل مرفق |

## عرض قائمة المواضيع

```http
GET /api/v1/partner/support/threads
Authorization: Bearer {token}
```

### معلمات الاستعلام

| المعلمة | النوع | الوصف |
|-----------|------|-------------|
| `status` | string | التصفية حسب الحالة: `open`، `pending`، `closed` |
| `subject` | string | التصفية حسب فئة الموضوع |
| `per_page` | integer | النتائج لكل صفحة (الافتراضي: 20، الحد الأقصى: 100) |
| `page` | integer | رقم الصفحة |

### الاستجابة

```json
{
  "data": [
    {
      "uuid": "thr_01HZ9K2M4N5P6Q7R8S9T0UV1WX",
      "subject": "technical_issue",
      "title": "Signal ingestion 422 errors after rate limit window",
      "status": "open",
      "priority": "high",
      "message_count": 4,
      "unread_count": 1,
      "context_type": null,
      "context_id": null,
      "created_at": "2026-03-15T10:22:00Z",
      "last_message_at": "2026-03-15T14:47:00Z"
    }
  ],
  "meta": {
    "current_page": 1,
    "per_page": 20,
    "total": 3
  }
}
```

## إنشاء موضوع

```http
POST /api/v1/partner/support/threads
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

### جسم الطلب

| الحقل | النوع | مطلوب | الوصف |
|-------|------|----------|-------------|
| `subject` | string | ✓ | فئة موضوع الدعم (راجع القائمة أدناه) |
| `title` | string | ✓ | ملخص مختصر (255 حرفًا كحد أقصى) |
| `message` | string | ✓ | نص الرسالة الأولى (10,000 حرف كحد أقصى) |
| `priority` | string | | `low`، `normal`، `high`، `urgent` — الافتراضي `normal` |
| `context_type` | string | | `case` أو `alert` — يربط الموضوع بمورد محدد |
| `context_id` | string | | UUID للحالة أو التنبيه المرتبط |
| `attachments[]` | file | | حتى 5 ملفات لكل رسالة (انظر قواعد المرفقات) |

### تعداد فئات الموضوع

| القيمة | حالة الاستخدام |
|-------|----------|
| `technical_issue` | أخطاء API، إخفاقات التكامل، السلوك غير المتوقع |
| `signal_question` | أسئلة حول إشارات محددة أو نتائج التسجيل |
| `integration_support` | الإعداد الأولي، إعداد SDK، تكوين webhook |
| `billing` | الاشتراك، الفواتير، تغييرات الخطة |
| `other` | أي موضوع غير مشمول أعلاه |

### مثال على الطلب

```bash
curl -X POST https://api.protegey.com/api/v1/partner/support/threads \
  -H "Authorization: Bearer $TOKEN" \
  -F "subject=technical_issue" \
  -F "title=Signal ingestion returning 422 after UFES schema validation" \
  -F "message=We are consistently getting 422 responses when submitting signals with nested device metadata. The error references ufes_version but our payload matches the v2 schema." \
  -F "priority=high" \
  -F "attachments[]=@/tmp/error-payload.json"
```

### الاستجابة

    "uuid": "thr_01HZ9K2M4N5P6Q7R8S9T0UV1WX",

    "priority": "high",

    "context_id": null,
    "created_at": "2026-03-16T09:00:00Z",
    "messages": [
      {
        "uuid": "msg_01HZ9K2M4N5P6Q7R8S9T0UV1WY",
        "body": "We are consistently getting 422 responses...",
        "sender_type": "partner",
        "sender_name": "Ada Boateng",
        "attachments": [
          {
            "uuid": "att_01HZ9K2M4N5P6Q7R8S9T0UV1WZ",

## إضافة رسالة

```http
POST /api/v1/partner/support/threads/{uuid}/messages
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

يضيف ردًا إلى موضوع قائم. إذا كان الموضوع بحالة `closed`، فإن إرسال رسالة يُعيد فتحه تلقائيًا.

### جسم الطلب

| الحقل | النوع | مطلوب | الوصف |
|-------|------|----------|-------------|
| `message` | string | ✓ | نص الرسالة (10,000 حرف كحد أقصى) |
| `attachments[]` | file | | حتى 5 ملفات لكل رسالة |

### الاستجابة

```json
{
  "data": {
    "uuid": "msg_01HZ9K2M4N5P6Q7R8S9T0UV1BB",
    "body": "Confirmed, removing the empty string fixed it. Thank you.",
    "sender_type": "partner",
    "sender_name": "Ada Boateng",
    "attachments": [],
    "created_at": "2026-03-16T12:10:00Z"
  }
}
```

## تنزيل مرفق

```http
GET /api/v1/partner/support/attachments/{uuid}
Authorization: Bearer {token}
```

يُعيد المرفق كتدفق ثنائي. المرفقات مقيّدة بنطاق الشريك — لا يمكنك تنزيل مرفقات تخص موضوع شريك آخر.

| رأس الاستجابة | القيمة |
|----------------|-------|
| `Content-Type` | نوع MIME الأصلي |
| `Content-Disposition` | `attachment; filename="original-name.ext"` |
| `Content-Length` | حجم الملف بالبايت |

---

## قواعد المرفقات

| القاعدة | الحد |
|------|-------|
| الملفات لكل رسالة | 5 |
| الحجم الأقصى للملف | 10 ميغابايت لكل ملف |
| الأنواع المسموح بها | `jpg`، `png`، `gif`، `webp`، `pdf`، `txt` |
| التخزين | مشفَّر أثناء التخزين، مع تسجيل الوصول، وحذف تلقائي بعد 180 يومًا |

## التحديثات الفورية

تبثّ مواضيع الدعم الرسائل الجديدة عبر WebSocket بواسطة [Laravel Reverb](https://reverb.laravel.com/). اشترك في القناة الخاصة بالموضوع لاستقبال الرسائل فور وصولها دون الحاجة إلى الاستطلاع.

```javascript
import Echo from 'laravel-echo';

const echo = new Echo({ broadcaster: 'reverb', ... });

echo.private(`support.${threadUuid}`)
    .listen('.MessageCreated', (event) => {
        console.log('New message:', event.message);
    });
```

### الأحداث

| الحدث | الحمولة |
|-------|---------|
| `.MessageCreated` | `{ message: { uuid, body, sender_type, sender_name, created_at } }` |
| `.ThreadStatusChanged` | `{ status: 'open' \| 'pending' \| 'closed' }` |

## رموز الخطأ

| الرمز | المعنى |
|------|---------|
| `422` | فشل التحقق — راجع كائن `errors` |
| `403` | الموضوع لا ينتمي إلى حسابك |
| `404` | الموضوع أو المرفق غير موجود |
| `413` | المرفق يتجاوز 10 ميغابايت |
| `415` | نوع الملف غير مدعوم |
| `429` | تجاوز حد المعدل |
