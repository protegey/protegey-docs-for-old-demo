تتيح لك واجهة برمجة تطبيقات KYB (اعرف عميلك التجاري) جمع طلبات العملاء التجاريين ومراجعتها وفرزها من حيث المخاطر عبر استبيانات قابلة للتخصيص. يُنشئ الشركاء نماذج استقبال، ويُرسلون روابط دعوة موقَّعة، ويتخذون قرارات الموافقة — مع تشغيل فرز العقوبات وقواعد بيانات الأشخاص المعرَّضين سياسيًا (PPE) تلقائيًا عند الموافقة.

::callout{icon="i-lucide-building-2" color="blue"}
**الصلاحيات المطلوبة**: `kyb.invite` لإرسال الدعوات · `kyb.review` للبت في الطلبات · `kyb.manage` لبناء الاستبيانات. جميع الصلاحيات الثلاث مضمَّنة في دور الشريك الافتراضي.
::

---

## إدارة الاستبيانات

الاستبيانات نماذج استقبال مُصدَّرة بإصدارات، تتألف من أقسام وأسئلة مكتوبة. يُقفَل الاستبيان **تلقائيًا** فور إرسال أول دعوة — وبعد ذلك، استنسخه لإجراء تعديلات.

### عرض الاستبيانات

يُعيد استبيانات الشريك مع أي قوالب عالمية نشطة.

```http
GET /api/v1/partner/kyb/questionnaires
Authorization: Bearer {token}
```

### الحصول على استبيان

يُعيد الاستبيان مع قائمة أسئلته الكاملة.

```http
GET /api/v1/partner/kyb/questionnaires/{uuid}
Authorization: Bearer {token}
```

### إنشاء استبيان

```http
POST /api/v1/partner/kyb/questionnaires
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "title": "استبيان إدماج الشركاء الماليين",
  "version": "1.0",
  "is_default": false,
  "document_requirements": [
    { "document_type": "certificate_of_incorporation", "is_required": true },
    { "document_type": "aml_policies_and_procedures", "is_required": true }
  ],
  "questions": [
    {
      "section": "هوية الشركة",
      "order_index": 1,
      "type": "text",
      "label": "الاسم التجاري المسجَّل",
      "is_required": true,
      "is_screening_identifier": true
    },
    {
      "section": "هوية الشركة",
      "order_index": 2,
      "type": "boolean",
      "label": "هل يمتلك أي شخص أكثر من 25٪ من الشركة؟",
      "is_required": true
    }
  ]
}
```

**أنواع الأسئلة:** `text` · `textarea` · `boolean` · `select` · `multi_select` · `number` · `date`

**العرض الشرطي** — لا يظهر السؤال إلا عند استيفاء جميع `conditions`:

| الحقل | الوصف |
|---|---|
| `question_uuid` | UUID السؤال المتحكِّم |
| `operator` | `eq` (يساوي) · `neq` (لا يساوي) · `truthy` (أي قيمة غير فارغة/خاطئة) |
| `value` | مطلوب لـ `eq` و`neq`؛ يُحذف لـ `truthy` |

::callout{type="warning"}
ضع علامة `"is_screening_identifier": true` على سؤال **واحد بالضبط** في كل استبيان. تُستخدَم إجابته كاسم الشركة لفرز AML عند الموافقة.
::

### تحديث استبيان

مسموح به فقط إذا كان `is_locked: false`. يُعيد `409 Conflict` إذا كان مقفلًا.

```http
PUT /api/v1/partner/kyb/questionnaires/{uuid}
Authorization: Bearer {token}
```

### استنساخ استبيان

```http
POST /api/v1/partner/kyb/questionnaires/{uuid}/clone
Authorization: Bearer {token}
```

## إدارة الدعوات

### عرض الدعوات

```http
GET /api/v1/partner/kyb/invites
Authorization: Bearer {token}
```

**حالات الدعوة:**

| الحالة | الوصف |
|---|---|
| `pending` | أُرسلت، لم تُفتح بعد |
| `opened` | نقر المتقدِّم على الرابط |
| `in_progress` | تمت حفظ إجابة واحدة على الأقل |
| `submitted` | تم تقديم الطلب |
| `expired` | انقضت نافذة 30 يومًا دون تقديم |

### إرسال دعوة

```http
POST /api/v1/partner/kyb/invites
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "applicant_email": "cfo@acme-fintech.com",
  "applicant_name": "كوامي منساه",
  "questionnaire_uuid": "q_01HZKJ..."
}
```

احذف `questionnaire_uuid` لاستخدام الاستبيان الافتراضي النشط. يُقفَل الاستبيان تلقائيًا عند إرسال الدعوة. الروابط للاستخدام مرة واحدة فقط وتنتهي صلاحيتها بعد 30 يومًا.

## إدارة الطلبات

### عرض الطلبات

```http
GET /api/v1/partner/kyb/applications
Authorization: Bearer {token}
```

**حالات الطلب:**

| الحالة | الوصف |
|---|---|
| `draft` | بدأ المتقدِّم لكنه لم يُكمل |
| `submitted` | استُلم الطلب؛ في انتظار المراجعة |
| `under_review` | فتح المراجع الطلب |
| `more_info_required` | طلب المراجع توضيحات؛ يمكن للمتقدِّم إعادة التقديم |
| `approved` | مُعتمَد؛ أُنشئ الكيان في الرسم البياني |
| `rejected` | مرفوض (نهائي) |

### الحصول على تفاصيل الطلب

```http
GET /api/v1/partner/kyb/applications/{uuid}
Authorization: Bearer {token}
```

### البت في الطلب

يتطلب صلاحية `kyb.review`.

```http
POST /api/v1/partner/kyb/applications/{uuid}/decide
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "decision": "approved",
  "notes": "تم التحقق من جميع المستندات. تم إنشاء الكيان للمراقبة."
}
```

قيم `decision`: `approved` · `rejected` · `more_info_required`

::callout{icon="i-lucide-shield" color="amber"}
**يعمل فرز المخاطر عند الموافقة.** يُفرَز اسم الشركة ضد قوائم العقوبات وقواعد بيانات PPE. إذا كان `risk_score > 0.75` أو `is_pep = true` أو وجدت مطابقة للعقوبات، يُنشأ ملف تدقيق معزَّز (EDD) تلقائيًا.
::

يُعدّ `approved` و`rejected` **نهائيَّين** — لا يمكن تغيير القرار لاحقًا.

### تنزيل مستند

```http
GET /api/v1/partner/kyb/applications/{uuid}/documents/{document}/download
Authorization: Bearer {token}
```

يُعيد رابط S3 موقَّعًا محدود المدة.

## نقاط نهاية بوابة المتقدِّم

تستخدم هذه النقاط **مصادقة الرمز المميز** — لا يلزم bearer OAuth. رمز الدعوة مضمَّن في الرابط.

### تحميل حالة الطلب

```http
GET /api/v1/kyb/apply/{token}
```

### حفظ التقدُّم

يحفظ الإجابات بصورة تدريجية.

```http
POST /api/v1/kyb/apply/{token}/progress
Content-Type: application/json
```

### رفع مستند

```http
POST /api/v1/kyb/apply/{token}/documents
Content-Type: multipart/form-data
```

| الحقل | النوع | الوصف |
|---|---|---|
| `file` | ملف | الحد الأقصى 10 ميغابايت. المقبول: pdf، jpg، png، docx |
| `document_type` | نص | انظر جدول أنواع المستندات |

### حذف مستند

```http
DELETE /api/v1/kyb/apply/{token}/documents/{document}
```

### تقديم الطلب

```http
POST /api/v1/kyb/apply/{token}/submit
```

## أنواع المستندات

| النوع | التسمية | مطلوب عادةً |
|---|---|---|
| `certificate_of_incorporation` | عقد التأسيس | نعم |
| `memorandum_and_articles` | النظام الأساسي للشركة | نعم |
| `owner_id` | هوية المالك الفعلي | نعم |
| `aml_policies_and_procedures` | سياسات وإجراءات مكافحة غسل الأموال | نعم |
| `certificate_of_good_standing` | شهادة حسن السيرة | لا |
| `organisational_chart` | الهيكل التنظيمي | لا |
| `proof_of_address_business` | إثبات عنوان الشركة | لا |
| `financial_statements` | البيانات المالية (آخر سنتين) | لا |
| `payment_services_license` | ترخيص خدمات الدفع | لا |
| `aml_kyc_review` | مراجعة مستقلة AML/KYC | لا |
| `other` | مستند داعم آخر | لا |

## الصلاحيات

| الصلاحية | من يحتاجها | الإجراءات |
|---|---|---|
| `kyb.invite` | مديرو العلاقات، مسؤولو الامتثال | إرسال الدعوات، عرض الدعوات والطلبات |
| `kyb.review` | مراجعو الامتثال | اتخاذ القرارات، تنزيل المستندات |
| `kyb.manage` | المسؤولون الإداريون | إنشاء الاستبيانات وتحديثها واستنساخها |
