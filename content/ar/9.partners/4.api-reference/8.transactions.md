توفر واجهة برمجة تطبيقات مراقبة المعاملات (Transaction Monitoring API) نقاط نهاية شاملة لمراجعة إشارات الاحتيال، واتخاذ القرارات، وتحليل الأنماط، وتتبع مقاييس الأداء. هذه هي الواجهة الأساسية لمحللي الاحتيال لإدارة سير عمل مراجعة المعاملات.

::callout{icon="i-lucide-shield-check" color="blue"}
**المراقبة في الوقت الفعلي**: تدعم جميع نقاط النهاية الاستطلاع في الوقت الفعلي مع تصفية وترقيم صفحات مُحسّن لتدفقات المعاملات كبيرة الحجم.
::

---

## نظرة عامة

### القدرات الأساسية

- **خلاصة المعاملات**: مراقبة الإشارات في الوقت الفعلي مع خيارات تصفية واسعة.
- **اتخاذ القرار**: قرارات المعاملات الفردية والجماعية.
- **التحليلات**: تحليلات وتوجهات شاملة للاحتيال.
- **تتبع الأداء**: مقاييس أداء المراجع والفريق.

### المصادقة

تتطلب جميع نقاط النهاية مصادقة عبر رمز OAuth2 Bearer:

```bash
Authorization: Bearer YOUR_ACCESS_TOKEN
```

---

## نقاط النهاية (Endpoints)

### قائمة المعاملات

**GET** `/api/v1/transaction-monitoring`

استرجاع خلاصة معاملات مرقمة مع قدرات تصفية وبحث واسعة.

### عرض تفاصيل المعاملة

**GET** `/api/v1/transaction-monitoring/{signalId}`

استرجاع معلومات مفصلة لإشارة معاملة محددة.

### اتخاذ قرار

**POST** `/api/v1/transaction-monitoring/{signalId}/decide`

اتخاذ قرار بشأن معاملة (موافقة، رفض، إشارة للمراجعة).

| الحقل      | الوصف                                                        |
| ---------- | ------------------------------------------------------------ |
| `decision` | القرار: `approved`, `declined`, `flagged`, `mark_suspicious` |
| `reason`   | مبرر القرار (10-500 حرف)                                     |

### اتخاذ قرار جماعي (Bulk Decision)

**POST** `/api/v1/transaction-monitoring/bulk-decide`

اتخاذ قرارات بشأن معاملات متعددة في وقت واحد (ميزة Enterprise).

## التحليلات (Analytics)

### إحصائيات عامة

**GET** `/api/v1/transaction-monitoring/analytics`

استرجاع التحليلات والإحصائيات العامة لمراقبة المعاملات.

### التحليلات الزمنية

**GET** `/api/v1/transaction-monitoring/analytics/time-series`

الحصول على بيانات السلاسل الزمنية لتحليل التوجهات (ساعة، يوم، أسبوع، شهر).

## مجموعة التحليلات

توفر مجموعة التحليلات 14 نقطة نهاية لمراقبة الاتجاهات والتوزيعات وأداء الفريق. تقبل جميع نقاط النهاية معلمتَي التاريخ `from` و`to` بصيغة ISO 8601. النطاق الافتراضي: آخر 30 يومًا.

### نظرة عامة

| نقطة النهاية | الوصف |
|----------|-------------|
| `GET /analytics/time-series` | أحجام المعاملات اليومية/بالساعة + متوسطات درجات المخاطر |
| `GET /analytics/comparison` | مقارنة فترة بأخرى (الحالية مقابل السابقة) |
| `GET /analytics/distribution` | مدرج تكراري لدرجات المخاطر (حاويات 10 نقاط) |
| `GET /analytics/decision-time` | توزيع وقت اتخاذ القرار (p50، p90، p99) |
| `GET /analytics/heatmap` | مصفوفة نشاط 7×24 (يوم × ساعة، الحجم + متوسط المخاطر) |
| `GET /analytics/risk-factors` | أبرز الكواشف وفئات التصنيف وعلامات AML |
| `GET /analytics/performance` | إحصاءات قائمة الانتظار: العدد المعلق، متوسط العمر، معدل خرق اتفاقية مستوى الخدمة |
| `GET /analytics/reviewer-performance` | مقاييس القرار لكل محلل (Business/Enterprise) |

جميع نقاط نهاية التحليلات تستخدم المسار الأساسي `/api/v1/transaction-monitoring/analytics/`.

### السلاسل الزمنية

```http
GET /api/v1/transaction-monitoring/analytics/time-series
```

**المعلمات**: `from`، `to`، `granularity` (`hour`/`day`/`week`)، `risk_level`

يُعيد الأعداد اليومية والأعداد المُعلَّمة ومتوسط درجة المخاطر مع تفصيل مستويات المخاطر.

### المقارنة

```http
GET /api/v1/transaction-monitoring/analytics/comparison
```

**المعلمات**: `current_from`، `current_to`، `prior_from`، `prior_to`

يُعيد مقاييس الفارق: تغيير الحجم %، تغيير معدل العلامات، تغيير متوسط المخاطر.

### التوزيع

```http
GET /api/v1/transaction-monitoring/analytics/distribution
```

يُعيد مدرجًا تكراريًا من 10 حاويات لدرجات المخاطر (0–9، 10–19، ... 90–100) إضافةً إلى `mean`، `median`، `p95`، `p99`.

### وقت اتخاذ القرار

```http
GET /api/v1/transaction-monitoring/analytics/decision-time
```

يُعيد `p50_seconds`، `p90_seconds`، `p99_seconds`، `mean_seconds`، `reviewed_count`.

### الخريطة الحرارية

```http
GET /api/v1/transaction-monitoring/analytics/heatmap
```

يُعيد مصفوفة 7×24 (يوم الأسبوع × ساعة اليوم) مع `count` و`avg_risk` لكل خلية. يحدد نوافذ الوقت عالية المخاطر.

### عوامل المخاطر

```http
GET /api/v1/transaction-monitoring/analytics/risk-factors
```

يُعيد `top_detectors`، `top_taxonomy`، `top_aml_flags` — كل منها مصفوفة من كائنات `{name, count, pct}`.

### الأداء (إحصاءات قائمة الانتظار)

```http
GET /api/v1/transaction-monitoring/analytics/performance
```

يُعيد `pending_review`، `avg_queue_age_seconds`، `sla_breach_rate`، `throughput_per_hour`.

### أداء المراجعين

```http
GET /api/v1/transaction-monitoring/analytics/reviewer-performance
```

::callout{type="info"}
يتطلب خطة **Business** أو **Enterprise**.
::

يُعيد لكل مراجع: `decisions_made`، `avg_review_seconds`، `approve_rate`، `reject_rate`، `escalation_rate`.
