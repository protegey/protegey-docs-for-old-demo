إذا لم تكن لديك بيانات إشارات حقيقية بعد، يمكنك استخدام **مولِّد الإشارات التجريبية** لتعبئة بيئة اختبارك بسيناريوهات واقعية.

## كيفية توليد الإشارات

1. انتقل إلى **الاختبار > الإشارات التجريبية** في بوابة الشريك.
2. اختر **قالب إشارة** (مثلاً: الاستيلاء على الحساب).
3. اختر **ضبط إعدادات الحجم** (5 أو 20 أو 100 إشارة).
4. انقر على **توليد الإشارات**.

## القوالب المتاحة

| القالب | السيناريو |
|--------|-----------|
| **الاستيلاء على الحساب** | يحاكي عمليات تسجيل دخول مشبوهة ونشاطًا غير مصرح به على الحساب. |
| **بيانات مالية مسروقة** | يحاكي معاملات باستخدام وسائل دفع مخترقة. |
| **هوية اصطناعية** | يحاكي الإعداد ببيانات هوية مزورة أو محرَّفة. |
| **فشل التحقق من رقم الهاتف** | يحاكي إخفاقات متكررة في تدفقات 2FA أو KYC. |
| **تقرير احتيال خارجي** | يحاكي التقارير الواردة من شبكات شركاء خارجية. |

## تحديد ملف المخاطر الديناميكي

يستخدم مولِّد الإشارات التجريبية **تحديد ملف المخاطر الديناميكي** لإنشاء سيناريوهات اختبار واقعية. يُخصَّص لكل إشارة تلقائيًا ملف مخاطر يؤثر في متغيرات متعددة:

### توزيع المخاطر

| مستوى المخاطر | الاحتمالية | الخصائص |
|--------------|------------|---------|
| **حرج** | 10% | مبالغ عالية ($15k-$50k)، معاملات عابرة للحدود، ثقة عالية (0.85-0.99) |
| **مرتفع** | 20% | مبالغ قريبة من الحدود ($9k-$14k)، عابرة للحدود، ثقة متوسطة إلى عالية (0.75-0.90) |
| **متوسط** | 30% | مبالغ معتدلة ($1k-$5k)، معاملات محلية، ثقة متوسطة (0.50-0.75) |
| **منخفض** | 40% | مبالغ صغيرة ($10-$500)، معاملات محلية، ثقة عالية (0.80-0.99) |

### كيفية عمل تحديد ملف المخاطر

يتجاوز النظام تلقائيًا متغيرات القالب بناءً على ملف المخاطر المحدد:

**مبالغ المعاملات:**
- **حرج**: $15,000 - $50,000 (يُشغِّل كاشف شذوذ المبلغ)
- **مرتفع**: $9,000 - $14,000 (قريب من حدود العتبة)
- **متوسط**: $1,000 - $5,000 (النطاق الطبيعي)
- **منخفض**: $10 - $500 (معاملات صغيرة نموذجية)

**المؤشرات الجغرافية:**
- **حرج/مرتفع**: معاملات عابرة للحدود (رمز بلد مختلف عن بلد شريكك)
- **متوسط/منخفض**: معاملات محلية (نفس بلد الشريك)

**ثقة المصدر:**
- **حرج**: 0.85 - 0.99 (ثقة عالية بأنها احتيال)
- **مرتفع**: 0.75 - 0.90 (ثقة مرتفعة معتدلة)
- **متوسط**: 0.50 - 0.75 (غير محدد)
- **منخفض**: 0.80 - 0.99 (ثقة عالية بأنها شرعية)

::callout{type="info"}
**لماذا هذا مهم**: يضمن نظام تحديد ملف المخاطر وجود مزيج واقعي من إشارات الاحتيال في بيئة اختبارك، مما يتيح لك اختبار عتبات التنبيه وأولوية الحالات وسير عمل التحقيق في ظروف واقعية.
::

## تجاوزات المتغيرات

بينما يطبِّق النظام تلقائيًا تحديد ملف المخاطر، يمكنك تجاوز متغيرات بعينها عند استخدام API مباشرةً:

```bash
POST /api/v1/partner/sandbox/generate-demo-signals
{
  "template": "account_takeover",
  "count": 10,
  "overrides": {
    "TRANSACTION_AMOUNT": 25000,
    "PHONE_NUMBER": "+233240000000",
    "COUNTRY_CODE": "GH"
  }
}
```

## حدود المعدل

لضمان استقرار النظام، يقتصر توليد الإشارات التجريبية على **3 طلبات في الساعة** لكل شريك عبر نقطة النهاية HTTP. للاختبار بحجم أكبر، استخدم أداة [محاكي API](./api-simulator) عبر سطر الأوامر أو ميزة [محاكاة السيناريوهات](./scenarios).

## عرض النتائج

بعد التوليد، ستظهر الإشارات في **سجلات الإشارات** مع علامة مصدر `Simulator` وبيانات وصفية `generated_by: centry_demo`. يمكنك تصفية السجلات حسب البيئة والمصدر لعزل البيانات التجريبية.

### البيانات الوصفية للإشارة
تتضمن كل إشارة تجريبية بيانات وصفية للتتبع:
```json
{
  "metadata": {
    "generated_by": "centry_demo",
    "demo_batch": 1738598400,
    "demo_sequence": 1,
    "demo_risk_intent": "critical"
  }
}
```

يتيح لك ذلك:
- تصفية الإشارات التجريبية عن بيانات الاختبار الحقيقية
- تتبع دفعات توليد الإشارات
- تحليل دقة توزيع المخاطر
- تصحيح سيناريوهات بعينها
