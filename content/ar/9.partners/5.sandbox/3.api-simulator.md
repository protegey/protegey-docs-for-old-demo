للاختبار المتقدم والتحقق من الأداء، نوفر محاكيًا مستندًا إلى Artisan عبر سطر الأوامر.

## التثبيت

المحاكي جزء من حزمة Centry Core. تأكد من تثبيت أحدث إصدار.

## الاستخدام الأساسي

شغِّل الأمر التالي لتوليد إشارات لشريك في بيئة الاختبار:

```bash
php artisan centry:simulate-signals \
  --template=account_takeover \
  --partner=<PARTNER_UUID> \
  --count=50
```

## الخيارات

| الخيار | الوصف | الافتراضي |
|--------|-------|-----------|
| `--template` | اسم القالب المراد استخدامه. | مطلوب |
| `--partner` | UUID شريك بيئة الاختبار. | مطلوب |
| `--count` | عدد الإشارات المراد توليدها. | 20 |
| `--rate` | الإشارات في الدقيقة (تحديد المعدل). | 10 |
| `--severity` | فرض ملف مخاطر محدد: `critical` أو `high` أو `medium` أو `low`. | توزيع عشوائي |
| `--list` | سرد جميع القوالب المتاحة. | لا ينطبق |

### استخدام خيار الخطورة

فرض مستوى مخاطر محدد على جميع الإشارات المولَّدة:

```bash
# توليد 50 إشارة بمخاطر حرجة لاختبار عتبات التنبيه
php artisan centry:simulate-signals \
  --template=account_takeover \
  --partner=<PARTNER_UUID> \
  --count=50 \
  --severity=critical

# توليد إشارات منخفضة المخاطر لاختبار سيناريوهات النتائج السلبية الزائفة
php artisan centry:simulate-signals \
  --template=stolen_financials \
  --partner=<PARTNER_UUID> \
  --count=30 \
  --severity=low
```

::callout{type="info"}
**حالة الاستخدام**: خيار `--severity` مفيد عند اختبار قواعد تنبيه محددة أو منطق أولوية الحالة أو توزيع عبء العمل على المحللين. بدون هذه العلامة، تتبع الإشارات توزيع المخاطر الطبيعي (10% حرج، 20% مرتفع، 30% متوسط، 40% منخفض).
::

## سلامة البيئة

يتضمن محاكي CLI ضمانات مدمجة للحيلولة دون الاستخدام العرضي في الإنتاج:
- **يستهدف فقط** عناوين URL تحتوي على `sandbox` أو `localhost` أو `127.0.0.1`.
- **يتطلب** شريكًا موضوعًا صراحةً في وضع الاختبار (Sandbox Mode).
- **يتطلب** مفتاح API بادئ الاختبار (`cen_test_sk_*`).

## عرض النتائج

بعد التوليد، ستظهر الإشارات في **سجلات الإشارات** (تأكد من ضبط مرشح البيئة على **الاختبار**).
عرض الإشارات في بوابة الشريك: `/signals?environment=sandbox`

## القوالب المخصصة

يمكنك إضافة قوالبك الخاصة بوضع ملفات JSON في `storage/app/signal-templates/`. راجع [مرجع القوالب](./signal-templates) للتفاصيل.
