# توثيق الشركاء

::callout{icon="i-lucide-shield-check" color="green"}
**وصول مُصرَّح به**: أنت مسجَّل الدخول بوصفك شريكًا معتمدًا. يحتوي هذا التوثيق على تفاصيل التنفيذ التقني غير المتاحة للعموم.
::

مرحبًا بك في توثيق شركاء Protegey. هذا دليلك التقني للتكامل مع شبكة Protegey العالمية للاستخبارات المالية ومكافحة الاحتيال.

## دورك في الشبكة

بوصفك شريكًا، أنت عقدة في منظومة دفاع جماعي. تؤثر جودة تكاملك مباشرةً على سلامة النظام البيئي المالي بأكمله.

### الالتزامات الرئيسية

1.  **حماية بيانات الاعتماد**: مفاتيح API الخاصة بك هي مفاتيح الحصن. لا تُشاركها أبدًا ولا تضمِّنها في مستودعات الكود.
2.  **الإبلاغ بإشارات دقيقة**: "القمامة تُنتج قمامة." تأكَّد من سلامة منطقك في الإبلاغ عن الاحتيال قبل إرسال الإشارات.
3.  **احترام الخصوصية**: أرسل البيانات المطلوبة بالمخطط فقط. لا ترسل بيانات شخصية (PII) غير مجزَّأة في حقول البيانات الوصفية الاختيارية.

## نموذج المسؤولية المشتركة

الأمان شراكة مشتركة.

| مسؤولية Protegey              | مسؤوليتك                                  |
| ----------------------------- | ----------------------------------------- |
| البنية التحتية للمنصة         | أمان مفتاح API الخاص بك                   |
| تشفير البيانات في حالة السكون | النقل الآمن للبيانات (TLS)                |
| دقة نموذج المخاطر             | دقة الإشارات                              |
| توفر الشبكة                   | معالجة أعطال واجهة برمجة التطبيقات بسلاسة |

## الإقرارات القانونية

باستخدام التوثيق التفصيلي لواجهة برمجة التطبيقات ونقاط نهايتها، تُؤكِّد موافقتك على:

- **اتفاقية الخدمات الرئيسية (MSA)**
- **اتفاقية معالجة البيانات (DPA)**
- **سياسة الاستخدام المقبول (AUP)**

::callout{icon="i-lucide-alert-triangle" color="amber"}
**السرية**: تُعدُّ تفاصيل التنفيذ الموصوفة في هذه الوثائق (ولا سيما منطق التسجيل والعتبات) **معلومات سرية**. لا تُفصح عنها لأطراف ثالثة.
::
