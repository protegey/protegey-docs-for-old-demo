# Scoring de confiance OSINT

## Vue d'ensemble

Les résultats OSINT bruts (listes de sanctions ONU/UE/UA, registres des PPE) ont une fiabilité très variable. Une correspondance sur la liste consolidée de l'ONU n'est pas équivalente à une correspondance sur un avis régional mis à jour il y a 18 mois. Le cadre de scoring de confiance quantifie cette variation selon quatre dimensions.

Les scores de confiance sont stockés dans `OsintEntityLink.confidence_score` (float 0,0–1,0) et sont retournés dans toutes les réponses de filtrage des sanctions.

---

## Les quatre dimensions

### 1. Autorité (40 %)

Mesure la crédibilité et le poids réglementaire de la source.

| Source | Score d'autorité |
|--------|----------------|
| Liste consolidée du Conseil de sécurité de l'ONU | 1,00 |
| Sanctions financières consolidées de l'UE | 0,95 |
| OFAC SDN (USA) | 0,95 |
| Conseil de paix et de sécurité de l'Union africaine | 0,85 |
| Listes nationales des CRF (États membres FATF) | 0,75 |
| Avis GIABA / ESAAMLG | 0,65 |
| Notices rouges INTERPOL | 0,80 |
| Listes régionales OHADA | 0,55 |
| Agrégateurs OSINT commerciaux | 0,50 |

Les scores d'autorité sont statiques par source et stockés dans `config/osint.php` sous `source_authority`.

### 2. Fraîcheur (25 %)

Mesure la récence de l'ingestion des données source et la récence de la confirmation de l'enregistrement spécifique. Utilise une décroissance temporelle exponentielle :

```php
$daysSinceIngest = now()->diffInDays($link->ingested_at);
$freshnessScore  = exp(-$daysSinceIngest / 365); // half-life ~253 days
```

| Ancienneté | Score de fraîcheur |
|-----|----------------|
| 0–7 jours | 0,98–1,00 |
| 1 mois | 0,92 |
| 3 mois | 0,78 |
| 6 mois | 0,61 |
| 12 mois | 0,37 |
| 24 mois | 0,14 |

La fraîcheur est recalculée hebdomadairement par la tâche `osint:recompute-freshness` (les dimanches à 05h00 UTC).

### 3. Corroboration (20 %)

Mesure le nombre de sources indépendantes confirmant la même correspondance.

```php
$sourceCount       = $link->corroborating_source_count; // 1–N
$corroborationScore = min(1.0, 0.4 + ($sourceCount - 1) * 0.2);
```

| Sources indépendantes | Score de corroboration |
|---------------------|---------------------|
| 1 (source unique) | 0,40 |
| 2 sources | 0,60 |
| 3 sources | 0,80 |
| 4+ sources | 1,00 |

### 4. Spécificité (15 %)

Mesure la précision de la correspondance pour identifier le sujet — nom légal complet + date de naissance + nationalité vs. correspondance sur le nom uniquement.

| Champs de correspondance présents | Score de spécificité |
|---------------------|------------------|
| Nom + date de naissance + nationalité + identifiant | 1,00 |
| Nom + date de naissance + nationalité | 0,85 |
| Nom + date de naissance | 0,70 |
| Nom + nationalité | 0,60 |
| Nom uniquement | 0,40 |
| Correspondance approximative / phonétique | 0,20 |

La spécificité est calculée par `EntityResolutionService::computeSpecificity()` au moment de l'ingestion.

---

## Formule du score composite

```php
$confidence = (
    ($authority      * 0.40) +
    ($freshness      * 0.25) +
    ($corroboration  * 0.20) +
    ($specificity    * 0.15)
);
```

**Exemple** : Correspondance sur la liste SDN de l'ONU, ingérée il y a 2 semaines, confirmée par 2 sources, nom + date de naissance + nationalité :
```
(1,00 × 0,40) + (0,97 × 0,25) + (0,60 × 0,20) + (0,85 × 0,15)
= 0,40 + 0,2425 + 0,12 + 0,1275
= 0,89
```

---

## Confiance dans le scoring de risque

Les scores de confiance alimentent la contribution au risque des sanctions :

```php
// In SanctionsMatchingService
$riskContribution = $match->is_exact_match
    ? 100 * $match->confidence_score
    : 50  * $match->confidence_score;
```

Une correspondance à haute confiance (0,9+) sur la liste ONU contribue à près de 90 points de risque. Une correspondance à faible confiance (0,3) sur une liste régionale obsolète contribue ~15 points — suffisant pour signaler à la révision, mais pas pour bloquer automatiquement.

---

## Tâche de décroissance hebdomadaire

`php artisan osint:recompute-freshness`

- Sélectionne tous les enregistrements `OsintEntityLink` dont `last_freshness_computed_at < 7 jours`
- Recalcule le score de fraîcheur avec la formule ci-dessus
- Met à jour `confidence_score` comme composante de l'autorité courante + nouvelle fraîcheur + corroboration stockée + spécificité stockée
- Journalise le nombre de recalculs dans la métrique `osint_freshness_recomputed`

Exécutée le dimanche à 05h00 UTC via le planificateur Laravel. Peut être exécutée manuellement sans effets secondaires.

## Exposition API

Les scores de confiance sont retournés sur `GET /api/v1/partner/compliance/sanctions/{entityId}` :

```json
{
  "matches": [
    {
      "source": "UN_CONSOLIDATED",
      "match_type": "exact",
      "confidence_score": 0.89,
      "confidence_breakdown": {
        "authority": 1.00,
        "freshness": 0.97,
        "corroboration": 0.60,
        "specificity": 0.85
      },
      "ingested_at": "2026-03-10T03:00:00Z"
    }
  ]
}
```
