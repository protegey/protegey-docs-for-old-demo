Le **Score de confiance partenaire** (0,0 - 1,0) détermine l'influence d'un signal partenaire sur le réseau.

## La formule

```python
trust_score = (base_trust * reliability_factor * volume_bonus) - penalties
```

### Composantes

1. **Confiance de base** : Valeur par défaut à `0,5` pour les nouveaux partenaires.
2. **Facteur de fiabilité** :
   - Calculé comme `1 - (false_positive_rate * 2)`.
   - Plafonné à un multiplicateur maximum de `1,5`.
3. **Bonus de volume** :
   - `log10(monthly_signals) / 10`.
   - Incite les contributeurs importants.
4. **Pénalités** :
   - Remplacements manuels appliqués par l'équipe T&S en cas de violations de conformité.

## Mise à jour des pondérations

Les scores de confiance sont recalculés **chaque nuit à 02h00 UTC** via le job batch `CalculateTrustScores`.
