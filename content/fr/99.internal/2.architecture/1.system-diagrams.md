## Topologie de haut niveau

```
Système partenaire
     │ HTTPS + X-API-Key
     ▼
SignalController (Laravel 12)
     │ validation clé API → partenaire résolu
     │ vérification limite de débit (par heure / par jour selon le plan)
     │ vérification du feature flag
     ▼
IngestSignalAction (pipeline synchrone, cible <50ms)
     ├── UFESNormalizationService
     ├── UFESValidator
     ├── ResolverRegistry (MSISDN, Device, Geo, Time)
     ├── FeatureEngineeringService → SignalFeature persisté
     ├── DetectorRegistry (9 détecteurs) → DetectorExecution persisté
     ├── TaxonomyRegistry → TaxonomyAssignment persisté
     ├── HotGraphService → graph_nodes/graph_edges upsertés + Redis préchauffé
     ├── WeightedRiskFusionEngine → fused_score calculé
     ├── PolicyEngine → décision BLOCK/ALLOW/ESCALATE/STEP_UP
     └── AlertGenerationService → FraudAlert + AlertLineage créés
             │
             ├── (async) AMLComplianceService
             │         → TransactionMonitoringRulesService
             │         → SanctionsMatchingService
             │         → PEPDetectionService
             │
             ├── (async) écouteur ShareAlertOnCreation
             │         → BroadcastSharedIntelligenceJob
             │
             └── (async) WebhookService
                       → dispatch des payloads signés HMAC vers partner_webhooks
```

## Infrastructure principale

| Composant | Technologie | Rôle |
|---|---|---|
| Serveur web | Laravel 12 (Octane optionnel) | Traitement des requêtes HTTP |
| Queue | Laravel queues (driver Redis) | Traitement asynchrone des jobs |
| DB principale | PostgreSQL 15+ | Toutes les données persistantes |
| Cache + adjacence | Redis 7+ | Cache graphe, cache géo-risque, compteurs de limite de débit |
| Push temps réel | Laravel Reverb (WebSockets) | Mises à jour en direct du portail partenaire |
| Interface admin | Inertia.js + Vue 3 | Panneau d'administration interne |
| Portail partenaire | Nuxt 3 (SPA) | Portail orienté partenaire |

## Isolation du schéma de base de données

```
Base de données PostgreSQL
├── schéma public
│   ├── signals, fraud_entities, fraud_cases, fraud_alerts
│   ├── graph_nodes, graph_edges
│   ├── partner_webhooks, webhook_deliveries
│   ├── policy_documents, decision_explanations
│   ├── aml_transaction_flags, suspicious_activity_reports
│   ├── pep_designations, geographic_risk_profiles
│   ├── osint_facts, osint_sources, osint_entity_links
│   ├── shared_intelligence_feed, regulatory_advisories
│   └── users, partners, subscriptions (partagés)
│
└── schéma sandbox
    ├── signals (données partenaire sandbox)
    ├── fraud_entities (données partenaire sandbox)
    ├── fraud_cases (données partenaire sandbox)
    └── [toutes les tables à portée partenaire dupliquées]
```

`SET search_path TO {sandbox|public}, public` est appliqué par requête par le middleware `EnforceSchemaIsolation`. Les modèles interrogent automatiquement le bon schéma.

## Intelligence graphe (Hot Graph)

```
Signal ingéré
     │
     ▼
HotGraphService::linkSignalToGraph()
     │
     ├── GraphNodeService::upsert(ACTOR, actor.hashed_id)
     ├── GraphNodeService::upsert(ACCOUNT, account)
     ├── GraphNodeService::upsert(DEVICE, device_fingerprint)
     ├── GraphNodeService::upsert(MSISDN, msisdn)
     ├── GraphEdgeService::upsert(ACTOR → ACCOUNT, USES_ACCOUNT)
     ├── GraphEdgeService::upsert(ACTOR → DEVICE, USES_DEVICE)
     └── GraphEdgeService::upsert(ACTOR → MSISDN, USES_PHONE)

GraphCacheService (Redis)
     ├── graph:1hop:{node_id} → voisins JSON (TTL 15min)
     └── graph:2hop:{node_id} → agrégat JSON 2-hop (TTL 15min)

HotGraphService::getNeighborhoodRisk(nodeId, hops=2)
     └── cache read-through : Redis d'abord → repli PostgreSQL
```

Types de nœuds : `ACTOR`, `ACCOUNT`, `MSISDN`, `DEVICE`, `IP`, `MERCHANT`, `AGENT`, `BENEFICIARY`
Types d'arêtes : `USES_DEVICE`, `USES_PHONE`, `SENT_TO`, `RECEIVED_FROM`, `CASHED_OUT_AT`, `SHARED_IDENTIFIER`

Toutes les requêtes graphe sont scopées par `tenant_id` pour prévenir les IDOR inter-locataires.

## Flux de dispatch webhook

```
AlertGenerationService crée FraudAlert
     │
     ▼
WebhookService::dispatch(partnerId, event, payload)
     │
     ├── Requête partner_webhooks WHERE is_active = true
     ├── Filtre par abonnement événement (vérification contains JSONB)
     └── Pour chaque endpoint :
           ├── Signer le payload : HMAC-SHA256(rawBody, endpoint.secret)
           ├── POST vers endpoint.url
           │     X-Protegey-Signature: {signature}
           │     X-Protegey-Event: {event_type}
           │     X-Protegey-Delivery-ID: {uuid}
           ├── Enregistrer dans webhook_deliveries
           └── En cas d'échec :
                 incrémenter failure_count
                 si failure_count >= 3 : désactiver l'endpoint (is_active = false)
```

## Topologie du graphe chaud

```
Signal Ingestion
    ↓
GraphNodeService.upsert(entity)        → graph_nodes (PostgreSQL)
GraphEdgeService.upsert(source, target) → graph_edges (PostgreSQL)
    ↓
Redis adjacency cache invalidation     → "graph:adj:{partner}:{nodeId}" TTL 15min
    ↓
HotGraphService.getNeighborhood(depth=2)
    ├── Cache HIT  → return in < 5ms
    └── Cache MISS → DB BFS → cache result → return
    ↓
WeightedRiskFusionEngine (network_score = 40%)
```

**Reconstruction hebdomadaire** : tâche `graph:rebuild-adjacency-cache` (dimanche 02h00 UTC) — pré-chauffe toutes les listes d'adjacence des partenaires.

## Flux du domaine Support

```
Partner Portal                      Laravel Backend
─────────────────                   ───────────────────────────
POST /support/threads        →      SupportThreadController
                                      → SupportThread::create()
                                      → SupportMessage::create()
                                      → AttachmentService::store() (if files)
                                      → broadcast(MessageCreated)
                                                 ↓
                                         Reverb WebSocket
                                                 ↓
Partner Portal (real-time)   ←      private-support.{threadUuid}
```

Toutes les pièces jointes sont stockées dans un stockage chiffré, limité au périmètre partenaire, avec suppression automatique après 180 jours.

## Flux de monitoring Phase M

```
Load Balancer          GET /ready     →  DatabaseCheck (< 100ms)
                                            ↓ 200 OK / 503

Admin Panel / Grafana  GET /health    →  HealthController
                                         [30s cache]
                                           ├── DB connection + latency
                                           ├── Redis ping + memory
                                           ├── Queue: pending/failed/workers
                                           ├── Reverb: active connections
                                           ├── Graph cache: hit rate + key count
                                           └── OSINT: last_run + records_processed
```
