L'API KYB (Know Your Business) vous permet de collecter, examiner et filtrer les candidatures de clients professionnels grâce à des questionnaires configurables. Les partenaires créent des formulaires d'admission, envoient des liens d'invitation signés et prennent des décisions d'approbation — le filtrage des sanctions et PPE s'exécutant automatiquement à l'approbation.

::callout{icon="i-lucide-building-2" color="blue"}
**Permissions requises** : `kyb.invite` pour envoyer des invitations · `kyb.review` pour décider des candidatures · `kyb.manage` pour créer des questionnaires. Ces trois permissions sont incluses par défaut dans le rôle Partenaire.
::

---

## Gestion des Questionnaires

Les questionnaires sont des formulaires d'admission versionnés composés de sections et de questions typées. Un questionnaire est **verrouillé automatiquement** dès l'envoi de la première invitation — après cela, clonez-le pour apporter des modifications.

### Lister les Questionnaires

Retourne les questionnaires propres au partenaire ainsi que les modèles globaux actifs.

```http
GET /api/v1/partner/kyb/questionnaires
Authorization: Bearer {token}
```

```json
{
  "data": [
    {
      "uuid": "q_01HZKJ...",
      "title": "Intégration Professionnelle — Standard",
      "version": "1.0",
      "is_active": true,
      "is_default": true,
      "is_locked": false,
      "question_count": 14,
      "created_at": "2026-04-01T09:00:00Z"
    }
  ]
}
```

### Obtenir un Questionnaire

Retourne le questionnaire avec sa liste complète de questions.

```http
GET /api/v1/partner/kyb/questionnaires/{uuid}
Authorization: Bearer {token}
```

### Créer un Questionnaire

```http
POST /api/v1/partner/kyb/questionnaires
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "title": "KYB Partenaire Fintech v2",
  "version": "2.0",
  "is_default": false,
  "document_requirements": [
    { "document_type": "certificate_of_incorporation", "is_required": true },
    { "document_type": "payment_services_license", "is_required": true }
  ],
  "questions": [
    {
      "section": "Identité de l'Entreprise",
      "order_index": 1,
      "type": "text",
      "label": "Nom enregistré de l'entreprise",
      "is_required": true,
      "is_screening_identifier": true
    },
    {
      "section": "Identité de l'Entreprise",
      "order_index": 2,
      "type": "select",
      "label": "Pays d'immatriculation",
      "is_required": true,
      "options": ["GH", "NG", "SN", "KE", "ZA"]
    },
    {
      "section": "Actionnariat",
      "order_index": 3,
      "type": "boolean",
      "label": "Une personne détient-elle plus de 25 % de l'entreprise ?",
      "is_required": true
    },
    {
      "section": "Actionnariat",
      "order_index": 4,
      "type": "text",
      "label": "Nom du bénéficiaire effectif (>25 %)",
      "is_required": true,
      "conditions": [
        { "question_uuid": "qn_01...", "operator": "truthy" }
      ]
    }
  ]
}
```

**Types de questions :** `text` · `textarea` · `boolean` · `select` · `multi_select` · `number` · `date`

**Affichage conditionnel** — une question n'est affichée que lorsque toutes ses `conditions` sont satisfaites :

| Champ | Description |
|---|---|
| `question_uuid` | UUID de la question de contrôle |
| `operator` | `eq` (égal) · `neq` (différent) · `truthy` (toute valeur non nulle/fausse) |
| `value` | Requis pour `eq` et `neq` ; omis pour `truthy` |

::callout{type="warning"}
Marquez exactement **une** question par questionnaire avec `"is_screening_identifier": true`. Cette réponse est utilisée comme nom de l'entreprise pour le filtrage AML lors de l'approbation. Si aucune n'est marquée, le filtrage est ignoré.
::

### Mettre à Jour un Questionnaire

Autorisé uniquement si `is_locked: false`. Retourne `409 Conflict` si déjà verrouillé.

```http
PUT /api/v1/partner/kyb/questionnaires/{uuid}
Authorization: Bearer {token}
```

### Cloner un Questionnaire

Crée une copie complète (avec toutes les questions) sous une nouvelle version.

```http
POST /api/v1/partner/kyb/questionnaires/{uuid}/clone
Authorization: Bearer {token}
```

```json
{
  "data": {
    "uuid": "q_01HZKN...",
    "title": "Intégration Professionnelle — Standard",
    "version": "1.1",
    "is_locked": false
  }
}
```

## Gestion des Invitations

### Lister les Invitations

```http
GET /api/v1/partner/kyb/invites
Authorization: Bearer {token}
```

**Statuts des invitations :**

| Statut | Description |
|---|---|
| `pending` | Envoyée, pas encore ouverte |
| `opened` | Lien cliqué par le candidat |
| `in_progress` | Au moins une réponse sauvegardée |
| `submitted` | Candidature soumise |
| `expired` | Fenêtre de 30 jours dépassée sans soumission |

### Envoyer une Invitation

```http
POST /api/v1/partner/kyb/invites
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "applicant_email": "daf@acme-fintech.com",
  "applicant_name": "Kwame Mensah",
  "questionnaire_uuid": "q_01HZKJ..."
}
```

Omettez `questionnaire_uuid` pour utiliser votre questionnaire par défaut actif. L'envoi de l'invitation verrouille automatiquement le questionnaire.

```json
{
  "data": {
    "uuid": "inv_01HZKJ...",
    "status": "pending",
    "expires_at": "2026-05-27T09:00:00Z",
    "portal_url": "https://app.protegey.com/apply/a3f8c..."
  }
}
```

## Gestion des Candidatures

### Lister les Candidatures

```http
GET /api/v1/partner/kyb/applications
Authorization: Bearer {token}
```

Paramètres : `status` · `per_page`

**Statuts des candidatures :**

| Statut | Description |
|---|---|
| `draft` | Commencée mais non soumise |
| `submitted` | Soumission reçue ; en attente d'examen |
| `under_review` | Examinateur a ouvert la candidature |
| `more_info_required` | Informations complémentaires demandées ; le candidat peut resoumettre |
| `approved` | Approuvée ; entité créée dans le graphe |
| `rejected` | Rejetée (terminal) |

### Obtenir le Détail d'une Candidature

```http
GET /api/v1/partner/kyb/applications/{uuid}
Authorization: Bearer {token}
```

### Décider d'une Candidature

Nécessite la permission `kyb.review`.

```http
POST /api/v1/partner/kyb/applications/{uuid}/decide
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "decision": "approved",
  "notes": "Tous les documents vérifiés. Entité créée pour surveillance."
}
```

Valeurs de `decision` : `approved` · `rejected` · `more_info_required`

::callout{icon="i-lucide-shield" color="amber"}
**Le filtrage des risques s'exécute lors de l'approbation.** Le nom de l'entreprise est filtré contre les listes de sanctions et PPE. Si `risk_score > 0.75`, `is_pep = true` ou une correspondance sanctions est trouvée, un dossier de Diligence Renforcée (EDD) est créé automatiquement.
::

### Télécharger un Document

```http
GET /api/v1/partner/kyb/applications/{uuid}/documents/{document}/download
Authorization: Bearer {token}
```

Retourne une URL S3 signée à durée limitée.

## Endpoints du Portail Candidat

Ces endpoints utilisent l'**authentification par jeton** — aucun bearer OAuth n'est requis. Le jeton d'invitation est intégré dans l'URL.

### Charger l'État de la Candidature

```http
GET /api/v1/kyb/apply/{token}
```

### Sauvegarder la Progression

Sauvegarde de façon incrémentale. Tous les champs sont facultatifs.

```http
POST /api/v1/kyb/apply/{token}/progress
Content-Type: application/json
```

```json
{
  "answers": [
    { "question_uuid": "qn_01...", "value": "Acme Fintech SARL" },
    { "question_uuid": "qn_02...", "value": "SN" }
  ]
}
```

### Téléverser un Document

```http
POST /api/v1/kyb/apply/{token}/documents
Content-Type: multipart/form-data
```

| Champ | Type | Description |
|---|---|---|
| `file` | Fichier | Max 10 Mo. Acceptés : pdf, jpg, png, docx |
| `document_type` | string | Voir tableau des types de documents |

### Supprimer un Document

```http
DELETE /api/v1/kyb/apply/{token}/documents/{document}
```

### Soumettre la Candidature

```http
POST /api/v1/kyb/apply/{token}/submit
```

## Permissions

| Permission | Rôle concerné | Actions |
|---|---|---|
| `kyb.invite` | Chargés de relation, responsables conformité | Envoyer des invitations, consulter invitations et candidatures |
| `kyb.review` | Analystes conformité | Approuver/rejeter/demander des informations, télécharger documents |
| `kyb.manage` | Administrateurs | Créer, mettre à jour et cloner des questionnaires |
