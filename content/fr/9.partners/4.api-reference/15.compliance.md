L'API Risk & Compliance as a Service (RCaaS) fournit des outils de conformité LCB-FT intégrés directement dans le pipeline de signaux Protegey. Chaque signal est automatiquement évalué contre les listes de sanctions, les bases de données PPE, les profils de risque géographique et les règles de surveillance des transactions AML.

## Tableau de Bord de Conformité

```http
GET /api/v1/partner/compliance/dashboard
Authorization: Bearer {token}
```

```json
{
  "open_sars": 3,
  "flags_last_30_days": 47,
  "screened_entities": 1240,
  "sanctions_matches": 2,
  "high_risk_jurisdictions_flagged": 8,
  "upcoming_calendar_events": 5
}
```

## Filtrage des Sanctions

### Obtenir le profil de sanctions d'une entité

```http
GET /api/v1/partner/compliance/sanctions/{entityId}
Authorization: Bearer {token}
```

```json
{
  "entity_id": 42,
  "entity_name": "Jean Dupont",
  "is_sanctioned": false,
  "is_pep": true,
  "pep_designation": {
    "type": "government_official",
    "country_code": "CI",
    "source": "osint_un",
    "effective_from": "2022-01-01"
  },
  "osint_matches": [],
  "last_screened_at": "2026-02-18T04:00:00Z",
  "risk_level": "high"
}
```

### Re-filtrer une entité

Déclenche un re-filtrage immédiat sur les données OSINT les plus récentes :

```http
POST /api/v1/partner/compliance/sanctions/{entityId}/rescreen
Authorization: Bearer {token}
```

## Rapports d'Activité Suspecte (RAS)

### Lister les RAS

```http
GET /api/v1/partner/compliance/sars
Authorization: Bearer {token}
```

Paramètres de requête : `status` (`draft`, `under_review`, `filed`, `archived`), `per_page`

```json
{
  "data": [
    {
      "id": "sar_abc123",
      "reference_number": "SAR-20260218-00042",
      "status": "under_review",
      "entity_id": 42,
      "narrative": "L'entité a présenté un comportement de fractionnement sur 3 comptes...",
      "transaction_total": 45000.0,
      "currency": "XOF",
      "created_at": "2026-02-15T10:00:00Z",
      "filed_at": null
    }
  ]
}
```

### Créer un RAS (Brouillon)

```http
POST /api/v1/partner/compliance/sars
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "entity_id": 42,
  "reason": "Fractionnement détecté : 12 transactions juste en dessous du seuil de déclaration",
  "case_id": "case_uuid_optionnel"
}
```

Un récit est généré automatiquement à partir des enregistrements `AmlTransactionFlag` de l'entité. Vous pouvez le modifier avant soumission.

### Mettre à jour le récit d'un RAS

```http
PUT /api/v1/partner/compliance/sars/{sarId}
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "narrative": "Récit d'investigation mis à jour..."
}
```

### Soumettre pour révision

```http
POST /api/v1/partner/compliance/sars/{sarId}/review
Authorization: Bearer {token}
```

### Déposer un RAS

Nécessite le rôle `analyst` ou supérieur.

```http
POST /api/v1/partner/compliance/sars/{sarId}/file
Authorization: Bearer {token}
```

Cycle de vie du RAS : `draft` → `under_review` → `filed` → `archived`

## Signalements de Transactions

Les signalements sont créés automatiquement par `TransactionMonitoringRulesService` pour chaque signal traité.

### Lister les signalements

```http
GET /api/v1/partner/compliance/transaction-flags
Authorization: Bearer {token}
```

Paramètres de requête : `rule_key`, `entity_id`, `from`, `to`, `per_page`

```json
{
  "data": [
    {
      "id": "flag_abc123",
      "signal_id": "sig_xyz789",
      "entity_id": 42,
      "rule_key": "structuring",
      "rule_description": "Transactions multiples juste en dessous du seuil de déclaration",
      "risk_contribution": 0.85,
      "flagged_at": "2026-02-18T10:00:00Z",
      "metadata": {
        "transaction_count": 8,
        "window_hours": 24,
        "threshold": 500000
      }
    }
  ]
}
```

**Clés de règle :** `structuring`, `velocity_breach`, `round_number`, `high_risk_jurisdiction`

## Risque Géographique

### Obtenir le profil de risque d'un pays

```http
GET /api/v1/partner/compliance/geo-risk/{countryCode}
Authorization: Bearer {token}
```

```json
{
  "country_code": "CI",
  "country_name": "Côte d'Ivoire",
  "fatf_status": "compliant",
  "risk_score": 0.42,
  "last_assessed_at": "2025-06-15"
}
```

**Statuts FATF :** `compliant`, `grey_list`, `black_list`, `not_assessed`

## Calendrier de Conformité

### Lister les événements

```http
GET /api/v1/partner/compliance/calendar
Authorization: Bearer {token}
```

```json
{
  "data": [
    {
      "id": "cal_abc123",
      "event_type": "aml_review",
      "entity_id": 42,
      "due_at": "2026-03-01T00:00:00Z",
      "completed_at": null,
      "notes": "Révision AML annuelle pour entité à haut risque"
    }
  ]
}
```

**Types d'événements :** `kyc_refresh`, `aml_review`, `sar_filing_deadline`, `sanctions_rescreening`

### Ajouter un événement au calendrier

```http
POST /api/v1/partner/compliance/calendar
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "event_type": "aml_review",
  "entity_id": 42,
  "due_at": "2026-03-01T00:00:00Z",
  "notes": "Suivi des signalements de fractionnement"
}
```
