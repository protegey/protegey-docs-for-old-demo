title: API de Gestion des Dossiers (Cases)
description: Référence API complète pour la gestion des dossiers partenaires, incluant la création de dossiers, l'ajout de notes, le téléchargement de preuves et le suivi des enquêtes.
---

L'API de Gestion des Dossiers permet aux partenaires de créer, gérer et enquêter sur des dossiers de fraude directement depuis leurs systèmes. Les dossiers représentent des enquêtes formelles qui commencent généralement par des signaux ou des alertes.

::callout{type="info"}
**Restriction de fonctionnalité** : La gestion des dossiers est disponible pour les forfaits Professional et supérieurs. L'accès en mode sandbox est inclus dans tous les forfaits.
::

## Authentification

Tous les points de terminaison nécessitent une authentification par jeton OAuth2 Bearer :

```bash
Authorization: Bearer VOTRE_JETON_D_ACCES
```

## Limites de Débit

- **Lister les dossiers** : 60 requêtes par minute
- **Créer/Mettre à jour les dossiers** : 30 requêtes par minute
- **Ajouter des notes/preuves** : 120 requêtes par minute
- **Détails d'un dossier** : 120 requêtes par minute

---

## Lister les Dossiers

**GET** `/api/v1/partner/cases`

Récupère une liste paginée de dossiers de fraude pour votre organisation partenaire.

### Paramètres de Requête

| Paramètre  | Type    | Description                                                      |
| ---------- | ------- | ---------------------------------------------------------------- |
| `status`   | string  | Filtrer par statut : `open`, `in_progress`, `resolved`, `closed` |
| `priority` | string  | Filtrer par priorité : `low`, `medium`, `high`, `critical`       |
| `per_page` | integer | Éléments par page (max : 100)                                    |

---

## Créer un Dossier

**POST** `/api/v1/partner/cases`

Créer manuellement un nouveau dossier d'enquête sur la fraude.

### Corps de la Requête

| Champ         | Type   | Requis | Description                                              |
| ------------- | ------ | ------ | -------------------------------------------------------- |
| `title`       | string | Oui    | Titre du dossier (max 255 caractères)                    |
| `description` | string | Non    | Description détaillée                                    |
| `priority`    | string | Oui    | Niveau de priorité : `low`, `medium`, `high`, `critical` |

---

## Détails d'un Dossier

**GET** `/api/v1/partner/cases/{uuid}`

Récupère les informations détaillées d'un dossier spécifique, incluant les incidents liés, les notes et les changements de statut.

---

## Mettre à jour un Dossier

**PUT** `/api/v1/partner/cases/{uuid}`

Met à jour le statut, la priorité ou l'attribution d'un dossier.

::callout{type="warning"}
**Validation de l'attribution** : Lors de l'attribution d'un dossier, le système vérifie que l'utilisateur appartient bien à votre organisation partenaire.
::

---

## Ajouter une Note

**POST** `/api/v1/partner/cases/{uuid}/notes`

Ajoute une note d'enquête à un dossier.

---

## Ajouter une Preuve (Evidence)

**POST** `/api/v1/partner/cases/{uuid}/evidence`

Joint des preuves à l'appui d'un dossier (captures d'écran, documents, journaux, etc.).

::callout{type="info"}
**Formats pris en charge** : Images (PNG, JPG, GIF), documents (PDF, DOCX, XLSX), journaux (TXT, LOG, JSON), archives (ZIP).
::

---

## Créer un Dossier à partir d'un Signal

**POST** `/api/v1/partner/cases/from-signal/{signalId}`

Crée un dossier directement à partir d'un signal ou d'une transaction. C'est le flux recommandé pour escalader des signaux suspects en enquêtes formelles.

---

## Cycle de Vie des Statuts

Les dossiers suivent un cycle de vie défini :
`open` → `in_progress` → `resolved` → `closed`.

| Statut          | Description                                         |
| --------------- | --------------------------------------------------- |
| **open**        | Dossier créé, en attente d'attribution ou de tri.   |
| **in_progress** | Enquête activement en cours.                        |
| **resolved**    | Problème résolu, en attente de confirmation finale. |
| **closed**      | Dossier officiellement fermé.                       |

---

## Niveaux de Priorité

| Priorité     | Cas d'utilisation                               |
| ------------ | ----------------------------------------------- |
| **critical** | Fraude active en cours, impact financier élevé. |
| **high**     | Fraude suspectée, risque significatif.          |
| **medium**   | Fraude potentielle, risque modéré.              |
| **low**      | Anomalie mineure, risque faible.                |
