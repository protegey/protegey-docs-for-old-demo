# Support Threads

L'API Support Threads fournit un canal de messagerie intégré à la plateforme entre votre organisation et l'équipe support Protegey. Les fils de discussion persistent entre les sessions, prennent en charge les pièces jointes et transmettent les messages en temps réel via WebSocket.

::callout{type="info"}
Les fils de support sont limités à votre compte partenaire. Tous les agents et membres de votre équipe partagent une même boîte de réception.
::

---

## Endpoints

| Méthode | Chemin | Description |
|--------|------|-------------|
| `GET` | `/api/v1/partner/support/threads` | Lister tous les fils de support |
| `POST` | `/api/v1/partner/support/threads` | Créer un nouveau fil |
| `GET` | `/api/v1/partner/support/threads/{uuid}` | Obtenir le détail d'un fil et tous ses messages |
| `POST` | `/api/v1/partner/support/threads/{uuid}/messages` | Ajouter un message à un fil |
| `GET` | `/api/v1/partner/support/attachments/{uuid}` | Télécharger une pièce jointe |

---

## Lister les fils

```http
GET /api/v1/partner/support/threads
Authorization: Bearer {token}
```

### Paramètres de requête

| Paramètre | Type | Description |
|-----------|------|-------------|
| `status` | string | Filtrer par statut : `open`, `pending`, `closed` |
| `subject` | string | Filtrer par catégorie de sujet |
| `per_page` | integer | Résultats par page (défaut : 20, max : 100) |
| `page` | integer | Numéro de page |

### Réponse

```json
{
  "data": [
    {
      "uuid": "thr_01HZ9K2M4N5P6Q7R8S9T0UV1WX",
      "subject": "technical_issue",
      "title": "Signal ingestion 422 errors after rate limit window",
      "status": "open",
      "priority": "high",
      "message_count": 4,
      "unread_count": 1,
      "context_type": null,
      "context_id": null,
      "created_at": "2026-03-15T10:22:00Z",
      "last_message_at": "2026-03-15T14:47:00Z"
    }
  ],
  "meta": {
    "current_page": 1,

}
```

## Créer un fil

```http
POST /api/v1/partner/support/threads
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

### Corps de la requête

| Champ | Type | Requis | Description |
|-------|------|----------|-------------|
| `subject` | string | ✓ | Catégorie de sujet (voir l'énumération ci-dessous) |
| `title` | string | ✓ | Résumé court (max 255 caractères) |
| `message` | string | ✓ | Corps du message initial (max 10 000 caractères) |
| `priority` | string | | `low`, `normal`, `high`, `urgent` — défaut `normal` |
| `context_type` | string | | `case` ou `alert` — relie le fil à une ressource spécifique |
| `context_id` | string | | UUID du dossier ou de l'alerte lié(e) |
| `attachments[]` | file | | Jusqu'à 5 fichiers par message (voir les règles relatives aux pièces jointes) |

### Énumération des sujets

| Valeur | Cas d'usage |
|-------|----------|
| `technical_issue` | Erreurs API, échecs d'intégration, comportement inattendu |
| `signal_question` | Questions sur des signaux spécifiques ou sur le scoring |
| `integration_support` | Intégration initiale, configuration du SDK, configuration des webhooks |
| `billing` | Abonnement, facturation, changements de plan |
| `other` | Tout ce qui ne relève pas des catégories ci-dessus |

### Exemple de requête

```bash
curl -X POST https://api.protegey.com/api/v1/partner/support/threads \
  -H "Authorization: Bearer $TOKEN" \
  -F "subject=technical_issue" \
  -F "title=Signal ingestion returning 422 after UFES schema validation" \
  -F "message=We are consistently getting 422 responses when submitting signals with nested device metadata. The error references ufes_version but our payload matches the v2 schema." \
  -F "priority=high" \
  -F "attachments[]=@/tmp/error-payload.json"
```

### Réponse

```json
{
  "data": {
    "uuid": "thr_01HZ9K2M4N5P6Q7R8S9T0UV1WX",
    "subject": "technical_issue",
    "title": "Signal ingestion returning 422 after UFES schema validation",
    "status": "open",
    "priority": "high",
    "context_type": null,
    "context_id": null,
    "created_at": "2026-03-16T09:00:00Z",
    "messages": [
      {
        "uuid": "msg_01HZ9K2M4N5P6Q7R8S9T0UV1WY",
        "body": "We are consistently getting 422 responses...",
        "sender_type": "partner",
        "sender_name": "Ada Boateng",
        "attachments": [
          {
            "uuid": "att_01HZ9K2M4N5P6Q7R8S9T0UV1WZ",
            "filename": "error-payload.json",
            "mime_type": "application/json",
            "size_bytes": 1240
          }
        ],
        "created_at": "2026-03-16T09:00:00Z"
      }
    ]
  }
}
```

## Ajouter un message

```http
POST /api/v1/partner/support/threads/{uuid}/messages
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

Ajoute une réponse à un fil existant. Si le fil est à l'état `closed`, l'envoi d'un message le rouvre automatiquement.

### Corps de la requête

| Champ | Type | Requis | Description |
|-------|------|----------|-------------|
| `message` | string | ✓ | Corps du message (max 10 000 caractères) |
| `attachments[]` | file | | Jusqu'à 5 fichiers par message |

### Réponse

```json
{
  "data": {
    "uuid": "msg_01HZ9K2M4N5P6Q7R8S9T0UV1BB",
    "body": "Confirmed, removing the empty string fixed it. Thank you.",
    "sender_type": "partner",
    "sender_name": "Ada Boateng",
    "attachments": [],
    "created_at": "2026-03-16T12:10:00Z"
  }
}
```

## Télécharger une pièce jointe

```http
GET /api/v1/partner/support/attachments/{uuid}
Authorization: Bearer {token}
```

Retourne la pièce jointe sous forme de flux binaire. Les pièces jointes sont limitées au périmètre partenaire — il n'est pas possible de télécharger des pièces jointes appartenant au fil d'un autre partenaire.

| En-tête de réponse | Valeur |
|----------------|-------|
| `Content-Type` | Type MIME d'origine |
| `Content-Disposition` | `attachment; filename="nom-original.ext"` |
| `Content-Length` | Taille du fichier en octets |

---

## Règles relatives aux pièces jointes

| Règle | Limite |
|------|-------|
| Fichiers par message | 5 |
| Taille maximale par fichier | 10 Mo |
| Types autorisés | `jpg`, `png`, `gif`, `webp`, `pdf`, `txt` |
| Stockage | Chiffré au repos, accès journalisé, suppression automatique après 180 jours |

## Mises à jour en temps réel

Les fils de support diffusent les nouveaux messages via le WebSocket [Laravel Reverb](https://reverb.laravel.com/). Abonnez-vous au canal privé d'un fil pour recevoir les messages en temps réel sans interrogation périodique.

```javascript
import Echo from 'laravel-echo';

const echo = new Echo({ broadcaster: 'reverb', ... });

echo.private(`support.${threadUuid}`)
    .listen('.MessageCreated', (event) => {
        console.log('New message:', event.message);
    });
```

### Événements

| Événement | Charge utile |
|-------|---------|
| `.MessageCreated` | `{ message: { uuid, body, sender_type, sender_name, created_at } }` |
| `.ThreadStatusChanged` | `{ status: 'open' \| 'pending' \| 'closed' }` |

## Limites de débit

| Opération | Limite |
|-----------|-------|
| Lister / lire des fils | 60 requêtes / minute |
| Créer un fil | 10 requêtes / minute |
| Envoyer un message | 30 requêtes / minute |
| Télécharger une pièce jointe | 60 requêtes / minute |

---

## Codes d'erreur

| Code | Signification |
|------|---------|
| `422` | Échec de validation — consulter l'objet `errors` |
| `403` | Le fil n'appartient pas à votre compte |
| `404` | Fil ou pièce jointe introuvable |
| `413` | La pièce jointe dépasse 10 Mo |
| `415` | Type de fichier non pris en charge |
| `429` | Limite de débit dépassée |
