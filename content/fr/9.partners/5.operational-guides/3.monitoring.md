# Surveillance & Logs

Une surveillance efficace garantit que votre défense contre la fraude est active et opérationnelle.

## Ce qu'il faut surveiller

Nous recommandons d'instrumenter votre application pour suivre :

### 1. Disponibilité de l'API

- **Taux de succès** : % de réponses 2xx.
- **Taux d'échec** : % de réponses 4xx/5xx.
- **Alerte** : Déclencher si le taux 5xx > 1% pendant 5 minutes.

### 2. Latence

- **Métrique** : Latence P95 et P99 des appels à l'API Protegey.
- **Alerte** : Déclencher si P95 > 1000ms.

### 3. Distribution des scores de risque

- **Métrique** : Histogramme des scores de risque retournés.
- **Alerte** : Détecter une forte augmentation des scores « Risque élevé » (peut indiquer une attaque ou un bug).

## Logs du Portail Partenaire

Le Portail Partenaire fournit un **Journal des requêtes**.

- Consultez les requêtes API récentes.
- Filtrez par code de statut ou point de terminaison.
- Inspectez les charges utiles des requêtes/réponses (données sensibles masquées).
- **Rétention** : Les logs sont disponibles pendant 7 jours dans le portail.

## Intégration Datadog / Prometheus

(Entreprise uniquement)
Nous pouvons envoyer vos logs d'utilisation de l'API directement à votre instance Datadog ou Prometheus. Contactez votre responsable de compte pour activer cette fonctionnalité.
