# Conditions de Mise en Production

Pour garantir la sécurité du réseau, tous les partenaires doivent compléter cette évaluation de préparation avant d'obtenir l'accès à la Production.

## 1. Préparation Technique
- [ ] **Intégration Testée** : Signaux et requêtes soumis avec succès dans le Sandbox.
- [ ] **Gestion des Erreurs** : Confirmation que l'application échoue gracieusement en cas d'erreurs API.
- [ ] **Sécurité** : Les clés API sont gérées de manière sécurisée (non codées en dur).
- [ ] **TLS** : Utilisation de TLS 1.2+ pour toutes les connexions.

## 2. Préparation Opérationnelle
- [ ] **Équipe Formée** : Les analystes fraude savent comment interpréter les scores Protegey.
- [ ] **Processus Défini** : SOP claire définissant les actions à mener lorsqu'un utilisateur est signalé « Risque Élevé ».
- [ ] **Contacts** : Coordonnées d'urgence renseignées dans le Portail.

## 3. Conformité et Juridique
- [ ] **Contrats Signés** : MSA et DPA exécutés.
- [ ] **Mise à Jour de la Confidentialité** : Votre politique de confidentialité couvre le partage de données à des fins de prévention de la fraude.
- [ ] **Vérification d'Authentification** : Si vous utilisez la 2FA/MFA, l'intégration avec les signaux Protegey est mappée.

## Approbation Finale
Une fois ces éléments complétés, rendez-vous sur **Portail Partenaire > Paramètres > Accès Production** et cliquez sur **Demander l'Accès**. Notre équipe examinera votre compte dans les 24 heures.
