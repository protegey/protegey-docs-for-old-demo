# Authentification

Protegey utilise l'**Authentification par Clé API**.

::callout{icon="i-lucide-key" color="blue"}
**Gérer les Clés** : Vous pouvez générer et révoquer des clés dans le [Portail Partenaire](https://app.protegey.com/settings/api-keys).
::

## En-tête de Requête

Toutes les requêtes API doivent inclure votre **Clé API Secrète** dans l'en-tête `X-Centry-Key`.

```bash
curl -X GET https://api.protegey.com/v1/health \
  -H "X-Centry-Key: cen_live_sk_592834..."
```

## Types de Clés

| Type | Préfixe | Description | Utilisation |
|------|---------|-------------|-------------|
| **Clé Secrète (Secret Key)** | `..._sk_...` | **CONFIDENTIEL**. Accorde un accès complet à l'API. | Appels API côté serveur. |
| **Clé Publique (Public Key)** | `..._pk_...` | Identification publique. | Suivi côté client (futur) ou ID d'authentification de base. |

## Cycle de Vie des Clés

### Génération
Les clés sont générées par voie cryptographique. La **Clé Secrète** n'est affichée qu'**une seule fois**.
- Format : `cen_[env]_sk_[chaine_aleatoire]`
- Exemple : `cen_live_sk_8f7d6a5...`

### Rotation
Nous recommandons de renouveler les clés tous les 90 jours.
1. Générez une nouvelle clé dans le Portail.
2. Mettez à jour les variables d'environnement de votre application.
3. Vérifiez que la nouvelle clé fonctionne.
4. Révoquez l'ancienne clé dans le Portail.

### Révocation
Si vous soupçonnez qu'une clé a été compromise :
1. Révoquez **immédiatement** la clé dans le Portail Partenaire.
2. Cela invalidera instantanément toutes les sessions actives utilisant cette clé.
3. Contactez [security@protegey.com](mailto:security@protegey.com) pour demander un audit d'activité.

## Liste Blanche d'IP

Pour une couche de sécurité supplémentaire, vous pouvez restreindre l'utilisation des clés à des adresses IP spécifiques ou à des blocs CIDR.
- Configurez cela dans **Paramètres > Sécurité > Liste blanche d'IP**.
- Les requêtes provenant d'IP non autorisées seront rejetées avec une erreur `403 Forbidden` même si la clé API est valide.

## Codes d'Erreur

| Code | Signification | Action |
|------|---------------|--------|
| `401 Unauthorized` | Clé manquante ou invalide | Vérifiez votre en-tête `X-Centry-Key`. |
| `403 Forbidden` | Clé valide, mais permission refusée | Vérifiez la liste blanche d'IP ou les portées (scopes) de la clé. |
