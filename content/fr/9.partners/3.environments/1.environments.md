Protegey fournit deux environnements complètement isolés pour garantir des tests sécurisés et des opérations de production fiables.

| Fonctionnalité                      | Sandbox (`cen_test_`)              | Production (`cen_live_`)   |
| ----------------------------------- | ---------------------------------- | -------------------------- |
| **Point de Terminaison (Endpoint)** | `https://sandbox-api.protegey.com` | `https://api.protegey.com` |
| **Données**                         | Synthétiques / Fictives            | Intelligence Réelle        |
| **SLA**                             | Meilleur effort                    | Disponibilité de 99,99 %   |
| **Limites de Débit**                | Faibles (100/min)                  | Élevées (selon le niveau)  |
| **Coût**                            | Gratuit                            | Facturable                 |

## Isolation Stricte

**Les données ne franchissent jamais la frontière.**

- Un signal soumis au Sandbox **n'affectera pas** les scores de Production.
- Une entité de Production **ne peut pas** être interrogée en Sandbox (elle retournera une erreur 404).

## Choisir le Bon Environnement

### Utilisez le Sandbox quand :

- Vous développez votre intégration.
- Vous exécutez des tests CI/CD automatisés.
- Vous formez de nouveaux membres du personnel sur le tableau de bord.
- Vous testez la gestion des erreurs (le Sandbox prend en charge les "entrées magiques" pour déclencher des erreurs).

### Utilisez la Production quand :

- Vous traitez de réelles demandes de clients.
- Vous soumettez des signaux de fraude confirmés.
- Vous effectuez une surveillance des transactions en direct.

::callout{icon="i-lucide-flask-conical" color="purple"}
**Conseil** : Commencez toujours le développement dans le Sandbox. Nous recommandons de conserver une version de "Staging" de votre application pointant vers le Sandbox même après votre mise en service.
::
