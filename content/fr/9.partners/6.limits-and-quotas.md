# Limites et Quotas

Pour protéger les performances et l'intégrité du réseau, nous appliquons des limites à l'utilisation de l'API.

## Limites de Débit

Les limites sont appliquées par **Clé API**.

| Environnement  | Niveau       | Requêtes / Minute | Pointe (Burst) (5s) |
| -------------- | ------------ | ----------------- | ------------------- |
| **Sandbox**    | Tous         | 100               | 20                  |
| **Production** | Starter      | 1 000             | 100                 |
|                | Professional | 5 000             | 500                 |
|                | Enterprise   | Sur mesure        | Sur mesure          |

### Gestion des Limites de Débit

- Si vous dépassez la limite, vous recevrez une erreur `429 Too Many Requests`.
- Les en-têtes de réponse incluent :
  - `X-RateLimit-Limit` : Votre limite.
  - `X-RateLimit-Remaining` : Nombre de requêtes restantes dans la fenêtre actuelle.
  - `X-RateLimit-Reset` : Horodatage du moment où la fenêtre se réinitialise.

## Contraintes de Données

| Ressource   | Champ       | Contrainte                           |
| ----------- | ----------- | ------------------------------------ |
| Signal      | `metadata`  | Max 5 Ko (JSON)                      |
| Signal      | `entity_id` | Max 255 caractères                   |
| Batch (Lot) | `items`     | Max 100 éléments par requête par lot |

## Politique d'Utilisation Équitable

Le réseau Protegey repose sur la réciprocité.

- **Ratio Requêtes/Signaux** : Nous surveillons le ratio entre les Requêtes (consommation) et les Signaux (contribution).
- **Ratio Cible** : ~1:1 (idéal).
- **Acceptable** : jusqu'à 10:1 (10 requêtes pour chaque signal).
- **Abusif** : > 100:1 (Utilisation sans contribution).

Les partenaires qui consomment systématiquement l'intelligence sans contribuer en retour peuvent voir leur accès révisé ou restreint.
