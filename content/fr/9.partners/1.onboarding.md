Bienvenue dans l'intégration technique de Protegey. Ce guide est conçu pour les développeurs chargés d'intégrer leurs systèmes internes au réseau mondial d'intelligence contre la fraude Protegey.

## 1. Prérequis Techniques

Avant de commencer votre intégration, assurez-vous que votre environnement répond aux exigences suivantes :

- **HTTPS Uniquement** : Toutes les requêtes API doivent être effectuées via TLS 1.2+.
- **Support JSON** : Les corps de requêtes (payloads) doivent être du JSON valide.
- **Synchronisation de l'Horloge** : Assurez-vous que les horloges de vos serveurs sont synchronisées (NTP). Les signaux avec un horodatage datant de plus de 24 heures dans le passé ou de plus de 5 minutes dans le futur peuvent être rejetés.

## 2. Sélection de l'Environnement

Protegey fournit deux environnements distincts pour l'intégration :

| Environnement  | Objectif                         | URL de Base                        |
| -------------- | -------------------------------- | ---------------------------------- |
| **Sandbox**    | Intégration et Tests             | `https://sandbox-api.protegey.com` |
| **Production** | Partage d'Intelligence en Direct | `https://api.protegey.com`         |

Pour le modèle d'accès et les étapes d'approbation, voir [Accès Sandbox vs Production](/fr/platform/architecture#acces-sandbox-vs-production).

::callout{icon="i-lucide-shield-check" color="primary"}
**Isolation du Sandbox** : Toutes les données soumises au Sandbox sont logiquement isolées du réseau de production. Utilisez le Sandbox pour vérifier votre pipeline d'ingestion sans affecter les scores de risque du réseau.
::

## 3. Gestion des Clés API

Vous recevrez vos clés API via le [Portail Partenaire](https://app.protegey.com).

1. **Authentification** : Toutes les requêtes doivent inclure l'en-tête `X-Centry-Key`.
2. **Rotation des Clés** : Nous recommandons de renouveler vos clés secrètes tous les 90 jours.
3. **Sécurité** : Ne partagez jamais vos clés secrètes et ne les incluez jamais dans du code côté client (JavaScript/Mobile).

## 4. Meilleures Pratiques de Normalisation

La haute qualité des données est essentielle pour une mise en correspondance précise des entités à travers le réseau. Protegey fournit une normalisation intégrée pour les types d'entitées courants.

### Identifiants

Soumettez toujours les identifiants en **texte brut**. Protegey les normalise et les hache côté serveur via HMAC-SHA256 avec la clé réseau partagée, avant tout stockage ou liaison au graphe. Pré-hacher les identifiants côté client brisera la correspondance d'entités inter-institutions.

### Numéros de Téléphone et Indices de Pays

Pour les numéros de téléphone, fournissez un indice de pays via `primary_actor.identifiers.region` (ISO 3166-1 alpha-2). Cela aide le moteur de normalisation à résoudre les formats locaux ambigus (ex : `0244123456` → `+233244123456` lorsque `region: "GH"` est fourni).

```json
{
  "primary_actor": {
    "phone": "0244123456",
    "identifiers": {
      "region": "GH"
    }
  }
}
```

## 5. Première Ingestion de Signal

Une intégration réussie suit généralement ce flux de travail :

1. **Construction du Payload** : Formatez votre signal selon la documentation de l'[API Signals](/fr/partners/api-reference/signals).
2. **Soumission au Sandbox** : Envoyez votre premier signal au point de terminaison Sandbox.
3. **Vérification de la Réponse** : Assurez-vous de recevoir une réponse `201 Created` avec un `signal_id` unique.
4. **Vérification du Portail Partenaire** : Connectez-vous au portail et vérifiez que le signal apparaît dans votre journal d'activité.

## 6. Mise en Direct

Pour passer de l'environnement Sandbox à la Production :

1. **Demander des Clés de Production** : via le Portail Partenaire.
2. **Mettre à jour l'URL de base** : Pointez votre environnement de production vers `https://api.protegey.com`.
3. **Mode Ombre (Shadow Mode)** : Nous recommandons une période "Ombre" de 7 jours pendant laquelle vous ingérez des signaux mais n'agissez pas encore sur les scores retournés.
4. **Surveiller la Performance** : Examinez la santé de votre intégration via le tableau de bord.
