Le Sandbox (Bac à sable) Centry est un environnement complètement isolé où vous pouvez tester votre intégration sans affecter les données de production ni encourir de coûts.

## Pourquoi utiliser le Sandbox ?

- **Zéro Risque** : Testez des scénarios de fraude sans impacter vos métriques de production.
- **Haute Fidélité** : Le sandbox utilise les mêmes points de terminaison API, règles de validation et logique de traitement que la production.
- **Données Isolées** : Tous les signaux, entités et alertes sont stockés dans un schéma distinct (`sandbox`).
- **Outils de Démo** : Utilisez notre simulateur intégré pour générer instantanément des données de fraude réalistes.

## Basculer entre Environnements

Vous pouvez basculer entre les environnements **Sandbox** et **Production** en utilisant plusieurs méthodes :

### Dans le Portail Partenaire

Basculez entre les environnements à l'aide du sélecteur situé dans l'en-tête.

### Via les en-têtes API

Incluez l'environnement dans vos requêtes API :

```bash
curl -X GET https://api.protegey.com/api/v1/signals \
  -H "Authorization: Bearer VOTRE_JETON" \
  -H "X-Centry-Environment: sandbox"
```

### Via les paramètres de requête

Ajoutez `?environment=sandbox` à n'importe quel point de terminaison API :

```bash
https://api.protegey.com/api/v1/signals?environment=sandbox
```

### Via la surcharge de Session/Cookie

Définissez un cookie de session `centry_env_override=sandbox` pour un basculement persistant.

### Priorité de Détection de l'Environnement

Le système résout l'environnement dans l'ordre suivant :

1. Paramètre de requête (`?environment=sandbox`)
2. Surcharge de session/cookie (`centry_env_override`)
3. En-tête de requête (`X-Centry-Environment`)
4. Détection de domaine (sous-domaine `sandbox.*`)
5. En-tête Referer (pour les appels API cross-origin)
6. Statut de partenaire de l'utilisateur authentifié
7. **Par défaut** : `production`

::callout{type="warning"}
**Important** : Chaque environnement a son propre jeu de clés API. Assurez-vous d'utiliser la clé correcte pour l'environnement que vous ciblez.
::

## Isolation des Schémas de Base de Données

Protegey met en œuvre une **véritable isolation au niveau de la base de données** à l'aide des schémas PostgreSQL :

- **Données de production** : Stockées dans le schéma `public`
- **Données sandbox** : Stockées dans le schéma `sandbox`
- **Tables partagées** : Les utilisateurs, les partenaires et les abonnements restent uniquement dans le schéma `public`

Cette architecture offre :

- **Zéro risque** de pollution des analyses de production par les données sandbox
- **Réinitialisation facile des données** (vidage du schéma sandbox)
- **Isolation des performances** entre les environnements
- **Ségrégation des données** prête pour la conformité

## Exécution Sensible au Contexte

Toutes les requêtes et tâches en arrière-plan conservent un objet **CentryContext** immuable qui encapsule :

- L'état de l'environnement (sandbox/production)
- L'identité du partenaire (UUID)
- L'ID de suivi de la requête
- La résolution du schéma

Cela garantit que toutes les requêtes de base de données, les tâches de file d'attente et les événements de webhook utilisent automatiquement le bon schéma.

## Persistance des Données

Les données du Sandbox sont persistantes jusqu'à ce que vous choisissiez de les réinitialiser. Vous pouvez effectuer des réinitialisations avec différentes portées :

| Portée de Réinitialisation | Ce qui est supprimé                            | Cas d'utilisation                                    |
| -------------------------- | ---------------------------------------------- | ---------------------------------------------------- |
| **Full Reset**             | Toutes les données sandbox de votre partenaire | Repartir de zéro avec un environnement propre        |
| **Signals Only**           | Uniquement les enregistrements de signaux      | Effacer les signaux de test mais garder les dossiers |
| **Cases Only**             | Uniquement les enregistrements de dossiers     | Réinitialiser les enquêtes                           |
| **Entities Only**          | Uniquement les profils d'entités               | Effacer l'intelligence sur les acteurs               |

Accédez à la fonctionnalité de réinitialisation via **Sandbox > Reset** dans le Portail Partenaire ou utilisez le point de terminaison API : `POST /api/v1/partner/sandbox/reset`
