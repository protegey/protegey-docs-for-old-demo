Pour les tests avancés et la validation des performances, nous fournissons un simulateur CLI basé sur Artisan.

## Installation

Le simulateur fait partie du package Centry Core. Assurez-vous d'avoir installé la dernière version.

## Utilisation de Base

Exécutez la commande suivante pour générer des signaux pour un partenaire sandbox :

```bash
php artisan centry:simulate-signals \
  --template=account_takeover \
  --partner=<UUID_PARTENAIRE> \
  --count=50
```

## Options

| Option | Description | Par Défaut |
|--------|-------------|-------------|
| `--template` | Le nom du modèle à utiliser. | Requis |
| `--partner` | L'UUID de votre partenaire sandbox. | Requis |
| `--count` | Nombre de signaux à générer. | 20 |
| `--rate` | Signaux par minute (limitation de débit). | 10 |
| `--severity` | Forcer un profil de risque spécifique : `critical`, `high`, `medium`, `low`. | Distribution aléatoire |
| `--list` | Lister tous les modèles disponibles. | N/A |

### Utilisation de l'Option Severity

Forcez tous les signaux générés à un niveau de risque spécifique :

```bash
# Générer 50 signaux de risque critique pour tester les seuils d'alerte
php artisan centry:simulate-signals \
  --template=account_takeover \
  --partner=<UUID_PARTENAIRE> \
  --count=50 \
  --severity=critical

# Générer des signaux de faible risque pour tester des scénarios de faux négatifs
php artisan centry:simulate-signals \
  --template=stolen_financials \
  --partner=<UUID_PARTENAIRE> \
  --count=30 \
  --severity=low
```

::callout{type="info"}
**Cas d'utilisation** : L'option `--severity` est utile lors du test de règles d'alerte spécifiques, de la logique de priorisation des dossiers ou de la distribution de la charge de travail des analystes. Sans ce drapeau, les signaux suivent la distribution naturelle des risques (10 % critique, 20 % élevé, 30 % moyen, 40 % faible).
::

## Sécurité de l'Environnement

Le simulateur CLI inclut des protections intégrées pour éviter toute utilisation accidentelle en production :
- Il ciblera **uniquement** les URL contenant `sandbox`, `localhost` ou `127.0.0.1`.
- Il **nécessite** un partenaire qui est explicitement en mode Sandbox.
- Il **nécessite** une clé API préfixée sandbox (`cen_test_sk_*`).

## Visualisation des Résultats

Une fois générés, les signaux apparaîtront dans vos **Signal Logs** (assurez-vous que le filtre d'environnement est réglé sur **Sandbox**).
Visualisez les signaux dans le portail partenaire : `/signals?environment=sandbox`

## Modèles Personnalisés

Vous pouvez ajouter vos propres modèles en plaçant des fichiers JSON dans `storage/app/signal-templates/`. Consultez la [Référence des Modèles](./signal-templates) pour plus de détails.
