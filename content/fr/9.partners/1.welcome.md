# Documentation Partenaire

::callout{icon="i-lucide-shield-check" color="green"}
**Accès Autorisé** : Vous êtes connecté en tant que Partenaire approuvé. Cette documentation contient des détails techniques de mise en œuvre non accessibles au public.
::

Bienvenue dans la documentation partenaire de Protegey. C'est votre manuel technique pour l'intégration au réseau d'intelligence contre la fraude Protegey.

## Votre Rôle dans le Réseau

En tant que partenaire, vous êtes un nœud dans un système de défense collective. La qualité de votre intégration a un impact direct sur la sécurité de l'ensemble de l'écosystème financier.

### Obligations Clés

1.  **Protéger les Identifiants** : Vos clés API sont les clés du château. Ne les partagez jamais et ne les incluez jamais dans vos dépôts de code.
2.  **Signaler des Signaux Précis** : "Données erronées en entrée, résultats erronés en sortie." Assurez-vous que votre logique de marquage de la fraude est solide avant de soumettre des signaux.
3.  **Respecter la Confidentialité** : Envoyez uniquement les données requises par le schéma. N'envoyez pas de données personnelles (PII) non hachées dans les champs de métadonnées facultatifs.

## Modèle de Responsabilité Partagée

La sécurité est un partenariat.

| Protegey est Responsable de       | Vous êtes Responsable de                 |
| --------------------------------- | ---------------------------------------- |
| L'infrastructure de la plateforme | La sécurité de vos clés API              |
| Chiffrement des données au repos  | Transmission sécurisée des données (TLS) |
| Précision du modèle de risque     | Précision des signaux fournis            |
| Disponibilité du réseau           | Gestion gracieuse des échecs de l'API    |

## Reconnaissances Juridiques

En utilisant la documentation détaillée et les points de terminaison de l'API, vous réaffirmez votre accord avec :

- L'**Accord de Services Principal (MSA)**
- L'**Accord de Traitement des Données (DPA)**
- La **Politique d'Utilisation Acceptable (AUP)**
