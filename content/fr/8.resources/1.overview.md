## Glossaire

| Terme                  | Définition                                                                                |
| ---------------------- | ----------------------------------------------------------------------------------------- |
| **Signal**             | Un point de donnée brut envoyé à Protegey (ex : ID d'appareil, adresse IP).               |
| **Session**            | Une période continue d'activité de l'utilisateur regroupée par un identifiant de session. |
| **Verdict**            | Le résultat final du moteur de décision (AUTORISER, BLOQUER, DÉFI).                       |
| **Portail Partenaire** | Le tableau de bord où vous gérez les clés, les politiques et visualisez les analyses.     |
| **Environnement**      | Contextes isolés pour les tests (Sandbox) et pour la mise en direct (Production).         |

## FAQ

### Que se passe-t-il si l'API est indisponible ?

Nos SDK sont conçus pour "échouer en mode ouvert" (fail open). Si l'API Protegey est inaccessible, votre application doit par défaut choisir "AUTORISER" (ou votre solution de repli préférée) pour éviter de bloquer les utilisateurs légitimes.

### Puis-je faire des tests en Production ?

Non. Veuillez utiliser l'environnement Sandbox pour tous vos tests. Le trafic en Production affecte votre facturation et votre profil de risque.

### À quelle fréquence les scores de risque sont-ils mis à jour ?

En temps réel. Dès que nous recevons un signal, le score de risque est recalculé en fonction de la dernière intelligence globale disponible.
