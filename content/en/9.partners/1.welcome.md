Welcome to the Protegey Partner Documentation. This is your technical manual for integrating with the Protegey fraud intelligence network.

## Your Role in the Network

As a partner, you are a node in a collective defense system. Your integration quality directly impacts the safety of the entire financial ecosystem.

### Key Obligations

1.  **Protect Credentials**: Your API keys are the keys to the castle. Never share them or commit them to code repositories.
2.  **Report Accurate Signals**: "Garbage in, garbage out." Ensure your logic for flagging fraud is sound before submitting signals.
3.  **Respect Privacy**: Only send the data required by the schema. Do not send Unhashed PII in optional metadata fields.

## Shared Responsibility Model

Security is a partnership.

| Protegey Responsible For | You Responsible For              |
| ------------------------ | -------------------------------- |
| Platform Infrastructure  | Your API Key Security            |
| Data Encryption At Rest  | Secure Data Transmission (TLS)   |
| Risk Model Accuracy      | Signal Accuracy                  |
| Network Availability     | Handling API Failures Gracefully |

## Getting Support

If you encounter issues with integration, signal scoring, or compliance workflows, open a support thread directly from the partner portal:

1. Navigate to **Settings → Support**
2. Click **New Thread** and select the subject category
3. Attach relevant payloads or screenshots (up to 5 files, 10 MB each)
4. For issues related to a specific case or alert, use the **Get Help** button on that resource's detail page — this links the thread directly to the resource

The support team responds within the SLA for your priority level. Real-time responses arrive via WebSocket — no need to refresh.

See the [Support operational guide](/partners/operational-guides/support) and [Support API reference](/partners/api-reference/support) for full details.
