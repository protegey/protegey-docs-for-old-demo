# Monitoring & Logs

Effective monitoring ensures your fraud defense is active and healthy.

## What to Monitor

We recommend instrumenting your application to track:

### 1. API Availability
- **Success Rate**: % of 2xx responses.
- **Failure Rate**: % of 4xx/5xx responses.
- **Alert**: Trigger if 5xx rate > 1% for 5 minutes.

### 2. Latency
- **Metric**: P95 and P99 latency of Protegey API calls.
- **Alert**: Trigger if P95 > 1000ms.

### 3. Risk Score Distribution
- **Metric**: Histogram of returned risk scores.
- **Alert**: Detecting a huge spike in "High Risk" scores (could indicate an attack or a bug).

## Partner Portal Logs

The Partner Portal provides a **Request Log** viewer.
- View recent API requests.
- Filter by status code or endpoint.
- Inspect request/response payloads (Sensitive data masked).
- **Retention**: Logs are available for 7 days in the Portal.

## Data Dog / Prometheus Integration

(Enterprise Only)
We can ship your API usage logs directly to your Datadog or Prometheus instance. Contact your account manager to enable this feature.
