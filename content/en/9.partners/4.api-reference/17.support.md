# Support Threads

The Support Threads API provides an in-platform messaging channel between your organisation and the Protegey support team. Threads persist across sessions, support file attachments, and deliver messages in real-time via WebSocket.

::callout{type="info"}
Support threads are scoped to your partner account. All agents and members of your team share a single thread inbox.
::

---

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/partner/support/threads` | List all support threads |
| `POST` | `/api/v1/partner/support/threads` | Create a new thread |
| `GET` | `/api/v1/partner/support/threads/{uuid}` | Get thread detail + all messages |
| `POST` | `/api/v1/partner/support/threads/{uuid}/messages` | Add a message to a thread |
| `GET` | `/api/v1/partner/support/attachments/{uuid}` | Download an attachment |

## List Threads

```http
GET /api/v1/partner/support/threads
Authorization: Bearer {token}
```

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `status` | string | Filter by status: `open`, `pending`, `closed` |
| `subject` | string | Filter by subject category |
| `per_page` | integer | Results per page (default: 20, max: 100) |
| `page` | integer | Page number |

## Create Thread

```http
POST /api/v1/partner/support/threads
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `subject` | string | ✓ | Thread subject category (see enum below) |
| `title` | string | ✓ | Short summary (max 255 chars) |
| `message` | string | ✓ | Initial message body (max 10,000 chars) |
| `priority` | string | | `low`, `normal`, `high`, `urgent` — default `normal` |
| `context_type` | string | | `case` or `alert` — links thread to a specific resource |
| `context_id` | string | | UUID of the linked case or alert |
| `attachments[]` | file | | Up to 5 files per message (see attachment rules) |

### Subject Enum

| Value | Use Case |
|-------|----------|
| `technical_issue` | API errors, integration failures, unexpected behaviour |
| `signal_question` | Questions about specific signals or scoring |
| `integration_support` | Onboarding, SDK setup, webhook configuration |
| `billing` | Subscription, invoicing, plan changes |
| `other` | Anything not covered above |

### Example Request

```bash
curl -X POST https://api.protegey.com/api/v1/partner/support/threads \
  -H "Authorization: Bearer $TOKEN" \
  -F "subject=technical_issue" \
  -F "title=Signal ingestion returning 422 after UFES schema validation" \
  -F "message=We are consistently getting 422 responses when submitting signals with nested device metadata. The error references ufes_version but our payload matches the v2 schema." \
  -F "priority=high" \
  -F "attachments[]=@/tmp/error-payload.json"
```

## Add Message

```http
POST /api/v1/partner/support/threads/{uuid}/messages
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

Adds a reply to an existing thread. If the thread is `closed`, sending a message automatically re-opens it.

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `message` | string | ✓ | Message body (max 10,000 chars) |
| `attachments[]` | file | | Up to 5 files per message |

### Response

```json
{
  "data": {
    "uuid": "msg_01HZ9K2M4N5P6Q7R8S9T0UV1BB",
    "body": "Confirmed, removing the empty string fixed it. Thank you.",
    "sender_type": "partner",
    "sender_name": "Ada Boateng",
    "attachments": [],
    "created_at": "2026-03-16T12:10:00Z"
  }
}
```

## Download Attachment

```http
GET /api/v1/partner/support/attachments/{uuid}
Authorization: Bearer {token}
```

Returns the attachment as a binary stream. Attachments are partner-scoped — you cannot download attachments from another partner's thread.

| Response Header | Value |
|----------------|-------|
| `Content-Type` | Original MIME type |
| `Content-Disposition` | `attachment; filename="original-name.ext"` |
| `Content-Length` | File size in bytes |

---

## Attachment Rules

| Rule | Limit |
|------|-------|
| Files per message | 5 |
| Max file size | 10 MB per file |
| Allowed types | `jpg`, `png`, `gif`, `webp`, `pdf`, `txt` |
| Storage | Encrypted at rest, access-logged, auto-purged after 180 days |

## Real-Time Updates

Support threads broadcast new messages via [Laravel Reverb](https://reverb.laravel.com/) WebSocket. Subscribe to the private channel for a thread to receive real-time delivery without polling.

```javascript
import Echo from 'laravel-echo';

const echo = new Echo({ broadcaster: 'reverb', ... });

echo.private(`support.${threadUuid}`)
    .listen('.MessageCreated', (event) => {
        console.log('New message:', event.message);
    });
```

### Events

| Event | Payload |
|-------|---------|
| `.MessageCreated` | `{ message: { uuid, body, sender_type, sender_name, created_at } }` |
| `.ThreadStatusChanged` | `{ status: 'open' \| 'pending' \| 'closed' }` |

## Rate Limits

| Operation | Limit |
|-----------|-------|
| List / read threads | 60 requests / minute |
| Create thread | 10 requests / minute |
| Send message | 30 requests / minute |
| Download attachment | 60 requests / minute |

---

## Error Codes

| Code | Meaning |
|------|---------|
| `422` | Validation failed — check `errors` object |
| `403` | Thread does not belong to your account |
| `404` | Thread or attachment not found |
| `413` | Attachment exceeds 10 MB |
| `415` | Unsupported file type |
| `429` | Rate limit exceeded |
