The KYB (Know Your Business) API lets you collect, review, and risk-screen business customer applications through configurable questionnaires. Partners build intake forms, send signed invites, and make approval decisions — with sanctions and PEP screening running automatically on approval.

::callout{icon="i-lucide-building-2" color="blue"}
**Permissions required**: `kyb.invite` to send invites · `kyb.review` to decide applications · `kyb.manage` to build questionnaires. All three are included in the default Partner role.
::

---

## Questionnaire Management

Questionnaires are versioned intake forms composed of sections and typed questions. A questionnaire is **locked automatically** the moment its first invite is sent — after that, clone it to make changes.

### List Questionnaires

Returns partner-specific questionnaires plus any active global defaults.

```http
GET /api/v1/partner/kyb/questionnaires
Authorization: Bearer {token}
```

```json
{
  "data": [
    {
      "uuid": "q_01HZKJ...",
      "title": "Business Onboarding — Standard",
      "version": "1.0",
      "is_active": true,
      "is_default": true,
      "is_locked": false,
      "question_count": 14,
      "created_at": "2026-04-01T09:00:00Z"
    }
  ]
}
```

### Get Questionnaire

Returns the questionnaire with its full question list.

```http
GET /api/v1/partner/kyb/questionnaires/{uuid}
Authorization: Bearer {token}
```

```json
{
  "data": {
    "uuid": "q_01HZKJ...",
    "title": "Business Onboarding — Standard",
    "version": "1.0",
    "is_locked": false,
    "document_requirements": [
      { "document_type": "certificate_of_incorporation", "is_required": true },
      { "document_type": "aml_policies_and_procedures", "is_required": true },
      { "document_type": "proof_of_address_business", "is_required": false }
    ],
    "questions": [
      {
        "uuid": "qn_01HZKJ...",
        "section": "Business Identity",
        "order_index": 1,
        "type": "text",
        "label": "Registered business name",
        "help_text": "Enter the exact name as it appears on your certificate of incorporation.",
        "is_required": true,
        "is_screening_identifier": true,
        "options": null,
        "conditions": [],
        "validation_rules": { "max_length": 255 }
      }
    ]
  }
}
```

### Create Questionnaire

```http
POST /api/v1/partner/kyb/questionnaires
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "title": "Fintech Partner KYB v2",
  "version": "2.0",
  "is_default": false,
  "document_requirements": [
    { "document_type": "certificate_of_incorporation", "is_required": true },
    { "document_type": "payment_services_license", "is_required": true }
  ],
  "questions": [
    {
      "section": "Business Identity",
      "order_index": 1,
      "type": "text",
      "label": "Registered business name",
      "is_required": true,
      "is_screening_identifier": true
    },
    {
      "section": "Business Identity",
      "order_index": 2,
      "type": "select",
      "label": "Country of incorporation",
      "is_required": true,
      "options": ["GH", "NG", "SN", "KE", "ZA"]
    },
    {
      "section": "Ownership",
      "order_index": 3,
      "type": "boolean",
      "label": "Does any individual own more than 25% of the business?",
      "is_required": true
    },
    {
      "section": "Ownership",
      "order_index": 4,
      "type": "text",
      "label": "Name of beneficial owner (>25%)",
      "is_required": true,
      "conditions": [
        { "question_uuid": "qn_01...", "operator": "truthy" }
      ]
    }
  ]
}
```

**Question types:** `text` · `textarea` · `boolean` · `select` · `multi_select` · `number` · `date`

**Conditional rendering** — a question is only shown when all its `conditions` pass:

| Field | Description |
|---|---|
| `question_uuid` | The UUID of the controlling question |
| `operator` | `eq` (equals) · `neq` (not equals) · `truthy` (any non-false/null value) |
| `value` | Required for `eq` and `neq`; omit for `truthy` |

::callout{type="warning"}
Mark exactly **one** question per questionnaire with `"is_screening_identifier": true`. That answer is used as the business name for AML screening on approval. If none is marked, screening is skipped.
::

### Update Questionnaire

Only permitted when `is_locked: false`.

```http
PUT /api/v1/partner/kyb/questionnaires/{uuid}
Authorization: Bearer {token}
Content-Type: application/json
```

Returns `409 Conflict` if the questionnaire is already locked.

### Clone Questionnaire

Creates a full copy (with all questions) under a new version. Use this when you need to modify a locked questionnaire.

```http
POST /api/v1/partner/kyb/questionnaires/{uuid}/clone
Authorization: Bearer {token}
```

```json
{
  "data": {
    "uuid": "q_01HZKN...",
    "title": "Business Onboarding — Standard",
    "version": "1.1",
    "is_locked": false
  }
}
```

## Invite Management

### List Invites

```http
GET /api/v1/partner/kyb/invites
Authorization: Bearer {token}
```

Query parameters: `status` · `per_page`

```json
{
  "data": [
    {
      "uuid": "inv_01HZKJ...",
      "applicant_email": "cfo@acme-fintech.com",
      "applicant_name": "Kwame Mensah",
      "status": "in_progress",
      "questionnaire_uuid": "q_01HZKJ...",
      "expires_at": "2026-05-27T09:00:00Z",
      "opened_at": "2026-04-28T11:30:00Z",
      "submitted_at": null,
      "created_at": "2026-04-27T09:00:00Z"
    }
  ]
}
```

**Invite statuses:**

| Status | Description |
|---|---|
| `pending` | Sent, not yet opened |
| `opened` | Applicant clicked the link |
| `in_progress` | Applicant has saved at least one answer |
| `submitted` | Application submitted |
| `expired` | 30-day window passed without submission |

### Send Invite

```http
POST /api/v1/partner/kyb/invites
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "applicant_email": "cfo@acme-fintech.com",
  "applicant_name": "Kwame Mensah",
  "questionnaire_uuid": "q_01HZKJ..."
}
```

Omit `questionnaire_uuid` to use your active default questionnaire. Sending this invite locks the questionnaire automatically if it wasn't already.

```json
{
  "data": {
    "uuid": "inv_01HZKJ...",
    "status": "pending",
    "expires_at": "2026-05-27T09:00:00Z",
    "portal_url": "https://app.protegey.com/apply/a3f8c..."
  }
}
```

The applicant receives an email with a link to the applicant portal. Tokens are single-use and expire after 30 days.

## Application Management

### List Applications

```http
GET /api/v1/partner/kyb/applications
Authorization: Bearer {token}
```

Query parameters: `status` · `per_page`

```json
{
  "data": [
    {
      "uuid": "app_01HZKJ...",
      "applicant_name": "Kwame Mensah",
      "applicant_email": "cfo@acme-fintech.com",
      "status": "submitted",
      "submitted_at": "2026-04-28T14:00:00Z",
      "reviewed_at": null,
      "reviewer": null
    }
  ]
}
```

**Application statuses:**

| Status | Description |
|---|---|
| `draft` | Applicant has started but not submitted |
| `submitted` | Submission received; awaiting review |
| `under_review` | Reviewer has opened the application |
| `more_info_required` | Reviewer requested clarification; applicant can resubmit |
| `approved` | Application approved; entity created in graph |
| `rejected` | Application rejected (terminal) |

### Get Application Detail

```http
GET /api/v1/partner/kyb/applications/{uuid}
Authorization: Bearer {token}
```

```json
{
```

### Decide Application

Requires `kyb.review` permission.

```http
POST /api/v1/partner/kyb/applications/{uuid}/decide
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "decision": "approved",
  "notes": "All documents verified. Entity created for monitoring."
}
```

`decision` values: `approved` · `rejected` · `more_info_required`

`notes` is optional for `approved` and `rejected`; recommended for `more_info_required` to guide the applicant's resubmission.

```json
{
  "data": {
    "uuid": "app_01HZKJ...",
    "status": "approved",
    "decision_at": "2026-04-28T16:00:00Z",
    "entity_uuid": "ent_01HZKJ..."
  }
}
```

::callout{icon="i-lucide-shield" color="amber"}
**Risk screening runs on approval.** The business name (from the `is_screening_identifier` question) is screened against sanctions and PEP databases. If `risk_score > 0.75`, `is_pep = true`, or a sanctions match is found, an Enhanced Due Diligence (EDD) case is automatically created.
::

`approved` and `rejected` are **terminal** — they cannot be redecided. `more_info_required` allows the applicant to resubmit, after which the application returns to `submitted`.

### Download Document

```http
GET /api/v1/partner/kyb/applications/{uuid}/documents/{document}/download
Authorization: Bearer {token}
```

Returns a time-limited signed S3 URL for the document file.

## Applicant Portal Endpoints

These endpoints use **token authentication** — no OAuth bearer token is required. The invite token is embedded in the URL. They are public-facing and power the `/apply/{token}` portal.

### Load Application State

```http
GET /api/v1/kyb/apply/{token}
```

Returns the questionnaire structure, saved answers, uploaded documents, and current application status.

```json
{
  "data": {
    "invite": {
      "applicant_name": "Kwame Mensah",
      "status": "in_progress",
      "expires_at": "2026-05-27T09:00:00Z"
    },
    "questionnaire": {
      "title": "Business Onboarding — Standard",
      "document_requirements": [...],
      "questions": [...]
    },
    "progress": {
      "qn_01...": "Acme Fintech Ltd",
      "qn_02...": "GH"
    },
    "documents": [...],
    "application_status": "in_progress"
  }
}
```

### Save Progress

Incrementally saves answers. Can be called as often as needed — all fields are optional (only supplied answers are upserted).

```http
POST /api/v1/kyb/apply/{token}/progress
Content-Type: application/json
```

```json
{
  "answers": [
    { "question_uuid": "qn_01...", "value": "Acme Fintech Ltd" },
    { "question_uuid": "qn_02...", "value": "GH" }
  ]
}
```

### Upload Document

```http
POST /api/v1/kyb/apply/{token}/documents
Content-Type: multipart/form-data
```

| Field | Type | Description |
|---|---|---|
| `file` | File | Max 10 MB. Accepted: pdf, jpg, png, docx |
| `document_type` | string | See document types table below |

```json
{
  "data": {
    "uuid": "doc_01HZKJ...",
    "document_type": "certificate_of_incorporation",
    "original_filename": "cert.pdf",
    "file_size_bytes": 204800,
    "status": "uploaded",
    "uploaded_at": "2026-04-28T13:45:00Z"
  }
}
```

### Delete Document

```http
DELETE /api/v1/kyb/apply/{token}/documents/{document}
```

Returns `204 No Content`.

### Submit Application

Validates all required questions are answered and all required document types are uploaded before accepting the submission.

```http
POST /api/v1/kyb/apply/{token}/submit
```

```json
{
  "data": {
    "application_uuid": "app_01HZKJ...",
    "status": "submitted",
    "submitted_at": "2026-04-28T14:00:00Z"
  }
}
```

Returns `422 Unprocessable Entity` with a list of missing required fields if validation fails.

## Document Types

| Type | Label | Typically Required |
|---|---|---|
| `certificate_of_good_standing` | Certificate of Good Standing | No |
| `certificate_of_incorporation` | Certificate of Incorporation | Yes |
| `memorandum_and_articles` | Memorandum & Articles of Association | Yes |
| `organisational_chart` | Organisational Chart | No |
| `owner_id` | Beneficial Owner ID | Yes |
| `proof_of_address_owner` | Proof of Address (Owner) | No |
| `proof_of_address_business` | Proof of Address (Business) | No |
| `financial_statements` | Financial Statements (Last 2 Years) | No |
| `regulatory_registration` | Regulatory Registration Certificate | No |
| `payment_services_license` | Payment Services License | No |
| `aml_policies_and_procedures` | AML Policies & Procedures | Yes |
| `aml_kyc_review` | AML/KYC Independent Review | No |
| `aml_training_records` | AML Training Records | No |
| `pci_dss_compliance` | PCI DSS Compliance Certificate | No |
| `safeguarding_policy` | Client Funds Safeguarding Policy | No |
| `board_resolution` | Board Resolution / Authorization Letter | No |
| `other` | Other Supporting Document | No |

"Typically Required" reflects platform defaults. Your questionnaire's `document_requirements` config controls which types are actually required for your applicants.

## Permissions

| Permission | Who needs it | Actions |
|---|---|---|
| `kyb.invite` | Relationship managers, compliance officers | Send invites, list invites and applications |
| `kyb.review` | Compliance reviewers | Make approve/reject/more_info decisions, download documents |
| `kyb.manage` | Admin users | Create, update, and clone questionnaires |

All three permissions are available on all partner subscription tiers.
