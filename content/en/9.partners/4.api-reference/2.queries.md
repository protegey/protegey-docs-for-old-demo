# Risk Assessment API

The Risk Assessment API allows you to retrieve a real-time risk decision for an entity. This endpoint is designed to be called synchronously during your user flows (e.g., signup, checkout).

## Endpoint

```http
POST /api/v1/risk/assess
```

## Request Schema

### Headers

| Header | Value | Required | Description |
|--------|-------|----------|-------------|
| `Content-Type` | `application/json` | Yes | Standard JSON payload. |
| `X-Centry-Key` | `cen_live_sk_...` | Yes | Your Production Secret Key. |

### Body Parameters

```typescript
interface RiskAssessmentRequest {
  entity_type: 'email' | 'phone' | 'ip' | 'device_id' | 'crypto_address';
  identifier: string; // The value to assess (e.g., email address)
}
```

### Example Request

```bash
curl -X POST "https://api.protegey.com/v1/risk/assess" \
  -H "Content-Type: application/json" \
  -H "X-Centry-Key: cen_live_sk_..." \
  -d '{
    "entity_type": "email",
    "identifier": "fraudster@example.com"
  }'
```

## Response Schema

```typescript
interface RiskAssessmentResponse {
  decision: 'ALLOW' | 'REVIEW' | 'BLOCK';
  risk_score: number; // 0-100
  reasons: string[]; // List of contributing factors
}
```

### Decision Logic

| Decision | Risk Score | Meaning | Suggested Action |
|----------|------------|---------|------------------|
| `ALLOW` | < 50 | Low risk. | Proceed with transaction. |
| `REVIEW` | 50 - 79 | Medium risk. | Trigger step-up auth (2FA) or manual review. |
| `BLOCK` | >= 80 | High/Critical risk. | Deny the transaction/signup. |

### Example Response

```json
{
  "decision": "BLOCK",
  "risk_score": 85,
  "reasons": [
    "VELOCITY_HIGH",
    "NETWORK_BLOCKLIST_MATCH"
  ]
}
```

### Error Responses

**400 Bad Request**
```json
{
    "message": "The entity type must be one of: email, phone, ip, device_id, crypto_address."
}
```

**401 Unauthorized**
```json
{
    "message": "Partner authentication required"
}
```
