# Authentication

Protegey uses **API Key Authentication**.

::callout{icon="i-lucide-key" color="blue"}
**Manage Keys**: You can generate and revoke keys in the [Partner Portal](https://app.protegey.com/settings/api-keys).
::

## Request Header

All API requests must include your **Secret API Key** in the `X-Centry-Key` header.

```bash
curl -X GET https://api.protegey.com/v1/health \
  -H "X-Centry-Key: cen_live_sk_592834..."
```

## Key Types

| Type           | Prefix       | Description                               | Usage                                           |
| -------------- | ------------ | ----------------------------------------- | ----------------------------------------------- |
| **Secret Key** | `..._sk_...` | **CONFIDENTIAL**. Grants full API access. | Server-side API calls.                          |
| **Public Key** | `..._pk_...` | Public identification.                    | Client-side tracking (future) or Basic Auth ID. |

## Key Lifecycle

### Generation

Keys are generated cryptographically. The **Secret Key** is displayed **only once**.

- Format: `cen_[env]_sk_[random_string]`
- Example: `cen_live_sk_8f7d6a5...`

### Rotation

We recommend rotating keys every 90 days.

1. Generate a new key in the Portal.
2. Update your application environment variables.
3. Verify the new key is working.
4. Revoke the old key in the Portal.

### Revocation

If you suspect a key compromise:

1. **Immediately** revoke the key in the Partner Portal.
2. This will instantly degrade any active sessions using that key.
3. Contact [security@protegey.com](mailto:security@protegey.com) to request an audit of activity.

## IP Allowlisting

For an additional layer of security, you can restrict key usage to specific IP addresses or CIDR blocks.

- Configure this in **Settings > Security > IP Allowlist**.
- Requests from unauthorized IPs will be rejected with `403 Forbidden` even if the API key is valid.

## Error Codes

| Code               | Meaning                          | Action                            |
| ------------------ | -------------------------------- | --------------------------------- |
| `401 Unauthorized` | Missing or invalid key           | Check your `X-Centry-Key` header. |
| `403 Forbidden`    | Valid key, but permission denied | Check IP allowlist or key scopes. |
