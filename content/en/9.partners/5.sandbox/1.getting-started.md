# Getting Started with Sandbox

The Centry Sandbox is a completely isolated environment where you can test your integration without affecting production data or incurring costs.

## Why use Sandbox?

- **Zero Risk**: Test fraud scenarios without impacting your production metrics.
- **High Fidelity**: The sandbox uses the same API endpoints, validation rules, and processing logic as production.
- **Isolated Data**: All signals, entities, and alerts are stored in a separate schema (`sandbox`).
- **Demo Tools**: Use our built-in simulator to generate realistic fraud data instantly.

## Switching Environments

In the Partner Portal, you can toggle between **Sandbox** and **Production** environments using the switcher in the header.

> [!NOTE]
> Each environment has its own set of API keys. Ensure you use the correct key for the environment you are targeting.

## Data Persistence

Sandbox data is persistent until you choose to reset it. You can perform a full or granular reset via the **Sandbox > Reset** page.
