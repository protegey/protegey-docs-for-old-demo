For advanced testing and performance validation, we provide an Artisan-based CLI simulator.

## Installation

The simulator is part of the Centry Core package. Ensure you have the latest version installed.

## Basic Usage

Run the following command to generate signals for a sandbox partner:

```bash
php artisan centry:simulate-signals \
  --template=account_takeover \
  --partner=<PARTNER_UUID> \
  --count=50
```

## Options

| Option | Description | Default |
|--------|-------------|---------|
| `--template` | The name of the template to use. | Required |
| `--partner` | Your sandbox partner UUID. | Required |
| `--count` | Number of signals to generate. | 20 |
| `--rate` | Signals per minute (rate limiting). | 10 |
| `--severity` | Force a specific risk profile: `critical`, `high`, `medium`, `low`. | Random distribution |
| `--list` | List all available templates. | N/A |

### Using the Severity Option

Force all generated signals to a specific risk level:

```bash
# Generate 50 critical-risk signals for alert threshold testing
php artisan centry:simulate-signals \
  --template=account_takeover \
  --partner=<PARTNER_UUID> \
  --count=50 \
  --severity=critical

# Generate low-risk signals to test false negative scenarios
php artisan centry:simulate-signals \
  --template=stolen_financials \
  --partner=<PARTNER_UUID> \
  --count=30 \
  --severity=low
```

::callout{type="info"}
**Use Case**: The `--severity` option is useful when testing specific alert rules, case prioritization logic, or analyst workload distribution. Without this flag, signals follow the natural risk distribution (10% critical, 20% high, 30% medium, 40% low).
::

## Environment Safety

The CLI simulator includes built-in guards to prevent accidental production usage:
- It will **only** target URLs containing `sandbox`, `localhost`, or `127.0.0.1`.
- It **requires** a partner that is explicitly in Sandbox Mode.
- It **requires** a sandbox-prefixed API key (`cen_test_sk_*`).

## Viewing Results

Once generated, signals will appear in your **Signal Logs** (ensure the environment filter is set to **Sandbox**).
View signals in partner portal: `/signals?environment=sandbox`

## Custom Templates

You can add your own templates by placing JSON files in `storage/app/signal-templates/`. See the [Template Reference](./signal-templates) for details.
