# Signal Template Reference

Signal templates use a JSON structure to define the payload and variable resolution strategies.

## Template Structure

```json
{
  "name": "Template Display Name",
  "description": "Short description of the scenario",
  "signal_type": "ACCOUNT_TAKEOVER",
  "template": {
    "actor": {
      "hashed_id": "{{PHONE_NUMBER}}",
      "device_fingerprint": "{{DEVICE_ID}}"
    },
    "event": {
      "type": "ACCOUNT_TAKEOVER",
      "timestamp": "{{TIMESTAMP}}"
    }
  },
  "variables": {
    "PHONE_NUMBER": "faker:phoneNumber:GH",
    "DEVICE_ID": "uuid",
    "TIMESTAMP": "now"
  }
}
```

## Variable Strategies

| Strategy | Syntax | Example |
|----------|--------|---------|
| **Faker** | `faker:<method>:<args>` | `faker:email`, `faker:phoneNumber:GH` |
| **Random** | `random:<min>:<max>` | `random:100:5000` |
| **Enum** | `enum:<val1>,<val2>` | `enum:GH,NG,SN` |
| **Now** | `now` | Current ISO 8601 timestamp |
| **UUID** | `uuid` | Generates a fresh UUID v4 |

## Variable Overrides

When using the `DemoSignalService` programmatically, you can pass an overrides array to force specific values for certain variables.

```php
$service->generate($partner, 'account_takeover', 1, [
    'PHONE_NUMBER' => '0240000000'
]);
```
