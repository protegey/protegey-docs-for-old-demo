Joining the Protegey network is a curated process. Because our effectiveness relies on the quality of intelligence shared, we rigorously vet every partner.

## The Journey

### Stage 1: Discovery & Evaluation

_Current State_

You are exploring this public documentation to determine if Protegey fits your needs.

- **Action**: Review [Overview](/overview), [Platform Architecture](/platform), and [Compliance](/compliance).
- **Goal**: Confirm strategic fit.

### Stage 2: Application

_Duration: 1-3 Days_

Submit your application to join the network.

- **Requirement**: You must be a regulated entity or verified business.
- **Check**: We verify your corporate identity and regulatory status.
- **Outcome**: Invitation to the Sandbox Environment.

### Stage 3: Sandbox Integration

_Duration: 1-2 Weeks_

You receive access to the **Partner Portal** and **Sandbox API** with a complete, isolated testing environment.

**What You Get**:

- **Sandbox API Keys**: Test API keys for development
- **Partner Portal Access**: Web dashboard with full feature access
- **Physical Data Isolation**: Sandbox uses separate PostgreSQL schema - zero risk to production
- **Demo Signal Generation**: Generate realistic fraud signals with varied risk profiles
- **Full Technical Documentation**: Complete API reference and integration guides

**Key Features Available**:

**1. Sandbox Environment**

- **Physical Schema Separation**: Complete database isolation using PostgreSQL schemas
- **Environment Switching**: Toggle between sandbox and production seamlessly
- **Demo Data Generation**:
  - Generate 1-100 signals with realistic risk distribution (10% critical, 20% high, 30% medium, 40% low)
  - 5+ fraud signal templates (account takeover, stolen financials, synthetic identity, etc.)
  - Africa-specific data patterns (phone numbers, currencies, countries)
- **Granular Reset**: Reset specific data types (signals only, entities only, cases only, etc.)
- **Weekly Auto-Reset**: Automatic cleanup every Sunday at 00:00 UTC

**2. Transaction Monitoring**

- Real-time fraud signal feed with filtering
- Risk scoring and decision making
- Transaction analytics and reporting
- CSV export functionality

**3. Case Management**

- Create fraud investigation cases manually or from signals
- Add notes and evidence attachments
- Track case status and priority
- Assignment and team collaboration
- Complete timeline view of all activities

**4. Alert Management**

- Automated alert generation based on risk thresholds
- Alert triage workflow (acknowledge, resolve, mark false positive)
- Alert statistics and performance tracking

**5. Entity Intelligence**

- Entity risk profiles and history
- Network relationship discovery
- Status lifecycle management (flagged → confirmed → cleared)
- Cross-transaction pattern analysis

**6. Analytics Dashboard**

- Performance metrics and KPIs
- Risk heatmaps by time/geography
- Decision trends and patterns
- Team performance tracking

**Integration Tasks**:

- **Task 1**: Signal ingestion - Submit test fraud signals via API
- **Task 2**: Risk assessment - Query entity risk scores
- **Task 3**: Decision handling - Process risk decisions in your application
- **Task 4**: Webhook configuration - Set up webhook endpoint for real-time notifications
- **Task 5**: Error handling - Test error scenarios using magic values
- **Task 6**: Case workflows - Create and manage fraud investigation cases

**Validation Checklist**:

- ✅ Successfully submit signals to sandbox API
- ✅ Handle all error responses (400, 401, 429, 500)
- ✅ Receive and verify webhook signatures
- ✅ Create cases from high-risk signals
- ✅ Generate and analyze demo data patterns
- ✅ Test environment switching (sandbox ↔ production)
- ✅ Validate data isolation (sandbox data doesn't leak to production)

::callout{icon="i-lucide-database" color="blue"}
**True Isolation**: Protegey's sandbox uses PostgreSQL schema-level separation. Your test data is physically separated from production, ensuring zero risk of contamination.
::

### Stage 4: Production Approval

_Duration: 2-5 Days_

Once technical integration is verified, we finalize the partnership.

- **Legal**: Sign the Master Services Agreement (MSA) and Data Processing Agreement (DPA).
- **Security**: Complete a lightweight security questionnaire.
- **Outcome**: Production API keys issued.

### Stage 5: Live & Monitoring

_Status: Live Partner_

You are live in production with full access to all features.

**Production Features**:

- **Real-Time Signal Processing**: Sub-200ms API responses with async fraud scoring
- **Case Management**: Full investigation workflows with team collaboration
- **Alert Management**: Automated fraud detection with customizable thresholds
- **Entity Intelligence**: Deep actor profiles with network analysis
- **Transaction Monitoring**: High-volume transaction review dashboard
- **Analytics & Reporting**: Performance metrics, risk trends, and team insights
- **Webhook Notifications**: Real-time event delivery for `signal.ingested`, `alert.created`, `case.status_changed`
- **API Access**: All partner APIs with production rate limits
- **Sandbox Access**: Continued access to sandbox for testing new features

**Recommended Rollout**:

- **Week 1**: Shadow Mode - Log risk scores without blocking transactions
- **Week 2**: Soft Launch - Block only critical risk (score ≥ 90)
- **Week 3**: Gradual Enforcement - Lower threshold to high risk (score ≥ 80)
- **Week 4+**: Full Enforcement - Apply all risk-based decisions

**Ongoing Support**:

- **Threshold Calibration**: We help tune risk thresholds for your business
- **Performance Review**: Monthly analytics review calls
- **Feature Updates**: Early access to new platform capabilities
- **Technical Support**: Priority support channel for production issues

## Prerequisites

Before starting, ensure you have:

1. **Technical Team**: Developers to handle API integration.
2. **Operational Team**: Fraud analysts or Trust & Safety managers to consume intelligence.
3. **Legal Authority**: Ability to sign data sharing agreements.
