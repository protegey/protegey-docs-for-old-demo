## High-Level Topology

```
Partner System
     │ HTTPS + X-API-Key
     ▼
SignalController (Laravel 12)
     │ validate API key → partner resolved
     │ rate limit check (per-hour / per-day based on plan)
     │ feature flag check
     ▼
IngestSignalAction (synchronous pipeline, target <50ms)
     ├── UFESNormalizationService
     ├── UFESValidator
     ├── ResolverRegistry (MSISDN, Device, Geo, Time)
     ├── FeatureEngineeringService → SignalFeature persisted
     ├── DetectorRegistry (9 detectors) → DetectorExecution persisted
     ├── TaxonomyRegistry → TaxonomyAssignment persisted
     ├── HotGraphService → graph_nodes/graph_edges upserted + Redis warmed
     ├── WeightedRiskFusionEngine → fused_score computed
     ├── PolicyEngine → BLOCK/ALLOW/ESCALATE/STEP_UP decision
     └── AlertGenerationService → FraudAlert + AlertLineage created
             │
             ├── (async) AMLComplianceService
             │         → TransactionMonitoringRulesService
             │         → SanctionsMatchingService
             │         → PEPDetectionService
             │
             ├── (async) ShareAlertOnCreation listener
             │         → BroadcastSharedIntelligenceJob
             │
             └── (async) WebhookService
                       → dispatch HMAC-signed payloads to partner_webhooks
```

## Graph Intelligence (Hot Graph)

```
Signal ingested
     │
     ▼
HotGraphService::linkSignalToGraph()
     │
     ├── GraphNodeService::upsert(ACTOR, actor.hashed_id)
     ├── GraphNodeService::upsert(ACCOUNT, account)
     ├── GraphNodeService::upsert(DEVICE, device_fingerprint)
     ├── GraphNodeService::upsert(MSISDN, msisdn)
     ├── GraphEdgeService::upsert(ACTOR → ACCOUNT, USES_ACCOUNT)
     ├── GraphEdgeService::upsert(ACTOR → DEVICE, USES_DEVICE)
     └── GraphEdgeService::upsert(ACTOR → MSISDN, USES_PHONE)

GraphCacheService (Redis)
     ├── graph:1hop:{node_id} → JSON neighbors (TTL 15min)
     └── graph:2hop:{node_id} → JSON 2-hop aggregate (TTL 15min)

HotGraphService::getNeighborhoodRisk(nodeId, hops=2)
     └── read-through cache: Redis first → Postgres fallback
```

Node types: `ACTOR`, `ACCOUNT`, `MSISDN`, `DEVICE`, `IP`, `MERCHANT`, `AGENT`, `BENEFICIARY`
Edge types: `USES_DEVICE`, `USES_PHONE`, `SENT_TO`, `RECEIVED_FROM`, `CASHED_OUT_AT`, `SHARED_IDENTIFIER`

All graph queries scope by `tenant_id` to prevent cross-tenant IDOR.

## Webhook Dispatch Flow

```
AlertGenerationService creates FraudAlert
     │
     ▼
WebhookService::dispatch(partnerId, event, payload)
     │
     ├── Query partner_webhooks WHERE is_active = true
     ├── Filter by event subscription (JSONB contains check)
     └── For each endpoint:
           ├── Sign payload: HMAC-SHA256(rawBody, endpoint.secret)
           ├── POST to endpoint.url
           │     X-Protegey-Signature: {signature}
           │     X-Protegey-Event: {event_type}
           │     X-Protegey-Delivery-ID: {uuid}
           ├── Record in webhook_deliveries
           └── On failure:
                 increment failure_count
                 if failure_count >= 3: disable endpoint (is_active = false)
```

## Hot Graph Topology

```
Signal Ingestion
    ↓
GraphNodeService.upsert(entity)        → graph_nodes (PostgreSQL)
GraphEdgeService.upsert(source, target) → graph_edges (PostgreSQL)
    ↓
Redis adjacency cache invalidation     → "graph:adj:{partner}:{nodeId}" TTL 15min
    ↓
HotGraphService.getNeighborhood(depth=2)
    ├── Cache HIT  → return in < 5ms
    └── Cache MISS → DB BFS → cache result → return
    ↓
WeightedRiskFusionEngine (network_score = 40%)
```

**Weekly rebuild**: `graph:rebuild-adjacency-cache` job (Sunday 02:00 UTC) pre-warms all partner adjacency lists.

                                           ├── Queue: pending/failed/workers
