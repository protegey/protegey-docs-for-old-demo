# OSINT Confidence Scoring

## Overview

Raw OSINT results (UN/EU/AU sanctions lists, PEP registries) have highly variable reliability. A match on the UN consolidated list is not equivalent to a match on a regional advisory that was last updated 18 months ago. The confidence scoring framework quantifies this variation across four dimensions.

Confidence scores are stored on `OsintEntityLink.confidence_score` (float 0.0–1.0) and are returned in all sanctions screening responses.

---

## The Four Dimensions

### 1. Authority (40%)

Measures the credibility and regulatory weight of the source.

| Source | Authority Score |
|--------|----------------|
| UN Security Council Consolidated List | 1.00 |
| EU Consolidated Financial Sanctions | 0.95 |
| OFAC SDN (USA) | 0.95 |
| African Union Peace & Security Council | 0.85 |
| National FIU lists (FATF member states) | 0.75 |
| GIABA / ESAAMLG advisories | 0.65 |
| INTERPOL Red Notices | 0.80 |
| Nigeria NIGSAC / CBN TFS list | 0.80 |
| OHADA regional lists | 0.55 |
| Commercial OSINT aggregators | 0.50 |

Authority scores are static per source and stored in `config/osint.php` under `source_authority`.

### 2. Freshness (25%)

Measures how recently the source data was ingested and how recently the specific record was confirmed. Uses exponential time-decay:

```php
$daysSinceIngest = now()->diffInDays($link->ingested_at);
$freshnessScore  = exp(-$daysSinceIngest / 365); // half-life ~253 days
```

| Age | Freshness Score |
|-----|----------------|
| 0–7 days | 0.98–1.00 |
| 1 month | 0.92 |
| 3 months | 0.78 |
| 6 months | 0.61 |
| 12 months | 0.37 |
| 24 months | 0.14 |

Freshness is re-computed weekly by the `osint:recompute-freshness` job (Sundays, 05:00 UTC).

### 3. Corroboration (20%)

Measures how many independent sources confirm the same match.

```php
$sourceCount       = $link->corroborating_source_count; // 1–N
$corroborationScore = min(1.0, 0.4 + ($sourceCount - 1) * 0.2);
```

| Independent Sources | Corroboration Score |
|---------------------|---------------------|
| 1 (single source) | 0.40 |
| 2 sources | 0.60 |
| 3 sources | 0.80 |
| 4+ sources | 1.00 |

### 4. Specificity (15%)

Measures how precisely the match identifies the subject — full legal name + DOB + nationality vs. partial name match only.

| Match Fields Present | Specificity Score |
|---------------------|------------------|
| Name + DOB + nationality + identifier | 1.00 |
| Name + DOB + nationality | 0.85 |
| Name + DOB | 0.70 |
| Name + nationality | 0.60 |
| Name only | 0.40 |
| Fuzzy / phonetic match | 0.20 |

Specificity is computed by `EntityResolutionService::computeSpecificity()` at ingest time.

---

## Composite Score Formula

```php
$confidence = (
    ($authority      * 0.40) +
    ($freshness      * 0.25) +
    ($corroboration  * 0.20) +
    ($specificity    * 0.15)
);
```

**Example**: UN SDN list match, ingested 2 weeks ago, confirmed by 2 sources, name + DOB + nationality:
```
(1.00 × 0.40) + (0.97 × 0.25) + (0.60 × 0.20) + (0.85 × 0.15)
= 0.40 + 0.2425 + 0.12 + 0.1275
= 0.89
```

---

## Confidence in Risk Scoring

Confidence scores feed into the sanctions risk contribution:

```php
// In SanctionsMatchingService
$riskContribution = $match->is_exact_match
    ? 100 * $match->confidence_score
    : 50  * $match->confidence_score;
```

A high-confidence match (0.9+) on the UN list contributes close to 90 risk points. A low-confidence match (0.3) on a stale regional list contributes ~15 points — sufficient to flag for review but not to auto-block.

---

## Weekly Decay Job

`php artisan osint:recompute-freshness`

- Selects all `OsintEntityLink` records where `last_freshness_computed_at < 7 days ago`
- Recomputes freshness score using the formula above
- Updates `confidence_score` as composite of current authority + new freshness + stored corroboration + stored specificity
- Logs recomputation count to `osint_freshness_recomputed` metric

Run weekly Sunday 05:00 UTC via Laravel scheduler. Can be run manually without side effects.

## API Exposure

Confidence scores are returned on `GET /api/v1/partner/compliance/sanctions/{entityId}`:

```json
{
  "matches": [
    {
      "source": "UN_CONSOLIDATED",
      "match_type": "exact",
      "confidence_score": 0.89,
      "confidence_breakdown": {
        "authority": 1.00,
        "freshness": 0.97,
        "corroboration": 0.60,
        "specificity": 0.85
      },
      "ingested_at": "2026-03-10T03:00:00Z"
    }
  ]
}
```
