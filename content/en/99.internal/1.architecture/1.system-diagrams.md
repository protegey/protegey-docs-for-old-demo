## High-Level Topology

```mermaid
graph TD
    User[Partner System] -->|TLS 1.3| LB[Load Balancer]
    LB --> API[API Gateway]
    API -->|Auth Check| AuthService[Auth Service]
    API -->|Queue| Kafka[Kafka Signal Topic]
    
    subgraph Core Platform
        Kafka --> Ingest[Ingestion Worker]
        Ingest -->|Write| HotStore[(Redis Cluster)]
        Ingest -->|Write| ColdStore[(Postgres / S3)]
        
        Ingest -->|Trigger| Scorer[Risk Engine]
        Scorer -->|Read| HotStore
        Scorer -->|Read| TrustDB[(Trust Weights DB)]
        Scorer -->|Publish| ResultTopic[Results Topic]
    end
    
    ResultTopic --> Webhook[Webhook Worker]
    Webhook -->|Push| User
```

## Critical Components

1.  **API Gateway**: Handles rate limiting, auth validation, and routing.
2.  **Risk Engine**: The stateless compute cluster that executes scoring logic.
3.  **TrustDB**: Stores partner reputation scores (updated nightly).
