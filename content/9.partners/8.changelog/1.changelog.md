# Changelog

## v1.2.0 (Current)
_Released: 2026-01-10_

- **New Feature**: Added `crypto_address` as a supported Entity Type for Signals.
- **Improvement**: Reduced P99 latency for Queries API by 15%.
- **Fix**: Resolved issue with webhook retry logic for 503 errors.

## v1.1.0
_Released: 2025-12-15_

- **New Feature**: Webhook signing verification (`X-Protegey-Signature`).
- **Security**: Enforced TLS 1.3 for all new connections.
- **Deprecation**: Removed support for `v0` beta endpoints.

## v1.0.0
_Released: 2025-11-01_

- Initial production release.
- Signals API, Queries API, and Partner Portal live.
