# Webhooks

Webhooks allow Protegey to push intelligence to your systems in real-time.

## Event Types

| Event | Description |
|-------|-------------|
| `signal.created` | A new signal was added to the network for an entity you monitor. |
| `risk_score.changed` | The score for a monitored entity crossed a threshold. |
| `trust_score.updated` | Your Partner Trust Score has changed. |

## Configuring Webhooks

1. Go to **Partner Portal > Settings > Webhooks**.
2. Enter your endpoint URL (must remain `https://`).
3. Select the events you want to subscribe to.
4. Copy your **Webhook Signing Secret**.

## Payload Format

```json
{
  "id": "evt_abc123",
  "type": "risk_score.changed",
  "created_at": "2026-01-12T15:00:00Z",
  "data": {
    "entity_type": "email",
    "entity_value": "user@example.com",
    "old_score": 40,
    "new_score": 85,
    "trigger": "new_signal_received"
  }
}
```

## Security: Verifying Signatures

Every webhook request includes an `X-Protegey-Signature` header. You **must** verify this signature to ensure the request came from us.

### Verification Steps

1. Construct the signed content: `timestamp + "." + raw_body`.
2. Compute an HMAC-SHA256 signature using your **Webhook Signing Secret**.
3. Compare your computed signature with the header value.

```javascript
// Node.js Example
const signature = crypto
  .createHmac('sha256', secret)
  .update(`${timestamp}.${body}`)
  .digest('hex');

if (signature !== headerSignature) {
  throw new Error('Invalid signature');
}
```

## Retry Policy

If your endpoint returns anything other than `2xx`, we will retry:
- Immediate retry
- 1 minute
- 5 minutes
- 1 hour
- 6 hours

After 5 failed attempts, the webhook is disabled.
