# Queries API

The Queries API allows you to retrieve the current risk profile for an entity.

## Endpoint

```http
GET /api/v1/queries
```

## Request Parameters

```bash
curl -X GET "https://api.protegey.com/v1/queries?entity_type=email&entity_value=user@example.com" \
  -H "X-Protegey-Key: prt_live_..."
```

| Query Param | Description | Required |
|-------------|-------------|----------|
| `entity_type` | `email`, `phone`, `ip`, etc. | Yes |
| `entity_value` | The value to query. | Yes |
| `include_history` | `true`/`false`. Return recent signal details. | No (Default: false) |

## Response Schema

```json
{
  "entity": {
    "type": "email",
    "value": "user@example.com"
  },
  "risk_score": 85,
  "risk_level": "HIGH",
  "recommendation": "DECLINE",
  "factors": [
    "VELOCITY_HIGH",
    "NETWORK_BLOCKLIST"
  ],
  "signals_count": 12,
  "last_seen": "2026-01-12T10:00:00Z"
}
```

### Risk Levels

| Score | Level | Meaning |
|-------|-------|---------|
| 0-10 | `LOW` | No known risk. Safe to proceed. |
| 11-40 | `MEDIUM` | Some suspicious activity. Step-up auth recommended. |
| 41-80 | `HIGH` | Strong indicators of fraud. Manual review recommended. |
| 81-100 | `CRITICAL` | Confirmed fraud history. Recommend blocking. |

## Latency

The Query API is optimized for real-time decisioning.
- **P95 Latency**: < 200ms
- **P99 Latency**: < 500ms

If you experience latency > 1s, please check your connection or contact support.
